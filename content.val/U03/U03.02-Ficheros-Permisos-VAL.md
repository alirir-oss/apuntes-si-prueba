# 2. Fitxers, directoris i permisos

En Linux se sol dir que **"tot és un fitxer"**: els documents, els directoris, els dispositius i fins i tot la informació dels processos es representen com a fitxers. Per això, saber gestionar-los des del terminal és la base de tota la resta.

## 2.1 Llistar i navegar

| Ordre | Funció |
| --- | --- |
| `pwd` | Mostra el directori actual (*print working directory*). |
| `cd ruta` | Canvia de directori. |
| `ls [ruta]` | Llista el contingut d'un directori. |
| `tree [ruta]` | Mostra l'arbre de directoris (pot ser que calga instal·lar-lo: `sudo apt install tree`). |

Opcions més útils de `ls`:

| Opció | Efecte |
| --- | --- |
| `-l` | Format llarg: permisos, propietari, grandària, data… |
| `-a` | Inclou els fitxers ocults (els que comencen per `.`). |
| `-h` | Grandàries llegibles (K, M, G). S'utilitza juntament amb `-l`. |
| `-t` | Ordena per data de modificació (el més recent primer). |
| `-r` | Inverteix l'ordenació. |
| `-S` | Ordena per grandària. |
| `-R` | Recursiu: entra en els subdirectoris. |
| `-d` | Mostra el mateix directori, no el seu contingut. |

```bash
ls -lah ~          # Tot el directori personal, ocults inclosos, grandàries llegibles
ls -lt /var/log    # Registres ordenats per data
ls -ld /tmp        # Informació del directori /tmp en si
```

### Interpretar l'eixida de `ls -l`

```text
-rw-r--r-- 1 alumno alumno 1036 nov  8 18:41 notas.txt
drwxr-xr-x 2 alumno alumno 4096 nov  8 18:40 proyectos
lrwxrwxrwx 1 alumno alumno   10 nov  8 18:42 enlace -> notas.txt
```

| Camp | Exemple | Significat |
| --- | --- | --- |
| Tipus | `-` / `d` / `l` | `-` fitxer normal, `d` directori, `l` enllaç simbòlic, `c`/`b` dispositiu de caràcters/blocs. |
| Permisos | `rw-r--r--` | Permisos del propietari, del grup i de la resta (vegeu l'apartat 2.7). |
| Enllaços | `1` | Nombre d'enllaços durs al fitxer. |
| Propietari | `alumno` | Usuari propietari. |
| Grup | `alumno` | Grup propietari. |
| Grandària | `1036` | Grandària en bytes. |
| Data | `nov  8 18:41` | Data de l'última modificació. |
| Nom | `notas.txt` | Nom del fitxer. |

## 2.2 Crear, copiar, moure i esborrar

| Ordre | Funció | Opcions importants |
| --- | --- | --- |
| `mkdir dir` | Crea directoris. | `-p` crea els intermedis i no falla si ja existeix. |
| `touch fitx` | Crea un fitxer buit o n'actualitza la data si ja existeix. | |
| `cp origen destinació` | Copia fitxers. | `-r` recursiu (directoris), `-i` pregunta abans de sobreescriure, `-a` conserva permisos, dates i enllaços, `-v` mostra el que fa. |
| `mv origen destinació` | Mou **o canvia el nom**. | `-i` pregunta abans de sobreescriure, `-n` no sobreescriu mai. |
| `rm fitx` | Esborra fitxers. | `-r` recursiu, `-i` pregunta, `-f` força sense preguntar. |
| `rmdir dir` | Esborra un directori **buit**. | |

```bash
mkdir -p ~/practicas/u03         # Crea practicas i u03 si no existeixen
cd ~/practicas/u03
touch a.txt b.txt                # Dos fitxers buits
cp a.txt copia.txt               # Còpia amb un altre nom
cp a.txt b.txt /tmp/             # Diversos fitxers a un directori (la destinació va al final)
cp -r ~/practicas ~/practicas.bak   # Copia un directori complet
mv copia.txt renombrado.txt      # Canviar el nom
mv renombrado.txt /tmp/          # Moure
rm -i b.txt                      # Esborrar demanant confirmació
rmdir vacio/                     # Només funciona si el directori està buit
rm -r ~/practicas.bak            # Esborra un directori i tot el seu contingut
```

> [!CAUTION]
> En Linux **no hi ha paperera** des del terminal: el que s'esborra amb `rm` desapareix. Revisa dues vegades qualsevol ordre `rm -r` o `rm -rf`, especialment si conté comodins o variables. Una ordre com `rm -rf /` (o `rm -rf $DIR/` amb `$DIR` buida) pot destruir el sistema.

## 2.3 Veure el contingut dels fitxers

| Ordre | Funció |
| --- | --- |
| `cat fitx` | Mostra el fitxer complet. Amb diversos fitxers, els concatena. |
| `less fitx` | Mostra el fitxer paginat. `Espai` avança, `b` retrocedeix, `/text` busca, `q` ix. |
| `head -n N fitx` | Mostra les N primeres línies (10 per defecte). |
| `tail -n N fitx` | Mostra les N últimes línies (10 per defecte). |
| `tail -f fitx` | Segueix el fitxer en temps real (molt útil amb registres). `Ctrl+C` per a eixir. |
| `nl fitx` / `cat -n fitx` | Mostra el fitxer amb les línies numerades. |
| `wc fitx` | Compta línies (`-l`), paraules (`-w`) i bytes (`-c`). |

```bash
cat /etc/hostname
less /etc/services
head -n 3 /etc/passwd
sudo tail -f /var/log/syslog     # En sistemes amb només journald: journalctl -f
wc -l /etc/passwd                # Quantes línies (usuaris) hi ha?
```

## 2.4 Informació sobre fitxers

```bash
file /bin/ls          # ELF 64-bit LSB pie executable…  -> tipus real del fitxer
file foto.jpg         # JPEG image data…  (Linux no depén de l'extensió)
stat notas.txt        # Grandària, permisos, inode i dates d'accés/modificació/canvi
du -sh ~/Descargas    # Espai que ocupa un directori (-s resum, -h llegible)
```

## 2.5 Enllaços

Cada fitxer s'emmagatzema en el disc en una estructura anomenada **inode**, que en guarda les dades i les metadades (permisos, propietari, blocs que ocupa…). El nom del fitxer és només una entrada de directori que apunta a un inode. Hi ha dos tipus d'enllaços:

| | Enllaç dur (`ln`) | Enllaç simbòlic (`ln -s`) |
| --- | --- | --- |
| Què és | Un altre nom per al **mateix inode**. | Un fitxer xicotet que conté la **ruta** d'un altre (com un accés directe). |
| Si s'esborra l'original | El contingut continua accessible des de l'enllaç. | L'enllaç queda "trencat". |
| Directoris | No permés. | Permés. |
| Entre particions | No. | Sí. |

```bash
ln notas.txt notas_duro.txt          # Enllaç dur
ln -s /var/log/syslog ~/syslog       # Enllaç simbòlic: ln -s DESTINACIÓ NOM_ENLLAÇ
ls -li                               # -i mostra el número d'inode
```

## 2.6 Buscar fitxers amb `find`

`find` recorre un arbre de directoris i mostra els fitxers que compleixen unes condicions:

```text
find [on] [condicions] [acció]
```

| Condició | Significat |
| --- | --- |
| `-name 'patró'` | Nom (admet comodins; posa'l **entre cometes** perquè no l'expandisca la shell). |
| `-iname 'patró'` | Igual que `-name`, sense distingir majúscules. |
| `-type f` / `-type d` / `-type l` | Fitxers normals / directoris / enllaços simbòlics. |
| `-size +10M` / `-size -1k` | Més de 10 MiB / menys d'1 KiB. |
| `-mtime -7` / `-mtime +30` | Modificats fa menys de 7 dies / més de 30 dies. |
| `-user nom` | Pertanyen a l'usuari indicat. |
| `-perm -u=x` | Tenen activat el permís d'execució per al propietari. |
| `-empty` | Fitxers o directoris buits. |
| `-maxdepth N` | Baixa com a màxim N nivells. |

| Acció | Significat |
| --- | --- |
| `-print` | Mostra la ruta (acció per defecte). |
| `-exec ordre {} \;` | Executa una ordre per cada fitxer; `{}` se substitueix per la seua ruta. |
| `-exec ordre {} +` | Igual, però passant molts fitxers d'una vegada (més eficient). |
| `-delete` | Esborra els fitxers trobats (prova-ho abans sense `-delete`!). |

```bash
find ~ -name '*.java'                       # Fitxers .java en el meu directori personal
find /etc -maxdepth 1 -type f -name '*.conf'
find ~ -type f -size +100M                  # Fitxers grans
find /tmp -type f -mtime +7 -user "$USER"   # Els meus fitxers temporals de fa més d'una setmana
find . -type f -name '*.sh' -exec chmod u+x {} +   # Dona permís d'execució a tots els .sh
find . -type d -empty                       # Directoris buits
find /etc -name '*.conf' 2>/dev/null        # Amaga els errors de "Permís denegat"
```

> [!TIP]
> Per a buscar **dins** del contingut dels fitxers s'utilitza `grep -r 'text' directori`, que veurem en l'apartat següent.

## 2.7 Permisos

Linux és un sistema **multiusuari**: cada fitxer té un **propietari** i un **grup**, i uns permisos que indiquen què pot fer cada tipus d'usuari.

### Els tres permisos i les tres classes d'usuari

| Permís | Sobre un fitxer | Sobre un directori |
| --- | --- | --- |
| `r` (lectura) | Veure'n el contingut. | Llistar-ne el contingut (`ls`). |
| `w` (escriptura) | Modificar-ne el contingut. | Crear, esborrar i canviar el nom de fitxers de dins. |
| `x` (execució) | Executar-lo com a programa o script. | Entrar-hi (`cd`) i accedir als seus fitxers. |

Els permisos s'agrupen de tres en tres:

```text
 -   rwx   r-x   r--
 │    │     │     └── o (others): la resta d'usuaris
 │    │     └──────── g (group): membres del grup propietari
 │    └────────────── u (user): el propietari
 └─────────────────── tipus de fitxer
```

### `chmod`: canviar permisos

`chmod` admet dues notacions.

**Notació simbòlica**: `[ugoa][+-=][rwx]`

```bash
chmod u+x script.sh          # Afig execució al propietari
chmod g-w informe.txt        # Lleva escriptura al grup
chmod o= privado.txt         # Deixa la resta sense cap permís
chmod a+r publico.txt        # Lectura per a tots (a = all)
chmod u+rwx,g+rx,o-rwx dir/  # Diverses modificacions separades per comes
chmod -R g+w compartido/     # Recursiu: el directori i tot el seu contingut
```

**Notació octal**: cada classe d'usuari es representa amb un número que és la suma de `r=4`, `w=2` i `x=1`.

| Octal | Permisos | | Octal | Permisos |
| --- | --- | --- | --- | --- |
| `7` | `rwx` (4+2+1) | | `3` | `-wx` (2+1) |
| `6` | `rw-` (4+2) | | `2` | `-w-` |
| `5` | `r-x` (4+1) | | `1` | `--x` |
| `4` | `r--` | | `0` | `---` |

```bash
chmod 755 script.sh     # rwxr-xr-x : típic d'scripts i directoris
chmod 644 index.html    # rw-r--r-- : típic de fitxers de dades
chmod 600 ~/.ssh/id_ed25519   # rw------- : claus privades (SSH ho exigeix)
chmod 700 ~/privado     # rwx------ : directori només accessible per mi
```

> [!NOTE]
> En la Unitat 4 s'estudien amb detall el canvi de propietari (`chown`, `chgrp`), la màscara `umask`, els permisos especials (SUID, SGID, *sticky bit*) i les llistes de control d'accés (ACL).

## Exercicis resolts

### Exercici 2.1. Organitzar una pràctica

Crea en el teu directori personal la carpeta `entrega`, amb els fitxers buits `main.sh`, `README.md` i `notas.txt`. Després copia tota la carpeta a `entrega_backup`, canvia el nom de `notas.txt` a `apuntes.txt` (en la carpeta original) i esborra la còpia de seguretat.

{{% details "Veure solució" %}}
```bash
mkdir ~/entrega
touch ~/entrega/{main.sh,README.md,notas.txt}
cp -r ~/entrega ~/entrega_backup
mv ~/entrega/notas.txt ~/entrega/apuntes.txt
rm -r ~/entrega_backup
ls -l ~/entrega      # Comprovació
```
{{% /details %}}

### Exercici 2.2. Interpretar permisos

Indica què pot fer cada classe d'usuari i escriu-ne l'equivalent octal:

1. `-rwxr-x---`
2. `-rw-rw-r--`
3. `drwx--x--x`

{{% details "Veure solució" %}}
1. `750`. Propietari: llegir, escriure i executar. Grup: llegir i executar. Resta: res.
2. `664`. Propietari i grup: llegir i escriure. Resta: només llegir.
3. `711`. És un directori. El propietari pot llistar-lo, crear-hi fitxers i entrar-hi; el grup i la resta només poden **entrar-hi** (`cd`) i accedir a un fitxer si en coneixen el nom exacte, però no poden llistar-ne el contingut.
{{% /details %}}

### Exercici 2.3. Protegir un fitxer

Crea el fitxer `secreto.txt` de manera que **només tu** pugues llegir-lo i modificar-lo. Fes-ho amb les dues notacions de `chmod` i comprova el resultat.

{{% details "Veure solució" %}}
```bash
touch secreto.txt
chmod 600 secreto.txt           # Notació octal
chmod u=rw,go= secreto.txt      # Notació simbòlica equivalent
ls -l secreto.txt               # -rw------- 1 alumno alumno 0 … secreto.txt
```
{{% /details %}}

### Exercici 2.4. Cerques amb `find`

Escriu l'ordre que:

1. Mostra els fitxers `.log` de `/var/log` (sense entrar en subdirectoris).
2. Mostra els fitxers del teu directori personal modificats en les últimes 24 hores.
3. Compta quants fitxers `.conf` hi ha en `/etc` i els seus subdirectoris.
4. Esborra els fitxers `.tmp` de `~/practicas` (comprovant abans quins són).

{{% details "Veure solució" %}}
```bash
find /var/log -maxdepth 1 -type f -name '*.log'
find ~ -type f -mtime -1
find /etc -type f -name '*.conf' 2>/dev/null | wc -l   # wc -l compta les línies (vegeu l'apartat 3)
find ~/practicas -type f -name '*.tmp'          # 1r: comprovar
find ~/practicas -type f -name '*.tmp' -delete  # 2n: esborrar
```
{{% /details %}}
