# 8. Bucles: repetir accions

Un **bucle** repeteix un bloc d'ordres diverses vegades. Bash n'ofereix tres: `for` (per a cada element d'una llista), `while` (mentre es complisca una condició) i `until` (fins que es complisca una condició).

## 8.1 El bucle `for` sobre una llista

```bash
for variable in element1 element2 element3; do
    ordres que utilitzen "$variable"
done
```

En cada volta (**iteració**), la variable pren el valor de l'element següent de la llista.

```bash
for fruta in poma pera "raïm blanc"; do
    echo "M'agrada: $fruta"
done
```

La llista es pot generar de moltes maneres:

```bash
for i in {1..5}; do echo "Volta $i"; done            # Rang amb claus
for i in {0..20..5}; do echo "$i"; done              # 0 5 10 15 20 (amb salt)
for i in $(seq 1 2 9); do echo "$i"; done            # 1 3 5 7 9  (seq inici salt fi)
for fichero in *.txt; do echo "Processant $fichero"; done   # Fitxers que encaixen amb el patró
for usuario in $(cut -d: -f1 /etc/passwd); do echo "$usuario"; done   # Eixida d'una ordre
for param in "$@"; do echo "Paràmetre: $param"; done        # Paràmetres de l'script
```

> [!WARNING]
> Si cap fitxer no encaixa amb `*.txt`, Bash deixa el patró **tal qual** i el bucle s'executa una vegada amb la variable valent literalment `*.txt`. Per a evitar-ho, comprova que el fitxer existeix dins del bucle (`[[ -e $fichero ]] || continue`) o activa `shopt -s nullglob` al principi de l'script.

> [!NOTE]
> `for x in $(ordre)` separa l'eixida per **espais i salts de línia**, així que no és adequat si els elements poden contindre espais (per exemple, noms de fitxer). Per a recórrer línies s'utilitza `while read` (apartat 8.4) i per a recórrer fitxers, els comodins (`for f in *`).

## 8.2 El bucle `for` d'estil C

Quan necessitem un comptador numèric, Bash admet la sintaxi de C i Java:

```bash
for (( i = 0; i < 10; i++ )); do
    echo "i val $i"
done

for (( i = 10; i > 0; i -= 2 )); do echo -n "$i "; done; echo   # 10 8 6 4 2
```

Té tres parts: **inicialització** (`i = 0`), **condició** per a continuar (`i < 10`) i **actualització** en cada volta (`i++`). A diferència de `{1..n}`, els límits poden ser variables:

```bash
read -rp "Fins a quin número? " n
for (( i = 1; i <= n; i++ )); do echo "$i"; done
```

## 8.3 Els bucles `while` i `until`

`while` repeteix **mentre** la condició siga certa; `until`, **fins que** ho siga (és a dir, mentre siga falsa).

```bash
contador=1
while (( contador <= 5 )); do
    echo "Comptador: $contador"
    contador=$(( contador + 1 ))
done

contador=1
until (( contador > 5 )); do        # Mateix resultat amb until
    echo "Comptador: $contador"
    contador=$(( contador + 1 ))
done
```

`while` és el bucle adequat quan **no sabem quantes voltes** es faran, per exemple, en demanar dades fins que siguen correctes:

```bash
read -rp "Introdueix un número positiu: " num
while [[ ! $num =~ ^[0-9]+$ ]]; do
    echo "Valor no vàlid."
    read -rp "Introdueix un número positiu: " num
done
echo "Has introduït $num"
```

O en esperar que passe alguna cosa:

```bash
until ping -c 1 -W 1 servidor.local > /dev/null 2>&1; do
    echo "Esperant que el servidor responga…"
    sleep 5
done
echo "Servidor disponible!"
```

Un bucle **infinit** s'escriu amb `while true` i s'abandona amb `break` (o `Ctrl+C`):

```bash
while true; do
    read -rp "Escriu 'eixir' per a acabar: " orden
    [[ $orden == "eixir" ]] && break
    echo "Has escrit: $orden"
done
```

## 8.4 Llegir un fitxer línia a línia

Una de les tasques més freqüents dels scripts d'administració és processar un fitxer de text línia a línia. La forma correcta és:

```bash
while IFS= read -r linea; do
    echo "Línia: $linea"
done < fichero.txt
```

- `< fichero.txt`, al final del bucle, fa que `read` llija del fitxer en lloc del teclat.
- `read` retorna "fals" quan arriba al final del fitxer, i el bucle acaba.
- `IFS=` evita que s'eliminen els espais del principi i del final de la línia, i `-r` que s'interpreten les barres invertides.

`IFS` (*Internal Field Separator*) és la variable que indica a `read` quin caràcter separa els camps. Si li donem un valor, `read` pot **trossejar cada línia** en diverses variables. És ideal per a fitxers CSV o per a `/etc/passwd`:

```bash
#!/bin/bash
# usuarios.sh - Mostra usuari, UID i shell de cada compte
while IFS=: read -r usuario _ uid gid descripcion home shell; do
    echo "$usuario (UID $uid) utilitza $shell"
done < /etc/passwd
```

El guió baix `_` és un nom de variable que, per convenció, indica "aquest camp no m'interessa".

> [!CAUTION]
> Evita escriure `cat fitxer | while read …`. La canonada executa el bucle en un **subprocés**, així que les variables que modifiques dins (comptadors, sumes…) **es perden** en acabar el bucle. Utilitza sempre la redirecció `done < fitxer`.

## 8.5 `break` i `continue`

- `break` ix del bucle immediatament.
- `continue` abandona la volta actual i passa a la següent.

```bash
for n in {1..20}; do
    (( n % 2 == 0 )) && continue   # Bota els parells
    (( n > 11 )) && break          # Acaba en passar d'11
    echo -n "$n "
done
echo                                # 1 3 5 7 9 11
```

## 8.6 Menús interactius

Combinant `while` i `case` es construeixen menús que es repeteixen fins que l'usuari tria eixir. És un patró molt habitual en els exercicis d'aquesta unitat:

```bash
#!/bin/bash
# menu.sh - Menú d'informació del sistema

while true; do
    echo
    echo "===== MENÚ ====="
    echo "1) Data i hora"
    echo "2) Usuaris connectats"
    echo "3) Espai en disc"
    echo "4) Eixir"
    read -rp "Tria una opció: " opcion

    case "$opcion" in
        1) date ;;
        2) who ;;
        3) df -h / ;;
        4) echo "Fins prompte!"; break ;;
        *) echo "Opció no vàlida" ;;
    esac
done
```

Bash inclou també l'ordre `select`, que genera automàticament un menú numerat a partir d'una llista:

```bash
PS3="Tria un llenguatge: "           # PS3 és el missatge que mostra select
select lenguaje in Java Kotlin Python Eixir; do
    case "$lenguaje" in
        Eixir) break ;;
        "")    echo "Opció no vàlida" ;;   # Número fora de rang
        *)     echo "Has triat $lenguaje" ;;
    esac
done
```

## Exercicis resolts

### Exercici 8.1. Taula de multiplicar

Script que reba un número com a paràmetre (si no el rep, el demana per teclat) i en mostre la taula de multiplicar de l'1 al 10 amb un format alineat.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# tabla.sh - Taula de multiplicar
# Ús: ./tabla.sh [número]

num=$1
while [[ ! $num =~ ^-?[0-9]+$ ]]; do
    read -rp "Introdueix un número enter: " num
done

for (( i = 1; i <= 10; i++ )); do
    printf "%3d x %2d = %4d\n" "$num" "$i" $(( num * i ))
done
```

Si `$1` està buit o no és un número, la condició del `while` és certa i es demana el valor fins que siga correcte.
{{% /details %}}

### Exercici 8.2. Suma i mitjana dels paràmetres

Script que reba una quantitat variable de números enters i mostre quants són, la seua suma, la mitjana (amb dos decimals), el major i el menor. Els paràmetres que no siguen números s'ignoraran amb un avís.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# estadisticas.sh - Estadístiques dels números rebuts
# Ús: ./estadisticas.sh n1 n2 n3 …

(( $# > 0 )) || { echo "Ús: $0 n1 [n2 …]" >&2; exit 1; }

cantidad=0
suma=0

for n in "$@"; do
    if [[ ! $n =~ ^-?[0-9]+$ ]]; then
        echo "Avís: s'ignora '$n'" >&2
        continue
    fi
    # En la primera volta vàlida, el número és alhora el major i el menor
    if (( cantidad == 0 )); then
        mayor=$n
        menor=$n
    fi
    (( n > mayor )) && mayor=$n
    (( n < menor )) && menor=$n
    suma=$(( suma + n ))
    cantidad=$(( cantidad + 1 ))
done

(( cantidad > 0 )) || { echo "No s'ha rebut cap número vàlid" >&2; exit 2; }

media=$(awk -v s="$suma" -v c="$cantidad" 'BEGIN { printf "%.2f", s / c }')

echo "Quantitat: $cantidad"
echo "Suma:      $suma"
echo "Mitjana:   $media"
echo "Major:     $mayor"
echo "Menor:     $menor"
```

```text
$ ./estadisticas.sh 4 8 hola 15 -3
Avís: s'ignora 'hola'
Quantitat: 4
Suma:      24
Mitjana:   6.00
Major:     15
Menor:     -3
```

`awk -v` passa variables de Bash a `awk`, que sí que sap treballar amb decimals.
{{% /details %}}

### Exercici 8.3. Canvi de nom massiu

Script que afija a tots els fitxers `.jpg` del directori indicat (per defecte, l'actual) un prefix amb la data de hui: `foto.jpg` → `2026-11-08_foto.jpg`. Al final, ha d'indicar a quants fitxers ha canviat el nom.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# prefijo_fecha.sh - Afig la data com a prefix als .jpg
# Ús: ./prefijo_fecha.sh [directori]

dir=${1:-.}
[[ -d $dir ]] || { echo "Error: '$dir' no és un directori" >&2; exit 1; }

hoy=$(date +%F)
renombrados=0

for ruta in "$dir"/*.jpg; do
    [[ -e $ruta ]] || continue          # No hi ha cap .jpg
    nombre=$(basename "$ruta")          # foto.jpg (sense el directori)
    [[ $nombre == "${hoy}_"* ]] && continue   # Ja té el prefix: no el repetim
    mv -n -- "$ruta" "$dir/${hoy}_$nombre"
    renombrados=$(( renombrados + 1 ))
done

echo "Fitxers reanomenats: $renombrados"
```

Per a provar-ho sense risc: `mkdir prueba && touch prueba/{a,b,c}.jpg && ./prefijo_fecha.sh prueba && ls prueba`.
{{% /details %}}

### Exercici 8.4. Informe d'usuaris des d'un CSV

Donat el fitxer `alumnos.csv` (crea'l amb el contingut de baix), mostra un llistat amb el format `COGNOMS, Nom (grup)` i, al final, el nombre d'alumnes de cada grup. La primera línia és la capçalera i no s'ha de processar.

```text
nombre,apellidos,grupo
Ana,López Pérez,DAM1A
Luis,García Ruiz,DAM1B
Marta,Sanz Gil,DAM1A
Pablo,Ortega Martín,DAM1A
```

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# informe_alumnos.sh - Processa alumnos.csv
fichero=${1:-alumnos.csv}
[[ -r $fichero ]] || { echo "No es pot llegir '$fichero'" >&2; exit 1; }

total_a=0
total_b=0

# tail -n +2 mostra el fitxer a partir de la línia 2 (sense capçalera).
# < <(ordre) és una "substitució de processos": el bucle llig l'eixida de l'ordre
# sense utilitzar una canonada, així que els comptadors no es perden.
while IFS=, read -r nombre apellidos grupo; do
    echo "${apellidos^^}, $nombre ($grupo)"     # ^^ converteix a majúscules
    case "$grupo" in
        DAM1A) total_a=$(( total_a + 1 )) ;;
        DAM1B) total_b=$(( total_b + 1 )) ;;
    esac
done < <(tail -n +2 "$fichero")

echo "---"
echo "DAM1A: $total_a alumnes"
echo "DAM1B: $total_b alumnes"
```

```text
LÓPEZ PÉREZ, Ana (DAM1A)
GARCÍA RUIZ, Luis (DAM1B)
SANZ GIL, Marta (DAM1A)
ORTEGA MARTÍN, Pablo (DAM1A)
---
DAM1A: 3 alumnes
DAM1B: 1 alumnes
```

Si hi haguera molts grups distints, seria millor comptar-los amb un *array* associatiu (apartat 10) o amb `cut -d, -f3 alumnos.csv | tail -n +2 | sort | uniq -c`.
{{% /details %}}

### Exercici 8.5. Endevina el número

Joc en què l'script tria un número aleatori entre 1 i 100 i l'usuari té 7 intents per a endevinar-lo. Després de cada intent, l'script indica si el número secret és major o menor.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# adivina.sh - Joc d'endevinar un número
readonly MAX_INTENTOS=7
secreto=$(( RANDOM % 100 + 1 ))     # RANDOM: 0-32767 → % 100: 0-99 → +1: 1-100

for (( intento = 1; intento <= MAX_INTENTOS; intento++ )); do
    read -rp "Intent $intento/$MAX_INTENTOS. El teu número: " n

    if [[ ! $n =~ ^[0-9]+$ ]]; then
        echo "Això no és un número (l'intent compta igualment)."
    elif (( n < secreto )); then
        echo "El número secret és MAJOR."
    elif (( n > secreto )); then
        echo "El número secret és MENOR."
    else
        echo "Correcte! L'has endevinat en $intento intents."
        exit 0
    fi
done

echo "Has esgotat els intents. El número era $secreto."
exit 1
```
