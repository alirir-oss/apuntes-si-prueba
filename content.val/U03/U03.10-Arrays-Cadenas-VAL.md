# 10. Arrays i manipulació de cadenes

## 10.1 *Arrays* indexats

Un ***array*** (vector o llista) és una variable que guarda **diversos valors**, cadascun identificat per un **índex** numèric que comença en **0**.

```bash
# Creació
lenguajes=("Java" "Kotlin" "Python" "Bash")
notas=(7 5 9 6)
vacio=()

# Accés a un element: les claus són obligatòries!
echo "${lenguajes[0]}"      # Java
echo "${lenguajes[2]}"      # Python
echo "${lenguajes[-1]}"     # Bash (índexs negatius: des del final)

# Modificar i afegir
lenguajes[1]="C#"
lenguajes+=("SQL")          # Afig al final
unset 'lenguajes[0]'        # Elimina un element (l'índex 0 queda buit)
```

| Expressió | Resultat |
| --- | --- |
| `"${a[@]}"` | Tots els elements, cadascun per separat (com `"$@"`). |
| `${#a[@]}` | Nombre d'elements. |
| `"${!a[@]}"` | Llista d'índexs. |
| `${#a[i]}` | Longitud de l'element `i`. |
| `"${a[@]:1:2}"` | Dos elements a partir de l'índex 1 (un "tros" de l'*array*). |

### Recórrer un *array*

```bash
notas=(7 5 9 6)

# Per valors
for nota in "${notas[@]}"; do
    echo "Nota: $nota"
done

# Per índexs (quan necessitem la posició)
for i in "${!notas[@]}"; do
    echo "Alumne $i: ${notas[i]}"     # Dins de [ ] no cal el $
done

# Amb un comptador d'estil C
for (( i = 0; i < ${#notas[@]}; i++ )); do
    echo "Posició $i → ${notas[i]}"
done
```

### Emplenar un *array*

```bash
# Des de l'eixida d'una ordre o d'un fitxer, un element per línia
mapfile -t lineas < /etc/hostname
mapfile -t usuarios < <(cut -d: -f1 /etc/passwd)
echo "Hi ha ${#usuarios[@]} usuaris; el primer és ${usuarios[0]}"

# Des d'una cadena, separant per un caràcter
ruta="/usr/local/bin"
IFS=/ read -ra partes <<< "$ruta"     # partes=("" "usr" "local" "bin")

# Des del teclat
read -rap "Escriu diversos números separats per espais: " numeros
echo "Has escrit ${#numeros[@]} números"

# Amb fitxers
fotos=(*.jpg)
```

### Passar un *array* a una funció

Les funcions no reben *arrays* com a tals, sinó una llista de paràmetres. S'expandeix l'*array* en la crida amb `"${a[@]}"` i, dins de la funció, es recupera amb `"$@"`:

```bash
media() {
    local suma=0 n
    for n in "$@"; do
        suma=$(( suma + n ))
    done
    echo $(( suma / $# ))
}

notas=(7 5 9 6)
echo "Mitjana entera: $(media "${notas[@]}")"   # Mitjana entera: 6
```

## 10.2 *Arrays* associatius (ampliació)

En un *array* **associatiu** (diccionari o mapa) els índexs són **cadenes** en lloc de números. Cal declarar-los amb `declare -A`:

```bash
declare -A capital
capital[Espanya]="Madrid"
capital[França]="París"
capital+=([Itàlia]="Roma")

echo "${capital[França]}"                 # París
for pais in "${!capital[@]}"; do          # L'ordre de les claus no està garantit
    echo "$pais → ${capital[$pais]}"
done

# Comptar aparicions: shells utilitzades en el sistema
declare -A cuenta
while IFS=: read -r _ _ _ _ _ _ shell; do
    cuenta[$shell]=$(( ${cuenta[$shell]:-0} + 1 ))
done < /etc/passwd
for s in "${!cuenta[@]}"; do echo "$s: ${cuenta[$s]}"; done
```

## 10.3 Manipulació de cadenes

Bash disposa d'**expansions de paràmetres** que permeten transformar el contingut d'una variable sense recórrer a programes externs.

### Longitud i subcadenes

```bash
texto="Sistemas Informáticos"
echo "${#texto}"          # 21  -> longitud
echo "${texto:0:8}"       # Sistemas  -> 8 caràcters des de la posició 0
echo "${texto:9}"         # Informáticos  -> des de la posició 9 fins al final
echo "${texto: -5}"       # ticos  -> els 5 últims (l'espai abans del - és necessari!)
```

### Eliminar prefixos i sufixos

| Expansió | Elimina… |
| --- | --- |
| `${var#patró}` | La coincidència **més curta** del patró **al principi**. |
| `${var##patró}` | La coincidència **més llarga** al principi. |
| `${var%patró}` | La coincidència **més curta** **al final**. |
| `${var%%patró}` | La coincidència **més llarga** al final. |

Una regla per a recordar-ho: en el teclat, `#` està a l'esquerra de `%`, igual que el principi està a l'esquerra del final.

```bash
ruta="/home/alumno/proyectos/informe.final.pdf"

echo "${ruta##*/}"      # informe.final.pdf      -> nom del fitxer (com basename)
echo "${ruta%/*}"       # /home/alumno/proyectos -> directori (com dirname)
echo "${ruta##*.}"      # pdf                    -> extensió
fichero=${ruta##*/}
echo "${fichero%.*}"    # informe.final          -> nom sense l'última extensió
echo "${fichero%%.*}"   # informe                -> nom sense cap extensió
```

### Reemplaçar

```bash
frase="hola món, hola Bash"
echo "${frase/hola/adéu}"      # adéu món, hola Bash   -> la primera coincidència
echo "${frase//hola/adéu}"     # adéu món, adéu Bash   -> totes
echo "${frase// /_}"           # hola_món,_hola_Bash   -> espais per guions baixos
```

### Majúscules i minúscules

```bash
nombre="aNa lÓpez"
echo "${nombre^^}"     # ANA LÓPEZ  -> tot en majúscules
echo "${nombre,,}"     # ana lópez  -> tot en minúscules
echo "${nombre^}"      # ANa lÓpez  -> només la primera lletra en majúscula
```

### Valors per defecte (recordatori)

| Expansió | Resultat |
| --- | --- |
| `${var:-valor}` | `valor` si `var` no existeix o està buida (no modifica `var`). |
| `${var:=valor}` | Igual, però a més **assigna** `valor` a `var`. |
| `${var:?missatge}` | Si `var` no existeix o està buida, mostra `missatge` i acaba l'script. |
| `${var:+valor}` | `valor` si `var` **té** contingut; buit en cas contrari. |

## Exercicis resolts

### Exercici 10.1. Ordenar un vector (mètode de la bombolla)

Script que guarde en un *array* els números rebuts com a paràmetres i els ordene de menor a major **sense utilitzar `sort`**, implementant el mètode de la bombolla. Mostra el vector abans i després.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# burbuja.sh - Ordena els paràmetres amb el mètode de la bombolla
# Ús: ./burbuja.sh 10 2 32 14 5

(( $# > 0 )) || { echo "Ús: $0 n1 n2 …" >&2; exit 1; }

datos=("$@")
n=${#datos[@]}
echo "Original: ${datos[*]}"

# En cada passada, el major dels no ordenats "puja" fins a la seua posició final
for (( pasada = 0; pasada < n - 1; pasada++ )); do
    for (( j = 0; j < n - 1 - pasada; j++ )); do
        if (( datos[j] > datos[j + 1] )); then
            # Intercanvi utilitzant una variable auxiliar
            aux=${datos[j]}
            datos[j]=${datos[j + 1]}
            datos[j + 1]=$aux
        fi
    done
done

echo "Ordenat:  ${datos[*]}"
```

```text
$ ./burbuja.sh 10 2 32 14 5
Original: 10 2 32 14 5
Ordenat:  2 5 10 14 32
```

Aquest algorisme també l'estudiareu en Programació. En un script real utilitzaríem `printf '%s\n' "${datos[@]}" | sort -n`.
{{% /details %}}

### Exercici 10.2. És un palíndrom?

Script que demane una frase i indique si és un palíndrom (es llig igual del dret i del revés), sense tindre en compte els espais ni les majúscules. Per exemple: "Senén té sis nens i set nenes" (sense accents: "senen te sis nens i set nenes").

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# palindromo.sh - Comprova si una frase és un palíndrom

read -rp "Escriu una frase: " frase

# Normalitzem: minúscules i sense espais
limpia=${frase,,}
limpia=${limpia// /}

# Construïm la cadena invertida caràcter a caràcter
invertida=""
for (( i = ${#limpia} - 1; i >= 0; i-- )); do
    invertida+=${limpia:i:1}
done

if [[ $limpia == "$invertida" ]]; then
    echo "\"$frase\" és un palíndrom"
else
    echo "\"$frase\" NO és un palíndrom"
fi
```

Per a simplificar, l'script no elimina els accents: "Senén té sis nens i set nenes" no es detectaria. Es podria millorar amb `sed 'y/áàéèíóòú/aaeeioou/'`. També hi ha l'ordre `rev`, que inverteix una cadena: `invertida=$(rev <<< "$limpia")`.
{{% /details %}}

### Exercici 10.3. Ordenar les descàrregues per tipus

Script que recórrega un directori (per defecte `~/Descargas`) i moga cada fitxer a una subcarpeta amb el nom de la seua extensió en minúscules (`pdf/`, `jpg/`, `zip/`…). Els fitxers sense extensió aniran a `otros/`. Al final mostrarà quants fitxers s'han mogut a cada carpeta. Ha d'admetre l'opció `-n` com a primer paràmetre per a **simular** (mostrar què faria sense moure res).

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# ordenar_descargas.sh - Organitza fitxers en carpetes per extensió
# Ús: ./ordenar_descargas.sh [-n] [directori]
#   -n  Simulació: mostra el que faria sense moure res

simular=false
if [[ $1 == "-n" ]]; then
    simular=true
    shift
fi

dir=${1:-$HOME/Descargas}
[[ -d $dir ]] || { echo "Error: '$dir' no és un directori" >&2; exit 1; }

declare -A movidos            # extensió -> nombre de fitxers

for ruta in "$dir"/*; do
    [[ -f $ruta ]] || continue          # Només fitxers (ni directoris ni res si està buit)

    nombre=${ruta##*/}
    if [[ $nombre == *.* ]]; then
        ext=${nombre##*.}
        ext=${ext,,}
    else
        ext="otros"                     # Sense extensió
    fi

    if $simular; then
        echo "[simulació] $nombre → $ext/"
    else
        mkdir -p "$dir/$ext"
        mv -n -- "$ruta" "$dir/$ext/"
    fi
    movidos[$ext]=$(( ${movidos[$ext]:-0} + 1 ))
done

echo "--- Resum ---"
for ext in "${!movidos[@]}"; do
    printf "%-8s %3d fitxer(s)\n" "$ext/" "${movidos[$ext]}"
done
```

El comodí `*` no inclou els fitxers ocults (els que comencen per punt), així que l'script no els mou. `simular` guarda la paraula `true` o `false`, que també són ordres (retornen 0 i 1); per això `if $simular; then` funciona com una condició.
{{% /details %}}
