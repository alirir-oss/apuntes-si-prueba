# 6. Variables, paràmetres, entrada i eixida

## 6.1 Variables

Una **variable** és un nom que guarda un valor per a poder utilitzar-lo més tard. En Bash:

- **No és obligatori declarar-les** i, per defecte, no tenen tipus: tot valor és, en principi, una **cadena de text**.
- S'**assignen** amb `nom=valor`, **sense espais** al voltant de l'`=`.
- Es **consulten** anteposant-hi `$`: `$nom` o, de manera més explícita, `${nom}`.
- Consultar una variable que no existeix no dona error: se substitueix per una cadena buida (excepte amb `set -u`).

```bash
#!/bin/bash
ciclo="DAM"
curso=1
modulo="Sistemes Informàtics"

echo "Estudie el curs $curso de $ciclo, mòdul $modulo"
echo "Fitxer de notes: ${ciclo}_notas.txt"   # Les claus delimiten el nom
echo "Fitxer de notes: $ciclo_notas.txt"     # Error! Busca la variable "ciclo_notas"
```

**Regles per als noms**: lletres, xifres i guió baix; no poden començar per xifra; distingeixen majúscules. Per convenció, les variables d'**entorn** i les constants s'escriuen en MAJÚSCULES (`PATH`, `HOME`, `MAX_INTENTOS`) i les variables pròpies de l'script en minúscules (`fichero`, `contador`), per a no sobreescriure per error una variable del sistema.

```bash
readonly IVA=21        # Constant: no es pot modificar
unset curso            # Elimina la variable
```

### Tipus de dades: `declare`

Encara que Bash guarda tot com a text, l'ordre interna `declare` permet indicar el **tipus** o un **atribut** d'una variable. És el més semblant a declarar tipus que ofereix Bash:

| Declaració | Tipus / atribut | Exemple |
| --- | --- | --- |
| *(cap)* | Cadena de text (tipus per defecte). | `nombre="Ana"` |
| `declare -i` | **Enter**: les assignacions s'avaluen com a expressions aritmètiques. | `declare -i total=2+3` → `5` |
| `declare -a` | *Array* indexat (llista). | `declare -a notas=(7 5 9)` |
| `declare -A` | *Array* associatiu (diccionari). | `declare -A capital` |
| `declare -r` | Constant (només lectura); equival a `readonly`. | `declare -r PI=3` |
| `declare -x` | Variable d'entorn; equival a `export`. | `declare -x EDITOR=nano` |
| `declare -l` / `-u` | Converteix el valor a minúscules / majúscules en assignar-lo. | `declare -u siglas=dam` → `DAM` |

```bash
declare -i contador=10
contador=contador+5        # Com que és enter, es calcula: 15
echo "$contador"           # 15
contador="hola"            # Un text no numèric val 0 en un enter
echo "$contador"           # 0

declare -p contador        # Mostra com està declarada: declare -i contador="0"
```

Els *arrays* s'estudien en l'apartat 10. Bash **no** té tipus decimal ni booleà: els decimals es calculen amb eines externes (apartat 6.5) i els valors lògics es representen amb codis d'eixida (apartat 7).

## 6.2 Cometes

Les cometes són una de les fonts d'errors més habituals en Bash. Convé tindre clares les diferències:

| Escriptura | Comportament | Exemple | Resultat |
| --- | --- | --- | --- |
| `"…"` (dobles) | Agrupen en **un sol argument** i **sí** que substitueixen `$variables` i `$(ordres)`. | `echo "Hola $USER"` | `Hola alumno` |
| `'…'` (simples) | Agrupen i **no** substitueixen res: text literal. | `echo 'Hola $USER'` | `Hola $USER` |
| `\` (barra invertida) | Escapa (lleva el significat especial de) el caràcter següent. | `echo "Preu: \$5"` | `Preu: $5` |
| Sense cometes | La shell **divideix** el valor pels espais i **expandeix** els comodins. | `echo $var` | Imprevisible |

Per què és tan important posar les variables entre cometes? Observa aquest exemple:

```bash
fichero="mis notas.txt"
touch "$fichero"     # Crea UN fitxer anomenat "mis notas.txt"
rm $fichero          # Intenta esborrar DOS fitxers: "mis" i "notas.txt"!
rm "$fichero"        # Correcte
```

> [!IMPORTANT]
> Regla d'or: **posa sempre les variables entre cometes dobles** (`"$var"`), excepte si saps exactament per què no fer-ho.

## 6.3 Variables d'entorn

Les **variables d'entorn** les defineix el sistema o l'usuari i les hereten tots els programes que s'executen des de la shell.

| Variable | Contingut |
| --- | --- |
| `HOME` | Directori personal de l'usuari. |
| `USER` | Nom de l'usuari. |
| `PWD` | Directori actual. |
| `PATH` | Directoris on es busquen les ordres, separats per `:`. |
| `SHELL` | Shell per defecte de l'usuari. |
| `HOSTNAME` | Nom de l'equip. |
| `LANG` | Idioma i configuració regional. |
| `RANDOM` | Un número aleatori entre 0 i 32767 cada vegada que es consulta. |

```bash
env                          # Llista les variables d'entorn
echo "$PATH"
export EDITOR=nano           # Crea una variable d'entorn (l'heretaran els processos fills)
export PATH="$PATH:$HOME/herramientas"   # Afig un directori al PATH
```

Una variable creada sense `export` només existeix en la shell actual; els scripts i programes que llancem no la veuran. Perquè una variable o un `alias` es definisquen en totes les sessions, s'afigen al fitxer `~/.bashrc`.

## 6.4 Substitució d'ordres

`$(ordre)` executa l'ordre i se substitueix per **el que aquesta escriu en l'eixida estàndard**. Així podem guardar el resultat de qualsevol ordre en una variable:

```bash
hoy=$(date +%F)
num_usuarios=$(wc -l < /etc/passwd)
kernel=$(uname -r)
echo "El $hoy hi ha $num_usuarios usuaris i el kernel és $kernel"
```

> [!NOTE]
> Trobaràs en scripts antics la forma amb accents greus: `` hoy=`date +%F` ``. Funciona igual, però `$(…)` és més llegible i es pot niar sense problemes: `$(basename "$(pwd)")`. Utilitza sempre `$(…)`.

## 6.5 Aritmètica

Com que les variables són text, Bash necessita una sintaxi especial per a fer càlculs. La forma recomanada és l'**expansió aritmètica** `$(( ))`:

```bash
a=17
b=5
echo "Suma: $(( a + b ))"            # 22  (dins de (( )) no cal el $)
echo "Resta: $(( a - b ))"           # 12
echo "Producte: $(( a * b ))"        # 85
echo "Quocient: $(( a / b ))"        # 3   -> divisió ENTERA!
echo "Residu: $(( a % b ))"          # 2
echo "Potència: $(( 2 ** 10 ))"      # 1024

total=$(( (a + b) * 2 ))             # Parèntesis per a la precedència
(( contador = 0 ))                   # (( )) avalua sense retornar el valor
(( contador++ ))                     # Increment: contador val 1
(( contador += 5 ))                  # contador val 6
let "contador = contador * 2"        # let és equivalent a (( ))
```

| Operador | Significat | | Operador | Significat |
| --- | --- | --- | --- | --- |
| `+ - * /` | Suma, resta, producte, quocient enter | | `++ --` | Increment, decrement |
| `%` | Residu de la divisió | | `+= -= *= /=` | Operació i assignació |
| `**` | Potència | | `< > <= >= == !=` | Comparacions (retornen 1 o 0) |

> [!NOTE]
> `(( ))` també retorna un codi d'eixida: `0` (cert) si el resultat és distint de zero i `1` (fals) si és zero. Per això `(( contador++ ))` amb `contador=0` "falla" i, amb `set -e`, aturaria l'script. Si utilitzes el mode estricte, incrementa amb `contador=$(( contador + 1 ))`.

Bash **només treballa amb enters**. Per a decimals cal recórrer a una altra eina, com `awk` o `bc` (aquest últim pot requerir `sudo apt install bc`):

```bash
awk "BEGIN { printf \"%.2f\n\", 17 / 5 }"   # 3.40
echo "scale=2; 17 / 5" | bc                 # 3.40
```

> [!WARNING]
> En apunts antics apareixen `expr 3 + 2` i `$[ 3 + 2 ]`. `expr` és un programa extern, lent i incòmode (exigeix espais i escapar l'`*`: `expr 3 \* 2`), i `$[ ]` és una sintaxi **obsoleta** que pot desaparéixer. Utilitza sempre `$(( ))`.

## 6.6 Paràmetres d'un script

Igual que `ls -l /etc` rep una opció i un argument, els nostres scripts poden rebre **paràmetres** des de la línia d'ordres. Dins de l'script es consulten amb aquestes **variables especials**:

| Variable | Contingut |
| --- | --- |
| `$0` | Nom amb què s'ha invocat l'script. |
| `$1`, `$2`, … `$9` | Primer, segon… nové paràmetre. A partir del desé: `${10}`, `${11}`… |
| `$#` | **Nombre** de paràmetres rebuts. |
| `"$@"` | Tots els paràmetres, **cadascun com un element independent**. És la forma correcta de recórrer-los. |
| `"$*"` | Tots els paràmetres units en **una sola cadena**. |
| `$?` | Codi d'eixida de l'última ordre. |
| `$$` | PID del mateix script. |
| `$!` | PID de l'últim procés llançat en segon pla. |

```bash
#!/bin/bash
# parametros.sh - Mostra els paràmetres rebuts
echo "Script:        $0"
echo "Núm. paràm.:   $#"
echo "Primer:        $1"
echo "Segon:         $2"
echo "Tots:          $*"
```

```text
$ ./parametros.sh hola "bon dia" 42
Script:        ./parametros.sh
Núm. paràm.:   3
Primer:        hola
Segon:         bon dia
Tots:          hola bon dia 42
```

Fixa't que `"bon dia"` arriba com a **un únic** paràmetre gràcies a les cometes.

### Desplaçar paràmetres: `shift`

`shift` descarta `$1` i desplaça la resta una posició: `$2` passa a ser `$1`, `$3` passa a ser `$2`, i `$#` disminueix en u. És útil per a processar els paràmetres d'un en un:

```bash
#!/bin/bash
echo "Primer: $1 (n'hi ha $#)"
shift
echo "Ara el primer és: $1 (en queden $#)"
```

### Valors per defecte

```bash
destino=${1:-/tmp}       # Si no es passa $1 (o està buit), s'utilitza /tmp
nombre=${2:-"convidat"}
fichero=${1:?"Falta el nom del fitxer"}   # Si falta $1, mostra l'error i acaba
```

## 6.7 Entrada de dades: `read`

`read` atura l'script fins que l'usuari escriu una línia i prem Intro, i guarda el que s'ha escrit en una o diverses variables.

| Opció | Efecte |
| --- | --- |
| `-p "text"` | Mostra un missatge (*prompt*) abans de llegir. |
| `-r` | No interpreta les barres invertides `\` (recomanat **sempre**). |
| `-s` | No mostra el que s'escriu (contrasenyes). |
| `-n N` | Acaba després de llegir N caràcters, sense esperar Intro. |
| `-t N` | Espera com a màxim N segons. |
| `-a array` | Guarda cada paraula en un element d'un *array* (apartat 10). |

```bash
#!/bin/bash
read -rp "Com et diuen? " nombre
read -rp "Quants anys tens? " edad
echo "Hola, $nombre. D'ací a 10 anys en tindràs $(( edad + 10 ))."

read -rsp "Contrasenya: " clave
echo                                  # Salt de línia (amb -s no es mostra l'Intro)
echo "La contrasenya té ${#clave} caràcters."   # ${#var} = longitud

read -rp "Nom i cognom: " nom ape     # La primera paraula va a nom, la resta a ape
read -rn 1 -p "Continuar? (s/n) " resp
echo
```

## 6.8 Eixida de dades: `echo` i `printf`

`echo` és suficient per a missatges senzills:

```bash
echo "Text amb salt de línia al final"
echo -n "Sense salt de línia: "
echo -e "Tabulador:\tfi\nLínia nova"     # -e interpreta \t, \n…
```

`printf` permet controlar el **format** (amplària de columnes, decimals…) de manera precisa i es comporta igual en tots els sistemes. Rep una cadena de format i els valors:

| Format | Significat |
| --- | --- |
| `%s` | Cadena. |
| `%d` | Número enter. |
| `%f` / `%.2f` | Número decimal / amb dos decimals. |
| `%10s` / `%-10s` | Cadena alineada a la dreta / esquerra en 10 caràcters. |
| `%05d` | Enter de 5 xifres emplenat amb zeros. |
| `\n`, `\t` | Salt de línia, tabulador (`printf` **no** afig el salt final automàticament). |

```bash
printf "%-10s %5s\n" "Alumne" "Nota"
printf "%-10s %5.1f\n" "Ana" 8.75 "Luis" 6.5   # El format es reutilitza per a cada parella
printf "Fichero_%03d.txt\n" 7                   # Fichero_007.txt
```

```text
Alumne      Nota
Ana          8.8
Luis         6.5
Fichero_007.txt
```

### Exercici 6.1. Calculadora de dos números

Script que reba dos números enters **com a paràmetres** i en mostre la suma, la resta, el producte, el quocient i el residu. Si no rep exactament dos paràmetres, ha de mostrar com s'utilitza i acabar amb codi 1.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# calculadora.sh - Operacions bàsiques amb dos enters
# Ús: ./calculadora.sh <num1> <num2>

if [[ $# -ne 2 ]]; then              # Les condicions s'expliquen en l'apartat 7
    echo "Ús: $0 <num1> <num2>" >&2
    exit 1
fi

a=$1
b=$2

echo "$a + $b = $(( a + b ))"
echo "$a - $b = $(( a - b ))"
echo "$a * $b = $(( a * b ))"
echo "$a / $b = $(( a / b ))   (divisió entera)"
echo "$a % $b = $(( a % b ))"
```

```text
$ ./calculadora.sh 17 5
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3   (divisió entera)
17 % 5 = 2
```

Què passa si el segon número és 0 o si es passa una lletra? En l'apartat 7 aprendrem a validar l'entrada; la versió completa està en els [exercicis resolts]({{< relref "/U03/U03.12-Ejercicios-Resueltos-VAL.md" >}}).

### Exercici 6.2. Conversor d'unitats

Script interactiu que demane una quantitat de **segons** i la mostre en hores, minuts i segons. Per exemple, `3725` → `1 h 2 min 5 s`.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# segundos.sh - Converteix segons a h/min/s

read -rp "Introdueix un nombre de segons: " total

horas=$(( total / 3600 ))
minutos=$(( (total % 3600) / 60 ))
segundos=$(( total % 60 ))

echo "$total segons = $horas h $minutos min $segundos s"
printf "Format rellotge: %02d:%02d:%02d\n" "$horas" "$minutos" "$segundos"
```

```text
Introdueix un nombre de segons: 3725
3725 segons = 1 h 2 min 5 s
Format rellotge: 01:02:05
```

### Exercici 6.3. Generador de fitxers de projecte

Script que reba el nom d'un projecte (per defecte, `proyecto`) i cree en el directori actual una carpeta amb aquest nom, els subdirectoris `src`, `docs` i `tests`, i un `README.md` amb el títol del projecte, l'autor (l'usuari actual) i la data.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# nuevo_proyecto.sh - Crea l'esquelet d'un projecte
# Ús: ./nuevo_proyecto.sh [nom]

nombre=${1:-proyecto}

mkdir -p "$nombre"/{src,docs,tests}

cat > "$nombre/README.md" <<EOF
# $nombre

- Autor: $USER
- Data de creació: $(date +%F)

## Descripció

Escriu ací la descripció del projecte.
EOF

echo "Projecte '$nombre' creat:"
ls -R "$nombre"
```

### Exercici 6.4. `"$@"` enfront de `"$*"`

Executa aquest script com `./comillas.sh u "dos tres" quatre` i explica la diferència entre els dos bucles (el bucle `for` s'explica en l'apartat 8: repeteix l'ordre `echo` per a cada element).

```bash
#!/bin/bash
echo 'Amb "$@":'
for p in "$@"; do echo "  [$p]"; done
echo 'Amb "$*":'
for p in "$*"; do echo "  [$p]"; done
```

{{% details "Veure solució" %}}
```text
Amb "$@":
  [u]
  [dos tres]
  [quatre]
Amb "$*":
  [u dos tres quatre]
```

`"$@"` manté **cada paràmetre per separat**, respectant que `"dos tres"` és un de sol. `"$*"` els **uneix** tots en una única cadena. Per això, per a recórrer o reenviar els paràmetres a una altra ordre, s'utilitza sempre `"$@"`.
{{% /details %}}
