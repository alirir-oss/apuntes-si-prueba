# 9. Funcions

## 9.1 Per a què serveixen?

Una **funció** és un bloc d'ordres amb nom que es pot executar (**cridar**) tantes vegades com es vulga. Les funcions permeten:

- **No repetir codi**: si una tasca es fa en diversos llocs, s'escriu una vegada.
- **Dividir** un script llarg en peces xicotetes, cadascuna amb una responsabilitat clara.
- **Donar nom** a les operacions, cosa que fa que el programa principal es llija quasi com un text: `comprobar_argumentos`, `crear_copia`, `enviar_informe`.

## 9.2 Definir i cridar una funció

```bash
nom_funcio() {
    ordres
}
```

També hi ha la forma `function nom_funcio { … }`, pròpia de Bash. Totes dues són equivalents; la primera és l'estàndard i la que utilitzarem.

Per a **cridar** la funció s'escriu el seu nom com si fora una ordre més. La funció ha d'estar **definida abans** de cridar-la; per això les funcions es col·loquen al principi de l'script.

```bash
#!/bin/bash
separador() {
    echo "----------------------------------------"
}

separador
echo "Informe del sistema"
separador
```

## 9.3 Paràmetres

Les funcions reben paràmetres **igual que un script**: dins de la funció, `$1`, `$2`, `$#` i `"$@"` es refereixen als arguments de la **crida**, no als de l'script.

```bash
#!/bin/bash
saludar() {
    echo "Hola, $1. Tens $2 anys."
}

saludar "Ana" 19        # Hola, Ana. Tens 19 anys.
saludar "Luis" 22       # Hola, Luis. Tens 22 anys.
```

Si la funció necessita els paràmetres de l'script, cal passar-los-hi explícitament: `procesar "$@"`.

## 9.4 Àmbit de les variables: `local`

Per defecte, **totes les variables són globals**: una variable creada o modificada dins d'una funció és visible (i modificable) en tot l'script. Això pot provocar errors difícils de trobar:

```bash
#!/bin/bash
contar_hasta_3() {
    for i in 1 2 3; do echo -n "$i "; done
    echo
}

i=1
while (( i <= 3 )); do
    echo "Volta $i del bucle principal"
    contar_hasta_3      # En acabar, la i global val 3…
    i=$(( i + 1 ))      # …passa a 4 i el bucle principal acaba després d'UNA sola volta
done
```

```text
Volta 1 del bucle principal
1 2 3
```

La solució és declarar les variables internes de la funció amb `local`, que fa que només existisquen dins d'ella:

```bash
contar_hasta_3() {
    local i
    for i in 1 2 3; do echo -n "$i "; done
    echo
}
```

> [!TIP]
> Declara com a `local` **totes** les variables de les teues funcions, excepte si vols modificar a propòsit una variable global. És bona pràctica copiar els paràmetres en variables locals amb noms descriptius: `local fichero=$1 destino=$2`.

## 9.5 Retornar resultats

Una funció de Bash no "retorna" valors com en Java. Hi ha dos mecanismes, amb usos distints:

### 1. Retornar un estat amb `return`

`return N` acaba la funció amb un **codi d'eixida** entre 0 i 255 (igual que `exit` en un script, però sense acabar l'script). S'utilitza per a funcions que responen **sí o no**, i permet utilitzar-les directament com a condició:

```bash
es_entero() {
    [[ $1 =~ ^-?[0-9]+$ ]]      # El codi d'eixida de l'última ordre és el de la funció
}

es_par() {
    if (( $1 % 2 == 0 )); then
        return 0                 # Cert
    else
        return 1                 # Fals
    fi
}

if es_entero "$1" && es_par "$1"; then
    echo "$1 és un enter parell"
fi
```

### 2. Retornar una dada amb `echo`

Per a retornar una **dada** (un text, un número gran, una llista…), la funció l'escriu en l'eixida estàndard i qui la crida la captura amb `$( )`:

```bash
area_rectangulo() {
    local base=$1 altura=$2
    echo $(( base * altura ))
}

extension() {
    echo "${1##*.}"
}

area=$(area_rectangulo 4 5)
echo "L'àrea és $area"                        # L'àrea és 20
echo "Extensió: $(extension informe.pdf)"     # Extensió: pdf
```

> [!WARNING]
> Si utilitzes aquest mecanisme, la funció no ha d'escriure **res més** en l'eixida estàndard, perquè també es capturaria. Els missatges informatius o d'error de la funció han d'anar a l'eixida d'errors: `echo "Calculant…" >&2`.

| Necessite… | Mecanisme | Exemple de crida |
| --- | --- | --- |
| Saber si alguna cosa és certa/falsa o si hi ha hagut error | `return 0` / `return 1` | `if existe_usuario "$u"; then …` |
| Obtindre una dada calculada | `echo dada` | `total=$(sumar 3 4)` |

## 9.6 Biblioteques de funcions: `source`

Les funcions que es reutilitzen en diversos scripts es poden guardar en un fitxer a banda (una **biblioteca**) i carregar-se amb `source` (o la seua abreviatura `.`):

```bash
# lib/utilidades.sh - Funcions comunes (no necessita shebang ni permís d'execució)
error() {
    echo "ERROR: $*" >&2
    exit 1
}

info() {
    echo "[$(date +%T)] $*"
}

confirmar() {
    local resp
    read -rp "$1 (s/n) " resp
    [[ $resp == [sS] ]]
}
```

```bash
#!/bin/bash
# limpiar.sh - Utilitza la biblioteca d'utilitats
# Carrega la biblioteca utilitzant la ruta del mateix script, perquè funcione
# s'execute des d'on s'execute
source "$(dirname "$0")/lib/utilidades.sh"

[[ -d $1 ]] || error "'$1' no és un directori"

if confirmar "Vols esborrar els fitxers .tmp de $1?"; then
    find "$1" -name '*.tmp' -delete
    info "Neteja acabada"
fi
```

## 9.7 Estructura recomanada: la funció `main`

En scripts d'una certa grandària és habitual posar el programa principal en una funció `main`, que es crida en l'última línia. Així l'script es llig de dalt a baix, començant pel més general:

```bash
#!/bin/bash
# plantilla amb main

uso() {
    echo "Ús: $0 <directori>" >&2
    exit 1
}

contar_ficheros() {
    local dir=$1
    find "$dir" -type f | wc -l
}

main() {
    [[ $# -eq 1 ]] || uso
    [[ -d $1 ]] || { echo "No existeix el directori '$1'" >&2; exit 2; }
    echo "El directori $1 conté $(contar_ficheros "$1") fitxers"
}

main "$@"
```

## Exercicis resolts

### Exercici 9.1. Funcions de validació

Escriu les funcions `es_entero`, `es_positivo` i `en_rango` (que rep un número, un mínim i un màxim) i utilitza-les en un script que demane una nota del 0 al 10 fins que el valor siga correcte.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# pedir_nota.sh - Validació amb funcions

es_entero() {
    [[ $1 =~ ^-?[0-9]+$ ]]
}

es_positivo() {
    es_entero "$1" && (( $1 >= 0 ))
}

en_rango() {
    local n=$1 min=$2 max=$3
    es_entero "$n" && (( n >= min && n <= max ))
}

read -rp "Nota (0-10): " nota
until en_rango "$nota" 0 10; do
    echo "La nota ha de ser un enter entre 0 i 10."
    read -rp "Nota (0-10): " nota
done

echo "Nota registrada: $nota"
```

Fixa't que cada funció és una sola condició: el seu codi d'eixida és el de l'última ordre, així que no cal `return`. A més, `es_positivo` i `en_rango` reutilitzen `es_entero`.
{{% /details %}}

### Exercici 9.2. Usuaris reals del sistema

Utilitzant funcions, escriu un script que lliste els usuaris del sistema que corresponen a **persones** (UID ≥ 1000 i distint de 65534, que és l'usuari especial `nobody`), mostrant-ne el nom, el directori personal i si aquest existeix.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# usuarios_reales.sh - Llista els comptes de persones

readonly UID_MIN=1000
readonly UID_NOBODY=65534

# Retorna cert si l'UID correspon a una persona
es_persona() {
    local uid=$1
    (( uid >= UID_MIN && uid != UID_NOBODY ))
}

# Mostra una línia amb la informació de l'usuari
mostrar_usuario() {
    local nombre=$1 home=$2 estado
    if [[ -d $home ]]; then
        estado="existeix"
    else
        estado="NO existeix"
    fi
    printf "%-15s %-25s %s\n" "$nombre" "$home" "$estado"
}

main() {
    printf "%-15s %-25s %s\n" "USUARI" "DIRECTORI" "ESTAT"
    local nombre uid home
    while IFS=: read -r nombre _ uid _ _ home _; do
        if es_persona "$uid"; then
            mostrar_usuario "$nombre" "$home"
        fi
    done < /etc/passwd
}

main
```

Cada funció té una única responsabilitat i rep per paràmetre tot el que necessita: no depén de variables globals amb un nom concret. Això s'anomena **baix acoblament** i fa que les funcions siguen fàcils de provar i de reutilitzar.
{{% /details %}}

### Exercici 9.3. Registre de missatges

Crea una funció `log` que reba un nivell (`INFO`, `AVIS`, `ERROR`) i un missatge, i escriga una línia amb la data i l'hora, el nivell i el missatge, tant en pantalla com en el fitxer indicat per la variable `LOG`. Els missatges de nivell `ERROR` s'han de mostrar per l'eixida d'errors. Prova-la en un script que comprove si existeixen diversos directoris.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# comprobar_dirs.sh - Exemple de funció de registre

LOG="/tmp/comprobar_dirs.log"

log() {
    local nivel=$1
    shift                               # Llevem el nivell; la resta és el missatge
    local linea
    linea="$(date '+%F %T') [$nivel] $*"
    echo "$linea" >> "$LOG"
    if [[ $nivel == "ERROR" ]]; then
        echo "$linea" >&2
    else
        echo "$linea"
    fi
}

log INFO "Inici de la comprovació"
for dir in /etc /var/log /noexiste "$HOME"; do
    if [[ -d $dir ]]; then
        log INFO "El directori $dir existeix"
    else
        log ERROR "No existeix el directori $dir"
    fi
done
log INFO "Fi. Registre guardat en $LOG"
```

`shift` dins d'una funció desplaça els paràmetres **de la funció**, no els de l'script.
