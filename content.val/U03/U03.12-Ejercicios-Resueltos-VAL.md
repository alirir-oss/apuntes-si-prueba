# 12. Exercicis resolts integradors

Aquests exercicis combinen tot el que s'ha vist en la unitat. Abans de mirar la solució, **intenta resoldre'ls tu**: la manera d'aprendre a programar és enfrontar-se als problemes, equivocar-se i corregir.

## Com abordar un problema

> [!TIP]
> 1. **Entén l'enunciat** i escriu un exemple de com s'executarà l'script i què ha de mostrar.
> 2. **Simplifica**: resol primer una versió reduïda del problema (per exemple, amb un nombre fix de dades) i amplia-la després.
> 3. **Prova prompte i sovint**: executa l'script cada vegada que afiges unes poques línies.
> 4. **Fes visible el que passa**: utilitza `echo` de depuració o `bash -x` per a veure els valors reals de les variables.
> 5. **Prova els casos difícils**: sense arguments, amb lletres en lloc de números, amb fitxers que no existeixen, amb noms amb espais…
> 6. **Revisa amb ShellCheck** abans de donar l'script per acabat.

## Exercici 12.1. Calculadora robusta

Escriu `calc.sh`, que reba **tres** paràmetres: un número, un operador i un altre número, i en mostre el resultat. Operadors admesos: `+`, `-`, `x` (producte), `/` (divisió amb dos decimals) i `%` (residu). L'script ha de detectar tots els errors possibles amb missatges clars.

```text
$ ./calc.sh 9 x 3
9 x 3 = 27
$ ./calc.sh 7 / 2
7 / 2 = 3.50
$ ./calc.sh 7 / 0
Error: no es pot dividir entre zero
$ ./calc.sh 7 + a
Error: 'a' no és un número enter
```

**Anàlisi.** Per què `x` i no `*` per a multiplicar? Perquè `*` és un comodí: la shell el substituiria per la llista de fitxers del directori **abans** de cridar l'script (comprova-ho amb `echo *`). Els errors que cal tindre en compte són: nombre de paràmetres incorrecte, operands no numèrics, operador desconegut i divisió o residu entre zero.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# calc.sh - Calculadora d'enters amb validació
# Ús: ./calc.sh <num1> <operador> <num2>   (operadors: + - x / %)

error() {
    echo "Error: $*" >&2
    exit 1
}

es_entero() {
    [[ $1 =~ ^-?[0-9]+$ ]]
}

# --- Validacions ---
(( $# == 3 )) || error "calen 3 paràmetres. Ús: $0 <num1> <+|-|x|/|%> <num2>"

a=$1
op=$2
b=$3

es_entero "$a" || error "'$a' no és un número enter"
es_entero "$b" || error "'$b' no és un número enter"

if [[ $op == "/" || $op == "%" ]] && (( b == 0 )); then
    error "no es pot dividir entre zero"
fi

# --- Càlcul ---
case "$op" in
    +) resultado=$(( a + b )) ;;
    -) resultado=$(( a - b )) ;;
    x) resultado=$(( a * b )) ;;
    /) resultado=$(awk -v a="$a" -v b="$b" 'BEGIN { printf "%.2f", a / b }') ;;
    %) resultado=$(( a % b )) ;;
    *) error "operador '$op' no vàlid (utilitza + - x / %)" ;;
esac

echo "$a $op $b = $resultado"
```
{{% /details %}}

## Exercici 12.2. Estan en ordre?

Escriu `ordenados.sh`, que reba una llista de números i indique si estan en **ordre creixent** (cadascun major o igual que l'anterior). Si no ho estan, ha d'indicar la primera posició en què es trenca l'ordre.

```text
$ ./ordenados.sh 3 10 25 78 99
Estan en ordre
$ ./ordenados.sh 3 10 25 15 99
No estan en ordre: 15 (posició 4) és menor que 25
```

**Anàlisi.** Primer pensa en la versió simplificada amb tres números: `(( $1 <= $2 && $2 <= $3 ))`. Per a generalitzar-la necessitem un bucle que compare **cada número amb l'anterior**, així que guardarem l'anterior en una variable.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# ordenados.sh - Comprova si els paràmetres estan en ordre creixent

(( $# >= 2 )) || { echo "Ús: $0 n1 n2 [n3 …]" >&2; exit 1; }

for n in "$@"; do
    [[ $n =~ ^-?[0-9]+$ ]] || { echo "Error: '$n' no és un enter" >&2; exit 1; }
done

anterior=$1
posicion=1
shift                          # Ja hem guardat el primer; recorrem la resta

for n in "$@"; do
    posicion=$(( posicion + 1 ))
    if (( n < anterior )); then
        echo "No estan en ordre: $n (posició $posicion) és menor que $anterior"
        exit 1
    fi
    anterior=$n
done

echo "Estan en ordre"
```

El codi d'eixida (0 si estan en ordre, 1 si no) permet utilitzar l'script com a condició en altres scripts: `if ./ordenados.sh 1 2 3; then …`.
{{% /details %}}

## Exercici 12.3. Llista capicua

Escriu `capicua.sh`, que indique si la llista de paràmetres és **capicua**, és a dir, si es llig igual en els dos sentits.

```text
$ ./capicua.sh 1 2 3 2 1
És capicua
$ ./capicua.sh ana pepe ana
És capicua
$ ./capicua.sh 1 2 3 1
No és capicua: l'element 2 (2) no coincideix amb el 3 (3)
```

**Anàlisi.** Cal comparar el primer amb l'últim, el segon amb el penúltim… i així fins a la **meitat** de la llista (no té sentit continuar, perquè repetiríem les comparacions). Si guardem els paràmetres en un *array*, podem accedir a qualsevol posició: l'element `i` es compara amb el `n - 1 - i`.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# capicua.sh - Indica si la llista de paràmetres és capicua

(( $# > 0 )) || { echo "Ús: $0 elem1 [elem2 …]" >&2; exit 1; }

lista=("$@")
n=${#lista[@]}

for (( i = 0; i < n / 2; i++ )); do
    j=$(( n - 1 - i ))                       # Posició simètrica
    if [[ ${lista[i]} != "${lista[j]}" ]]; then
        echo "No és capicua: l'element $(( i + 1 )) (${lista[i]}) no coincideix amb el $(( j + 1 )) (${lista[j]})"
        exit 1
    fi
done

echo "És capicua"
```

Amb una llista imparella (per exemple, 5 elements) `n / 2` val 2 (divisió entera): es comparen les posicions 0-4 i 1-3, i l'element central no necessita comparació.
{{% /details %}}

## Exercici 12.4. La mitjana i el valor més pròxim

Escriu `media.sh`, que llija números per teclat, un per línia, fins que l'usuari prema Intro sense escriure res. Aleshores ha de mostrar la mitjana (amb dos decimals) i el número introduït que **més s'hi acosta**. Els valors no numèrics es rebutjaran amb un avís.

```text
$ ./media.sh
Introdueix números (Intro buit per a acabar):
> 4
> 10
> 7
> 1
>
Mitjana: 5.50
Valor més pròxim a la mitjana: 4
```

**Anàlisi.** Cal guardar tots els números (en un *array*), perquè no es pot saber quin és el més pròxim fins a conéixer la mitjana. La distància d'un número a la mitjana és el **valor absolut** de la diferència. Com que Bash no treballa amb decimals, ho farem tot en enters multiplicant per 100.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# media.sh - Mitjana dels números introduïts i valor més pròxim

numeros=()
echo "Introdueix números (Intro buit per a acabar):"

while true; do
    read -rp "> " valor
    [[ -z $valor ]] && break                         # Línia buida: acabem
    if [[ $valor =~ ^-?[0-9]+$ ]]; then
        numeros+=("$valor")
    else
        echo "  '$valor' no és un enter; s'ignora" >&2
    fi
done

cantidad=${#numeros[@]}
(( cantidad > 0 )) || { echo "No s'ha introduït cap número"; exit 1; }

suma=0
for n in "${numeros[@]}"; do
    suma=$(( suma + n ))
done

# Treballem en centèsimes per a no perdre els decimals: 5.50 → 550
media100=$(( suma * 100 / cantidad ))

cercano=${numeros[0]}
mejor_dist=-1
for n in "${numeros[@]}"; do
    dist=$(( n * 100 - media100 ))
    (( dist < 0 )) && dist=$(( -dist ))              # Valor absolut
    if (( mejor_dist < 0 || dist < mejor_dist )); then
        mejor_dist=$dist
        cercano=$n
    fi
done

printf "Mitjana: %s\n" "$(awk -v s="$suma" -v c="$cantidad" 'BEGIN { printf "%.2f", s / c }')"
echo "Valor més pròxim a la mitjana: $cercano"
```

Si dos números estan a la mateixa distància (en l'exemple, 4 i 7 disten 1,5 de 5,5), l'script es queda amb el primer que troba, perquè només actualitza `cercano` quan la distància és **estrictament** menor.
{{% /details %}}

## Exercici 12.5. Editor de fitxers per menú

Escriu `editor.sh`, un script interactiu que treballe sobre un fitxer de text amb aquest menú, que es repeteix fins a triar `q`:

```text
Fitxer actual: notas.txt
1) Triar fitxer
2) Veure contingut (amb números de línia)
3) Buidar el fitxer
4) Afegir una línia al final
5) Esborrar una línia
6) Inserir una línia en una posició
q) Eixir
```

Cada opció s'implementarà en una **funció**. Les opcions 2 a 6 no s'han d'executar si encara no s'ha triat un fitxer, i la 3 ha de demanar confirmació.

**Anàlisi.** L'estructura és la de qualsevol menú: un bucle `while`, `read` per a l'opció i `case` per a cridar la funció corresponent. Per a esborrar o inserir línies utilitzarem `sed -i`:

- `sed -i '5d' fitx` esborra la línia 5.
- `sed -i '5i\text' fitx` insereix `text` abans de la línia 5.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# editor.sh - Editor de fitxers de text mitjançant menú

fichero=""

pausa() {
    read -rp "Prem Intro per a continuar…" _
}

hay_fichero() {
    if [[ -z $fichero ]]; then
        echo "Primer tria un fitxer (opció 1)."
        return 1
    fi
}

num_lineas() {
    wc -l < "$fichero"
}

linea_valida() {                      # Comprova que $1 és un núm. de línia entre 1 i $2
    [[ $1 =~ ^[0-9]+$ ]] && (( $1 >= 1 && $1 <= $2 ))
}

elegir_fichero() {
    read -rp "Nom del fitxer: " nombre
    if [[ -z $nombre ]]; then
        echo "No has escrit cap nom."
    elif [[ -e $nombre && ! -f $nombre ]]; then
        echo "'$nombre' existeix però no és un fitxer normal."
    else
        [[ -e $nombre ]] || { touch "$nombre" && echo "S'ha creat '$nombre'."; }
        fichero=$nombre
    fi
}

ver_contenido() {
    hay_fichero || return
    echo "----- $fichero ($(num_lineas) línies) -----"
    cat -n "$fichero"
    echo "-----"
}

vaciar() {
    hay_fichero || return
    read -rp "Segur que vols buidar '$fichero'? (s/n) " resp
    if [[ $resp == [sS] ]]; then
        : > "$fichero"                # ':' no fa res; la redirecció buida el fitxer
        echo "Fitxer buidat."
    else
        echo "Cancel·lat."
    fi
}

anadir_linea() {
    hay_fichero || return
    read -rp "Text de la línia nova: " texto
    echo "$texto" >> "$fichero"
}

borrar_linea() {
    hay_fichero || return
    local total
    total=$(num_lineas)
    (( total > 0 )) || { echo "El fitxer està buit."; return; }
    read -rp "Número de línia que s'esborrarà (1-$total): " n
    if linea_valida "$n" "$total"; then
        sed -i "${n}d" "$fichero"
        echo "Línia $n esborrada."
    else
        echo "Número de línia no vàlid."
    fi
}

insertar_linea() {
    hay_fichero || return
    local total
    total=$(num_lineas)
    if (( total == 0 )); then          # Fitxer buit: inserir = afegir
        anadir_linea
        return
    fi
    read -rp "Inserir abans de la línia (1-$total): " n
    if linea_valida "$n" "$total"; then
        read -rp "Text: " texto
        sed -i "${n}i\\${texto}" "$fichero"
    else
        echo "Número de línia no vàlid."
    fi
}

mostrar_menu() {
    clear
    echo "Fitxer actual: ${fichero:-(cap)}"
    echo "1) Triar fitxer"
    echo "2) Veure contingut (amb números de línia)"
    echo "3) Buidar el fitxer"
    echo "4) Afegir una línia al final"
    echo "5) Esborrar una línia"
    echo "6) Inserir una línia en una posició"
    echo "q) Eixir"
}

# --- Programa principal ---
while true; do
    mostrar_menu
    read -rn 1 -p "Opció: " opcion
    echo
    case "$opcion" in
        1) elegir_fichero ;;
        2) ver_contenido ;;
        3) vaciar ;;
        4) anadir_linea ;;
        5) borrar_linea ;;
        6) insertar_linea ;;
        q | Q) echo "Adéu!"; break ;;
        *) echo "Opció no vàlida." ;;
    esac
    pausa
done
```

La funció `hay_fichero` retorna 1 si no s'ha triat fitxer; `hay_fichero || return` fa que cada opció acabe en aquest cas sense repetir el missatge en totes les funcions.

> [!NOTE]
> Si el text inserit conté barres invertides `\`, `sed` les interpretarà. Per a un editor "real" caldria escapar-les; ací s'ha preferit mantindre el codi senzill.
{{% /details %}}

## Exercici 12.6. Alta massiva d'usuaris des d'un CSV

El departament t'entrega un fitxer `nuevos.csv` amb els alumnes d'un grup nou. Escriu `alta_usuarios.sh`, que cree un compte per cada línia amb aquestes regles:

- El nom d'usuari és la inicial del nom més el primer cognom, en minúscules i sense accents: *Ana López* → `alopez`.
- Si l'usuari ja existeix, es mostra un avís i es passa al següent.
- Cada usuari s'afig al grup indicat en el CSV (que es crea si no existeix), amb shell Bash i una contrasenya inicial que haurà de canviar en el primer inici de sessió.
- Per seguretat, l'script funciona per defecte en **mode simulació** i només crea els comptes si s'executa amb l'opció `--aplicar` i com a root.

```text
nombre,apellido1,apellido2,grupo
Ana,López,Pérez,dam1a
Íñigo,Martínez,Sanz,dam1a
José María,Gómez,Ruiz,dam1b
```

**Anàlisi.** És un exemple típic d'automatització de tasques d'administració; la gestió d'usuaris s'estudia a fons en la Unitat 4. Les parts són: llegir el CSV botant la capçalera, construir el nom d'usuari manipulant cadenes, comprovar si existeix (`id usuari`), i crear grup i usuari. El mode simulació és una pràctica professional: permet revisar què passarà abans de modificar el sistema.

{{% details "Veure solució" %}}
```bash
#!/bin/bash
#==============================================================
# alta_usuarios.sh - Crea comptes d'usuari a partir d'un CSV
# Ús: alta_usuarios.sh <fitxer.csv> [--aplicar]
# Format CSV: nom,cognom1,cognom2,grup (amb capçalera)
#==============================================================

readonly CLAVE_INICIAL="Canviar.2026"
csv=${1:?"Ús: $0 <fitxer.csv> [--aplicar]"}
aplicar=false
[[ ${2:-} == "--aplicar" ]] && aplicar=true

[[ -r $csv ]] || { echo "Error: no es pot llegir '$csv'" >&2; exit 1; }
if $aplicar && (( EUID != 0 )); then
    echo "Error: per a aplicar els canvis executa l'script amb sudo" >&2
    exit 1
fi
$aplicar || echo "*** MODE SIMULACIÓ: no es modificarà res (utilitza --aplicar) ***"

# Genera el nom d'usuari: inicial + primer cognom, minúscules, sense accents
generar_login() {
    local nombre=$1 apellido=$2
    local login="${nombre:0:1}${apellido}"
    login=${login,,}                                 # Minúscules
    login=${login// /}                               # Sense espais
    echo "$login" | sed 'y/áàéèíïóòúüñç/aaeeiioouunc/'   # Sense accents ni enyes
}

# Executa una ordre o, en simulació, només la mostra
ejecutar() {
    if $aplicar; then
        "$@"
    else
        echo "  [simulació] $*"
    fi
}

creados=0
omitidos=0

while IFS=, read -r nombre ape1 ape2 grupo; do
    [[ -z $nombre ]] && continue                     # Ignora línies buides
    login=$(generar_login "$nombre" "$ape1")

    if id "$login" &> /dev/null; then
        echo "AVÍS: l'usuari '$login' ja existeix; s'omet"
        omitidos=$(( omitidos + 1 ))
        continue
    fi

    echo "Creant '$login' ($nombre $ape1 $ape2) en el grup '$grupo'"
    if ! getent group "$grupo" > /dev/null; then
        ejecutar groupadd "$grupo"
    fi
    ejecutar useradd -m -s /bin/bash -g "$grupo" -c "$nombre $ape1 $ape2" "$login"
    if $aplicar; then
        echo "$login:$CLAVE_INICIAL" | chpasswd      # Assigna la contrasenya inicial
    else
        echo "  [simulació] assignar contrasenya inicial a $login"
    fi
    ejecutar chage -d 0 "$login"                     # Obliga a canviar-la en entrar
    creados=$(( creados + 1 ))
done < <(tail -n +2 "$csv")

echo "Resum: $creados usuari(s) per crear/creats, $omitidos omés/omesos."
```

```text
$ ./alta_usuarios.sh nuevos.csv
*** MODE SIMULACIÓ: no es modificarà res (utilitza --aplicar) ***
Creant 'alopez' (Ana López Pérez) en el grup 'dam1a'
  [simulació] groupadd dam1a
  [simulació] useradd -m -s /bin/bash -g dam1a -c Ana López Pérez alopez
  [simulació] assignar contrasenya inicial a alopez
  [simulació] chage -d 0 alopez
Creant 'imartinez' (Íñigo Martínez Sanz) en el grup 'dam1a'
…
$ sudo ./alta_usuarios.sh nuevos.csv --aplicar
```

Observa que la `Í` majúscula d'*Íñigo* es converteix primer en `í` (amb `,,`) i després en `i` (amb l'ordre `y` de `sed`, que substitueix caràcter a caràcter). No s'utilitza `tr` perquè treballa byte a byte i espatla els caràcters amb accent, que en UTF-8 ocupen dos bytes. Per a provar l'script sense risc, fes-ho en una màquina virtual o en un contenidor: `docker run -it --rm -v "$PWD":/w -w /w ubuntu:latest bash`.

> [!WARNING]
> Una contrasenya inicial comuna només és acceptable si s'obliga a canviar-la en el primer accés (`chage -d 0`) i es comunica per un canal segur. En un entorn real es generaria una contrasenya aleatòria per usuari, per exemple amb `openssl rand -base64 12`.

## Exercici 12.7. Comprovador d'equips de la xarxa

Escriu `comprobar_hosts.sh`, que llija un fitxer amb un equip (nom o IP) per línia, ignorant les línies buides i els comentaris (`#`), i comprove si cadascun respon a `ping`. Ha de mostrar el resultat en colors (verd: respon, roig: no respon), guardar un informe amb data en `informe_hosts_AAAA-MM-DD.txt` i acabar amb un codi igual al nombre d'equips que no responen (màxim 255).

```text
# hosts.txt
8.8.8.8
1.1.1.1
# Equips de l'aula
192.168.1.250
localhost
```

{{% details "Veure solució" %}}
```bash
#!/bin/bash
# comprobar_hosts.sh - Comprova quins equips d'una llista responen a ping
# Ús: ./comprobar_hosts.sh <fitxer_hosts>

readonly VERDE=$'\e[32m' ROJO=$'\e[31m' NORMAL=$'\e[0m'   # Codis de color ANSI

lista=${1:?"Ús: $0 <fitxer_hosts>"}
[[ -r $lista ]] || { echo "No es pot llegir '$lista'" >&2; exit 255; }

informe="informe_hosts_$(date +%F).txt"
caidos=0
total=0

echo "Informe de connectivitat - $(date '+%F %T')" > "$informe"

while IFS= read -r host; do
    host=${host%%#*}             # Elimina el comentari (des de # fins al final)
    host=${host//[[:space:]]/}   # Elimina espais i tabuladors
    [[ -z $host ]] && continue   # Línia buida o només comentari

    total=$(( total + 1 ))
    if ping -c 1 -W 2 "$host" &> /dev/null; then
        echo "${VERDE}[ OK ]${NORMAL} $host"
        echo "OK      $host" >> "$informe"
    else
        echo "${ROJO}[ERROR]${NORMAL} $host"
        echo "ERROR   $host" >> "$informe"
        caidos=$(( caidos + 1 ))
    fi
done < "$lista"

echo "Total: $total, sense resposta: $caidos" | tee -a "$informe"
echo "Informe guardat en $informe"
exit $(( caidos > 255 ? 255 : caidos ))
```

`$'\e[32m'` és una cadena amb un **codi d'escapament ANSI** que el terminal interpreta com "escriu en verd". L'última línia utilitza l'operador ternari de l'aritmètica de Bash (`condició ? valor_si : valor_no`), perquè els codis d'eixida no poden superar 255.
{{% /details %}}

## Exercicis proposats

Aquests exercicis no tenen solució publicada. Resol-los aplicant la metodologia del principi de la pàgina.

1. **Comptador de paraules.** Script que reba un fitxer de text i mostre les 10 paraules més repetides, sense distingir majúscules i sense signes de puntuació. *Pista:* `grep -oE '[[:alpha:]]+'` extrau una paraula per línia.
2. **Neteja de temporals.** Script que esborre d'un directori els fitxers amb una extensió donada i més antics que N dies (tots dos com a paràmetres), amb mode simulació per defecte, i que registre el que s'ha esborrat amb `logger`.
3. **Monitor d'un procés.** Script que comprove cada 30 segons si un procés (nom com a paràmetre) està en execució i, si no ho està, ho registre i el torne a llançar. Acaba en prémer `Ctrl+C` mostrant quantes vegades l'ha rellançat. *Pista:* `trap 'ordre' INT`.
4. **Gestor de notes.** Script amb menú que mantinga un fitxer CSV `alumne,nota` i permeta afegir alumnes, modificar una nota, esborrar un alumne, llistar ordenat per nota i calcular la mitjana.
5. **Informe del sistema en HTML.** Script que genere `informe.html` amb el nom de l'equip, la distribució, el temps encés, la memòria, l'espai en disc i els 5 processos que més CPU consumeixen, utilitzant un *here document*. Programa'l amb `cron` perquè es regenere cada hora.
6. **Còpia incremental.** Modifica el `backup.sh` de l'apartat 11 perquè faça una còpia completa els diumenges i, la resta de dies, només dels fitxers modificats en les últimes 24 hores (`find -newer` o `tar --newer-mtime`).
