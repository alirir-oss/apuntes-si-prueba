# 13. *Scripting* en PowerShell

Els sistemes Windows, molt presents en empreses i en els equips de desenvolupament, també s'administren i s'automatitzen amb scripts. En aquest apartat es presenta la sintaxi bàsica de **PowerShell** i les seues equivalències amb el que has aprés en Bash, perquè pugues treballar amb soltesa en els dos sistemes.

## 1. Scripting en Windows (PowerShell)

### 1.1 Què és PowerShell?

**PowerShell** és la shell de línia d'ordres i el llenguatge de *scripting* de Microsoft per a Windows (també disponible en Linux i macOS). És el successor de l'antic **CMD** (símbol del sistema) i del llenguatge per lots (`.bat`), i està construït sobre **.NET**.

Les seues característiques principals són:

- És **orientat a objectes**: les ordres no retornen text pla, sinó **objectes .NET**, que es poden filtrar, ordenar i encadenar sense analitzar cadenes.
- Disposa d'un **llenguatge de scripting complet**: variables, condicionals, bucles, funcions, gestió d'errors.
- Utilitza **cmdlets** (es pronuncia "command-lets"): ordres amb un format de nom normalitzat.

> [!NOTE]
> Hi conviuen dues versions: **Windows PowerShell 5.1** (`powershell.exe`), inclosa en Windows i que ja només rep correccions, i **PowerShell 7** (`pwsh.exe`), multiplataforma, de codi obert i en desenvolupament actiu. Es recomana instal·lar PowerShell 7 (`winget install --id Microsoft.PowerShell`). Tot el que s'explica en aquest annex funciona en totes dues, excepte si s'indica el contrari.

### 1.2 Cmdlets: format de nom

Els cmdlets segueixen sempre el patró **Verb-Substantiu**, en anglés i en singular:

```powershell
Get-Service     # obtindre serveis
Get-Process     # obtindre processos
Set-Location    # canviar de directori
Copy-Item       # copiar un element
```

Els verbs més habituals: `Get` (consultar), `Set` (modificar), `New` (crear), `Remove` (eliminar), `Copy`, `Move`, `Start`, `Stop`, `Restart`, `Out` (enviar a eixida), `Import`/`Export`.

Els paràmetres s'indiquen amb guió: `-Name`, `-Path`, `-Force`, `-Recurse`, `-ErrorAction`. Molts es poden abreujar: `-Recurse` s'accepta escrivint `-r` si no hi ha ambigüitat.

### 1.3 El sistema d'ajuda

```powershell
Get-Help Get-Process          # ajuda d'un cmdlet
Get-Help Get-Process -Examples  # només exemples
Update-Help                   # actualitza l'ajuda local
Get-Command *service*         # cmdlets que contenen "service"
Get-Member                    # propietats i mètodes dels objectes rebuts
```

### 1.4 Àlies

PowerShell inclou àlies de compatibilitat amb CMD i Linux per als cmdlets més comuns:


| Àlies         | Cmdlet          | Equivalent en CMD/Linux |
| ------------- | --------------- | ------------------------ |
| `ls`, `dir`   | `Get-ChildItem` | `ls`, `dir`              |
| `cd`          | `Set-Location`  | `cd`                     |
| `cp`, `copy`  | `Copy-Item`     | `cp`                     |
| `mv`, `move`  | `Move-Item`     | `mv`                     |
| `rm`, `del`   | `Remove-Item`   | `rm`                     |

Se'n creen de propis amb `New-Alias` i es llisten amb `Get-Alias`.

### 1.5 El pipeline (`|`)

L'operador `|` passa l'eixida d'un cmdlet com a entrada del següent, però **transferint objectes complets**, no text:

```powershell
Get-Process | Where-Object CPU -gt 10 | Sort-Object CPU -Descending
```

Cmdlets d'ús molt freqüent en el pipeline:


| Cmdlet                         | Funció                                   |
| ------------------------------ | ---------------------------------------- |
| `Where-Object`                 | filtra objectes segons una condició      |
| `Sort-Object`                  | ordena                                   |
| `Select-Object`                | selecciona propietats                    |
| `Measure-Object`               | compta, suma, fa la mitjana              |
| `Format-Table` / `Format-List` | dona format de taula o llista a l'eixida |
| `Group-Object`                 | agrupa                                   |
| `ForEach-Object`               | executa un bloc per cada objecte         |


### 1.6 Estructura d'un script

Un script de PowerShell és un fitxer de text amb extensió **`.ps1`**. Exemple mínim:

```powershell
# saludo.ps1
Write-Host "Inici de l'script"
$Nombre = Read-Host "Com et diuen?"
Write-Host "Hola, $Nombre"
```

Elements del llenguatge:

**Variables**: es declaren amb `$`, sense tipus obligatoris:

```powershell
$Nombre = "Mell"
$Numero = 7
$Lista  = @("u", "dos", "tres")       # array
$Tabla  = @{ clau = "valor" }         # taula hash
```

**Condicionals:**

```powershell
if ($Numero -gt 5) {
    Write-Host "Major que cinc"
} elseif ($Numero -eq 5) {
    Write-Host "És cinc"
} else {
    Write-Host "Menor que cinc"
}
```

Operadors de comparació (no s'utilitzen `>`, `<`, `=`): `-eq` (igual), `-ne` (distint), `-gt`/`-lt` (major/menor), `-ge`/`-le` (major o igual/menor o igual), `-like`/`-match` (patrons), `-and`, `-or`, `-not`.

**Bucles:**

```powershell
foreach ($item in $Lista) {
    Write-Host $item
}

for ($i = 0; $i -lt 5; $i++) {
    Write-Host "Volta $i"
}

while ($Numero -lt 10) {
    $Numero++
}
```

**Funcions:**

```powershell
function Saludo {
    param([string]$Nombre)
    Write-Host "Hola, $Nombre"
}
Saludo -Nombre "Mell"
```

**Comentaris:** amb `#` per a una línia i `<# ... #>` per a blocs.

### 1.7 Execució de scripts i política d'execució

Per seguretat, Windows **bloqueja per defecte l'execució de scripts**. La directiva que ho controla es consulta i es canvia amb:

```powershell
Get-ExecutionPolicy                    # consultar (per defecte: Restricted)
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Valors principals: `Restricted` (cap script), `RemoteSigned` (scripts locals sí, descarregats només si estan signats; el més recomanat), `AllSigned` (tots signats) i `Unrestricted` (tots, amb avís).

Per a executar un script des d'una consola:

```powershell
.\saludo.ps1        # en el directori actual
pwsh -File C:\scripts\saludo.ps1      # PowerShell 7 (en 5.1: powershell -File …)
```

Com en Linux, cal indicar la ruta (o que el directori estiga en `$env:Path`).

### 1.8 Paràmetres i entrada de l'usuari

Un script de PowerShell rep paràmetres declarant-los en un bloc `param()` al **principi** del fitxer. A diferència de Bash, els paràmetres tenen **nom** i poden tindre **tipus**, valor per defecte i validacions:

```powershell
# saludar.ps1 - Exemple de paràmetres amb tipus i validació
param(
    [Parameter(Mandatory)]              # Obligatori: si falta, PowerShell el demana
    [string]$Nombre,

    [ValidateRange(1, 10)]              # Només admet valors entre 1 i 10
    [int]$Veces = 1,                    # Valor per defecte

    [switch]$Mayusculas                 # Interruptor: val $true si s'escriu -Mayusculas
)

if ($Mayusculas) { $Nombre = $Nombre.ToUpper() }

for ($i = 1; $i -le $Veces; $i++) {
    Write-Output "Hola, $Nombre ($i/$Veces)"
}
```

```powershell
.\saludar.ps1 -Nombre Ana -Veces 2 -Mayusculas
# Hola, ANA (1/2)
# Hola, ANA (2/2)
.\saludar.ps1 Ana          # Els paràmetres també es poden passar per posició
.\saludar.ps1 -Veces 20    # Error: 20 no està en el rang 1-10
```

| Bash | PowerShell | Significat |
| --- | --- | --- |
| `$1`, `$2`… | `param([string]$Nombre, …)` | Paràmetres de l'script. |
| `$#` | `$args.Count` / `$PSBoundParameters.Count` | Nombre de paràmetres. |
| `"$@"` | `$args` | Paràmetres sense declarar (com a *array*). |
| `${1:-valor}` | `[string]$Nombre = "valor"` | Valor per defecte. |
| `read -rp "Text: " var` | `$var = Read-Host "Text"` | Llegir del teclat. |
| `read -rsp …` | `Read-Host "Clau" -AsSecureString` | Llegir sense mostrar el que s'escriu. |
| `exit 1` | `exit 1` | Acabar amb un codi d'eixida (consultable amb `$LASTEXITCODE`). |

`Read-Host` sempre retorna **text**. Per a operar amb números cal convertir-lo i comprovar que la conversió és possible:

```powershell
$entrada = Read-Host "Introdueix un número enter"
if ($entrada -match '^-?\d+$') {          # -match utilitza expressions regulars
    $numero = [int]$entrada                # Conversió explícita a enter
    Write-Output "El doble és $($numero * 2)"
} else {
    Write-Error "'$entrada' no és un número enter"
    exit 1
}
```

## 3. Ordres de gestió de fitxers

### 3.1 Llistar, copiar, moure i esborrar


| Ordre (cmdlet)                | Funció                              | Exemple                                        |
| ----------------------------- | ----------------------------------- | ---------------------------------------------- |
| `Get-ChildItem` (`ls`, `dir`) | llistar el contingut d'un directori | `Get-ChildItem C:\Users -Recurse`              |
| `Copy-Item` (`cp`)            | copiar fitxers/directoris           | `Copy-Item C:\datos D:\backup -Recurse`        |
| `Move-Item` (`mv`)            | moure o canviar el nom              | `Move-Item viejo.txt nuevo.txt`                |
| `Rename-Item`                 | canviar el nom                      | `Rename-Item informe.docx final.docx`          |
| `Remove-Item` (`rm`, `del`)   | eliminar                            | `Remove-Item .\temp -Recurse -Force`           |
| `New-Item`                    | crear fitxer o directori            | `New-Item -ItemType Directory -Path .\pruebas` |
| `New-Item -ItemType File`     | crear fitxer buit                   | `New-Item -ItemType File -Path .\notas.txt`    |
| `Get-Content` (`cat`)         | llegir un fitxer                    | `Get-Content .\log.txt -Tail 20`               |
| `Set-Content` / `Add-Content` | escriure / afegir a un fitxer       | `Add-Content log.txt "Línia nova"`             |
| `Test-Path`                   | comprovar si existeix una ruta      | `if (Test-Path C:\datos) { ... }`              |
| `Get-ItemProperty`            | propietats d'un fitxer              | `Get-ItemProperty .\notas.txt`                 |


### 3.2 Comodins i filtratge

Els comodins funcionen igual que en Linux: `*` (qualsevol text) i `?` (un caràcter):

```powershell
Get-ChildItem *.txt
Get-ChildItem C:\Users\?ata
Get-ChildItem -Recurse -Filter "*.log" | Where-Object Length -gt 1MB
```

### 3.3 Exemple de script

```powershell
# limpieza.ps1 — esborra fitxers .tmp de més de 7 dies i en deixa registre
$Carpeta = "C:\Users\usuario\AppData\Local\Temp"

Get-ChildItem $Carpeta -Filter *.tmp -Recurse | Where-Object {
    $_.LastWriteTime -lt (Get-Date).AddDays(-7)
} | ForEach-Object {
    Remove-Item $_.FullName -Force
    Add-Content limpieza.log "Esborrat: $($_.Name)"
}
```

La variable automàtica `$_` representa l'objecte actual del pipeline.


Exemple de script que vigila un procés:

```powershell
# vigilar.ps1 — reinicia el navegador si es tanca

    if (-not (Get-Process chrome -ErrorAction SilentlyContinue)) {
        Start-Process chrome
    }
    Start-Sleep -Seconds 10
}
```

## 5. Ordres d'empaquetament i compressió

### 5.1 Compressió amb `Compress-Archive`

PowerShell inclou cmdlets nadius per a treballar amb fitxers **ZIP**:


| Cmdlet             | Funció               | Exemple                                                         |
| ------------------ | -------------------- | --------------------------------------------------------------- |
| `Compress-Archive` | comprimir en .zip    | `Compress-Archive -Path C:\datos -DestinationPath copia.zip`    |
| `Expand-Archive`   | descomprimir un .zip | `Expand-Archive -Path copia.zip -DestinationPath C:\restaurado` |


```powershell
# Comprimir diversos elements en un zip
Compress-Archive -Path .\informes\*, .\facturas\* -DestinationPath backup.zip -Force

# Descomprimir sobreescrivint
Expand-Archive -Path backup.zip -DestinationPath .\restaurado -Force
```

El paràmetre `-Force` sobreescriu la destinació si ja existeix.

### 5.2 Altres eines d'empaquetament


| Eina                                                | Ús                                                                        |
| --------------------------------------------------- | ------------------------------------------------------------------------- |
| `tar`                                               | disponible en Windows 10+ i PowerShell: `tar -czf copia.tar.gz carpeta/`  |
| `MakeCab`                                           | empaquetar en format .cab (heretat de CMD)                                |
| `Expand`                                            | extraure fitxers .cab: `expand fichero.cab -F:* .\salida`                 |
| Gestors de paquets de programari: `winget`, `choco` | instal·lar programes des de la consola: `winget install git`              |


> [!NOTE]
> En Windows/PowerShell el format nadiu de compressió per cmdlet és ZIP; per a `.tar.gz` s'utilitza `tar`, que ja ve inclòs en el sistema.

### 5.3 Script de còpia de seguretat comprimida

```powershell
# backup.ps1 — comprimeix el directori de dades amb la data en el nom
$Origen  = "C:\Users\usuario\Documentos"
$Destino = "D:\Backups"
$Fecha   = Get-Date -Format "yyyyMMdd"

if (-not (Test-Path $Destino)) {
    New-Item -ItemType Directory -Path $Destino | Out-Null
}

Compress-Archive -Path $Origen -DestinationPath "$Destino\copia_$Fecha.zip" -Force
Write-Host "Còpia creada: copia_$Fecha.zip"
```

## Exercicis resolts

### Exercici 13.1. Calculadora amb paràmetres

Escriu `calc.ps1`, que reba dos números (`-A` i `-B`) i una operació (`-Operacion`) que només puga ser `suma`, `resta`, `producto` o `division`, i en mostre el resultat. La divisió entre zero ha de mostrar un error.

{{% details "Veure solució" %}}
```powershell
# calc.ps1 - Calculadora amb paràmetres validats
# Ús: .\calc.ps1 -A 7 -B 2 -Operacion division
param(
    [Parameter(Mandatory)] [double]$A,
    [Parameter(Mandatory)] [double]$B,
    [Parameter(Mandatory)]
    [ValidateSet("suma", "resta", "producto", "division")]   # Valors permesos
    [string]$Operacion
)

switch ($Operacion) {                     # switch equival al case de Bash
    "suma"     { $resultado = $A + $B }
    "resta"    { $resultado = $A - $B }
    "producto" { $resultado = $A * $B }
    "division" {
        if ($B -eq 0) {
            Write-Error "No es pot dividir entre zero"
            exit 1
        }
        $resultado = [math]::Round($A / $B, 2)
    }
}

Write-Output "$A $Operacion $B = $resultado"
```

`[ValidateSet]` fa que PowerShell rebutge qualsevol altra operació i, a més, permet autocompletar-la amb `Tab`. En declarar els números com a `[double]`, PowerShell treballa directament amb decimals, a diferència de Bash.

### Exercici 13.2. Alta massiva d'usuaris locals des d'un CSV

Escriu `alta_usuarios.ps1`, equivalent a l'exercici 12.6 de Bash: a partir d'un CSV amb les columnes `nombre,apellido1,apellido2,grupo`, crea un usuari local per cada línia (inicial del nom + primer cognom, en minúscules i sense accents), l'afig al seu grup (creant-lo si no existeix) i l'obliga a canviar la contrasenya en el primer inici de sessió. Per defecte ha de funcionar en **mode simulació**; només aplicarà els canvis amb l'interruptor `-Aplicar`.

{{% details "Veure solució" %}}
```powershell
# alta_usuarios.ps1 - Crea usuaris locals a partir d'un CSV
# Ús: .\alta_usuarios.ps1 -Csv .\nuevos.csv [-Aplicar]   (consola d'administrador)
param(
    [Parameter(Mandatory)] [string]$Csv,
    [switch]$Aplicar
)

if (-not (Test-Path $Csv)) { Write-Error "No existeix '$Csv'"; exit 1 }
if (-not $Aplicar) { Write-Output "*** MODE SIMULACIÓ: utilitza -Aplicar per a crear els usuaris ***" }

# Lleva accents i dièresis: "Íñigo" -> "Inigo"
function Quitar-Tildes([string]$texto) {
    $descompuesto = $texto.Normalize([Text.NormalizationForm]::FormD)
    return ($descompuesto -replace '\p{Mn}', '')   # \p{Mn}: marques diacrítiques
}

$claveInicial = ConvertTo-SecureString "Canviar.2026" -AsPlainText -Force

foreach ($fila in Import-Csv -Path $Csv -Encoding utf8) {
    $login = Quitar-Tildes(($fila.nombre.Substring(0, 1) + $fila.apellido1) -replace ' ', '')
    $login = $login.ToLower()

    if (Get-LocalUser -Name $login -ErrorAction SilentlyContinue) {
        Write-Warning "L'usuari '$login' ja existeix; s'omet"
        continue
    }

    Write-Output "Creant '$login' ($($fila.nombre) $($fila.apellido1)) en el grup '$($fila.grupo)'"
    if ($Aplicar) {
        if (-not (Get-LocalGroup -Name $fila.grupo -ErrorAction SilentlyContinue)) {
            New-LocalGroup -Name $fila.grupo | Out-Null
        }
        New-LocalUser -Name $login -Password $claveInicial `
            -FullName "$($fila.nombre) $($fila.apellido1) $($fila.apellido2)" | Out-Null
        Add-LocalGroupMember -Group $fila.grupo -Member $login
        net user $login /logonpasswordchg:yes | Out-Null   # Canvi obligatori en entrar
    }
}
```

Compara aquesta solució amb la de Bash: `Import-Csv` converteix cada línia en un **objecte** amb propietats (`$fila.nombre`, `$fila.grupo`), de manera que no cal trossejar el text amb `IFS` ni `cut`. `Write-Warning` i `Write-Error` envien els missatges als seus propis fluxos, com `>&2` en Bash.

### Exercici 13.3. Vigilant d'espai en disc

Escriu `espacio.ps1`, que comprove el percentatge d'ús de totes les unitats locals i, si alguna supera un llindar (paràmetre `-Umbral`, 80 per defecte), escriga un avís en pantalla i en el fitxer `C:\Logs\espacio.log`. Programa'l cada hora amb el Programador de tasques (apartat 11.4).

{{% details "Veure solució" %}}
```powershell
# espacio.ps1 - Avisa si alguna unitat supera el llindar d'ús
param([ValidateRange(1, 100)] [int]$Umbral = 80)

$log = "C:\Logs\espacio.log"
New-Item -ItemType Directory -Path (Split-Path $log) -Force | Out-Null   # Crea C:\Logs si falta

# DriveType = 3: discos locals (exclou USB, xarxa i lectors òptics)
$unidades = Get-CimInstance Win32_LogicalDisk -Filter "DriveType = 3"

foreach ($u in $unidades) {
    $uso = [math]::Round((1 - $u.FreeSpace / $u.Size) * 100)
    $linea = "{0:yyyy-MM-dd HH:mm} {1} al {2} %" -f (Get-Date), $u.DeviceID, $uso   # -f: format
    if ($uso -ge $Umbral) {
        Write-Warning $linea
        Add-Content -Path $log -Value "AVÍS $linea"
    } else {
        Write-Output "OK $linea"
    }
}
```

```powershell
$accion  = New-ScheduledTaskAction -Execute "pwsh.exe" `
             -Argument '-NoProfile -ExecutionPolicy Bypass -File "C:\Scripts\espacio.ps1" -Umbral 85'
$disparo = New-ScheduledTaskTrigger -Once -At (Get-Date) `
             -RepetitionInterval (New-TimeSpan -Hours 1)        # Repetir cada hora
Register-ScheduledTask -TaskName "Vigilant d'espai" -Action $accion -Trigger $disparo
```

L'operador `-f` substitueix `{0}`, `{1}`… pels valors indicats, de manera semblant a `printf` en Bash.
