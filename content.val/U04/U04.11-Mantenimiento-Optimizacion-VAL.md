# 11. Manteniment i optimització

Un sistema acabat d'instal·lar funciona bé, però amb l'ús s'acumulen actualitzacions pendents, fitxers temporals, programes que arranquen sense necessitat i, de vegades, errors en el disc. El **manteniment** és el conjunt de tasques periòdiques que mantenen el sistema **segur, estable i ràpid**. En aquest apartat veuràs les tasques bàsiques i aprendràs a **avaluar** les utilitats que s'utilitzen per a fer-les.

| Tasca | Freqüència orientativa | Objectiu |
| --- | --- | --- |
| Aplicar actualitzacions de seguretat | Automàtica o setmanal | Corregir vulnerabilitats. |
| Alliberar espai en disc | Mensual o en superar un llindar | Evitar que s'ompli el disc. |
| Revisar la salut dels discos | Mensual | Detectar fallades abans de perdre dades. |
| Revisar els programes i serveis d'arrancada | En instal·lar programari | Arrancada ràpida i menys superfície d'atac. |
| Revisar els registres | Setmanal o automatitzada | Detectar errors i accessos sospitosos (apartat 10). |
| Comprovar les còpies de seguretat | Mensual | Assegurar-se que es poden restaurar (Unitat 3). |

## 11.1 Actualitzacions

### Linux

En la Unitat 2 vas veure com funcionen els gestors de paquets. Aquestes són les ordres de manteniment en Debian/Ubuntu:

```bash
sudo apt update                     # Descarrega la llista actualitzada de paquets dels repositoris
apt list --upgradable               # Quins paquets tenen versió nova
sudo apt upgrade                    # Actualitza els paquets sense eliminar-ne cap
sudo apt full-upgrade               # Actualitza encara que calga instal·lar o eliminar dependències
sudo apt autoremove --purge         # Elimina dependències que ja no necessita ningú (i nuclis antics)
sudo apt clean                      # Buida la memòria cau de paquets descarregats (/var/cache/apt/archives)
[ -f /var/run/reboot-required ] && echo "Cal reiniciar"   # Després d'actualitzar el nucli, per exemple
```

Els programes instal·lats amb altres formats s'actualitzen a banda:

```bash
sudo snap refresh                   # Paquets Snap (també s'actualitzen sols diverses vegades al dia)
flatpak update                      # Paquets Flatpak
```

Ubuntu instal·la per defecte **`unattended-upgrades`**, que aplica automàticament les actualitzacions de seguretat cada dia. La seua configuració està en `/etc/apt/apt.conf.d/50unattended-upgrades` i el seu registre en `/var/log/unattended-upgrades/`.

```bash
systemctl status unattended-upgrades
sudo unattended-upgrade --dry-run --debug     # Simulació: què actualitzaria ara
```

### Windows

- **Windows Update** (*Configuració > Windows Update*): actualitzacions de seguretat, de qualitat i de característiques. En *Opcions avançades* es configuren les **hores actives** (en què no es reinicia l'equip) i les actualitzacions d'altres productes de Microsoft.
- **Microsoft Store**: actualitza les aplicacions instal·lades des de la Botiga.
- **winget**, el gestor de paquets de Windows, actualitza moltes aplicacions d'escriptori des de la línia d'ordres:

```powershell
winget upgrade                      # Llista les aplicacions amb versió nova
winget upgrade --all                # Les actualitza totes
winget upgrade --id Git.Git         # Actualitza una de concreta
winget list                         # Programes instal·lats que winget reconeix
```

## 11.2 Alliberar espai en disc

### Localitzar què ocupa espai

En Linux, a més de `du` i `df` (apartat 9), la utilitat **`ncdu`** mostra un navegador interactiu de directoris ordenats per grandària:

```bash
sudo apt install ncdu
ncdu ~                      # Navega amb les fletxes; 'd' esborra, 'q' ix
sudo ncdu -x /              # Tot el sistema d'arxius arrel (-x: sense entrar en altres muntatges)
```

En Windows, **Configuració > Sistema > Emmagatzematge** mostra quant ocupa cada categoria (aplicacions, fitxers temporals, documents…).

### Neteja en Linux

```bash
sudo apt autoremove --purge && sudo apt clean     # Paquets
sudo journalctl --vacuum-time=4weeks              # Registres antics del journal (apartat 10)
rm -rf ~/.cache/thumbnails/*                      # Miniatures d'imatges
du -sh ~/.cache                                   # Revisa la memòria cau del teu usuari
```

Com a desenvolupador, les eines de treball solen ser les que més espai acumulen:

```bash
docker system df                  # Espai que ocupen imatges, contenidors i volums
docker system prune               # Esborra contenidors aturats, xarxes sense ús i imatges òrfenes
find ~ -type d -name node_modules -prune -exec du -sh {} + | sort -h   # Dependències de projectes Node
```

### Neteja en Windows

- **Sensor d'emmagatzematge** (*Configuració > Sistema > Emmagatzematge > Sensor d'emmagatzematge*): esborra automàticament els fitxers temporals i buida la paperera periòdicament.
- **Recomanacions de neteja** (en la mateixa pantalla): fitxers temporals, fitxers grans o no utilitzats, fitxers d'actualitzacions anteriors.
- **Alliberador d'espai en disc** (`cleanmgr`): eina clàssica, encara disponible. Amb el botó *Neteja els fitxers del sistema* inclou restes d'actualitzacions.

```powershell
# Grandària de la carpeta de temporals de l'usuari
"{0:N0} MB" -f ((Get-ChildItem $env:TEMP -Recurse -File -ErrorAction SilentlyContinue |
                 Measure-Object Length -Sum).Sum / 1MB)
```

> [!CAUTION]
> No esborres a mà el contingut de `C:\Windows` (per exemple, `WinSxS` o `Installer`) ni de `/usr` o `/var/lib` en Linux. Per a alliberar espai del sistema, utilitza sempre les eines oficials: el sistema sap què es pot eliminar sense trencar res.

## 11.3 Salut i optimització dels discos

### Estat SMART

Els discos durs i SSD incorporen **SMART** (*Self-Monitoring, Analysis and Reporting Technology*), un sistema que registra indicadors del seu propi estat: sectors reassignats, errors de lectura, hores d'ús, temperatura, desgast en els SSD…

```bash
sudo apt install smartmontools
sudo smartctl -H /dev/sda        # Valoració global: PASSED o FAILED
sudo smartctl -a /dev/sda        # Tots els atributs (en discos NVMe: /dev/nvme0)
```

```powershell
Get-PhysicalDisk | Select-Object FriendlyName, MediaType, HealthStatus, OperationalStatus
Get-PhysicalDisk | Get-StorageReliabilityCounter |
    Select-Object DeviceId, Temperature, Wear, ReadErrorsTotal
```

> [!NOTE]
> En les màquines virtuals, els discos són fitxers de l'amfitrió i normalment **no oferixen dades SMART**. Prova aquestes ordres en un equip físic.

### Comprovar el sistema d'arxius

| Sistema | Eina | Observacions |
| --- | --- | --- |
| Linux (ext4) | `fsck` | El sistema d'arxius ha d'estar **desmuntat**. Per a l'arrel, el sistema el comprova en arrancar si detecta problemes. |
| Windows (NTFS) | `chkdsk` | `chkdsk C: /scan` comprova en línia, sense reiniciar. `chkdsk C: /f` corregix errors (en la unitat del sistema, en reiniciar). |

```bash
sudo umount /dev/sdb1
sudo fsck -f /dev/sdb1           # Comprova i repara una partició de dades
```

### Optimitzar les unitats

- **Discos durs mecànics (HDD)**: amb l'ús, els fitxers es **fragmenten** (els seus trossos queden dispersos pel disc) i l'accés es torna més lent. La **desfragmentació** els reordena.
- **SSD**: no s'han de desfragmentar (no millora el rendiment i augmenta el desgast). En el seu lloc s'utilitza **TRIM**, que informa el SSD de quins blocs ja no s'utilitzen perquè els puga gestionar eficientment.

En Linux, ext4 a penes patix fragmentació, i el TRIM s'executa setmanalment mitjançant un *timer* de systemd:

```bash
systemctl status fstrim.timer
sudo fstrim -av                  # Executa TRIM ara en tots els sistemes d'arxius que l'admeten
```

En Windows, l'eina **Desfragmenta i optimitza les unitats** (`dfrgui`) aplica automàticament desfragmentació o TRIM segons el tipus de disc, de manera programada:

```powershell
Optimize-Volume -DriveLetter C -Analyze -Verbose     # Analitza l'estat
Optimize-Volume -DriveLetter C -ReTrim -Verbose      # TRIM (SSD)
Optimize-Volume -DriveLetter D -Defrag -Verbose      # Desfragmentació (HDD)
```

### Reparar fitxers del sistema de Windows

Si Windows es comporta de manera estranya (errors en obrir eines del sistema, actualitzacions que fallen), es pot comprovar la integritat dels seus fitxers. Executa-ho en aquest ordre, en una consola d'administrador:

```bat
DISM /Online /Cleanup-Image /RestoreHealth   :: Repara la imatge de Windows descarregant el necessari
sfc /scannow                                 :: Comprova i repara els fitxers protegits del sistema
```

## 11.4 Optimitzar l'arrancada

Cada programa o servei que arranca amb el sistema **retarda l'inici**, **consumix memòria** i és una possible **via d'atac**. Convé revisar què s'inicia automàticament.

### Linux

```bash
systemd-analyze                     # Temps total d'arrancada (firmware, carregador, nucli, espai d'usuari)
systemd-analyze blame | head        # Unitats que més tarden a arrancar
systemd-analyze critical-chain      # Cadena de dependències que determina el temps d'arrancada
systemctl list-unit-files --type=service --state=enabled   # Serveis habilitats
```

Si trobes un servei que no necessites (per exemple, un servidor que vas instal·lar per a una pràctica), deshabilita'l: `sudo systemctl disable --now nom`. En l'escriptori, les aplicacions d'inici de sessió es gestionen amb l'aplicació *Aplicacions a l'inici* o en `~/.config/autostart/`.

### Windows

- **Administrador de tasques > Aplicacions d'inici**: llista de programes que s'inicien amb la sessió i el seu **impacte** en l'inici (alt, mitjà, baix). Clic dret > *Deshabilita*.
- **Configuració > Aplicacions > Inici**: la mateixa llista amb interruptors.
- `services.msc`: serveis amb inici automàtic (apartat 8).

```powershell
Get-CimInstance Win32_StartupCommand | Select-Object Name, Command, Location, User
```

## 11.5 Avaluar utilitats de manteniment

El criteri d'avaluació **g** demana no sols instal·lar utilitats, sinó **avaluar-les**. Abans d'instal·lar una eina, i sobretot abans de donar-li privilegis d'administrador, analitza-la amb criteris objectius:

| Criteri | Preguntes |
| --- | --- |
| **Necessitat** | Resol un problema que tinc? El resol ja una eina del sistema? |
| **Origen** | S'instal·la des del repositori oficial de la distribució, `winget` o la Microsoft Store? La seua web és l'oficial? |
| **Llicència** | És programari lliure, gratuït o de pagament? Permet l'ús que li donaré (per exemple, en una empresa)? |
| **Manteniment** | Quan es va publicar l'última versió? Té una comunitat activa? |
| **Privilegis i riscos** | Quins permisos necessita? Què pot esborrar o modificar? Es pot desfer el que fa? |
| **Recursos** | Quanta memòria i CPU consumix? Es queda executant-se en segon pla? |
| **Resultat mesurable** | Puc comprovar, amb dades, que ha millorat alguna cosa (espai alliberat, temps d'arrancada)? |

> [!WARNING]
> Desconfia dels programes que prometen "accelerar el PC", "netejar el registre" o "optimitzar la RAM". Els **netejadors del registre** de Windows no milloren el rendiment de manera apreciable i poden danyar el sistema; Microsoft no els recomana. Molts d'aquests programes, a més, inclouen publicitat o programari no desitjat. Les eines integrades del sistema cobrixen la gran majoria de les necessitats.

Algunes utilitats fiables i habituals que pots avaluar en les pràctiques:

| Utilitat | Sistema | Funció | Llicència |
| --- | --- | --- | --- |
| `htop`, `btop` | Linux | Monitoratge de processos i recursos. | Lliure (GPL / Apache) |
| `ncdu` | Linux | Anàlisi interactiva de l'espai en disc. | Lliure (MIT) |
| `smartmontools` | Linux i Windows | Estat SMART dels discos. | Lliure (GPL) |
| BleachBit | Linux i Windows | Neteja de memòries cau i temporals de moltes aplicacions. | Lliure (GPL) |
| Microsoft PowerToys | Windows | Conjunt d'utilitats oficials (entre aquestes, veure quin procés bloqueja un fitxer). | Lliure (MIT) |
| Sysinternals (Process Explorer, Autoruns…) | Windows | Eines avançades de Microsoft per a analitzar processos i programes d'inici. | Gratuïta (propietària) |
| WinDirStat | Windows | Mapa gràfic del que ocupa el disc. | Lliure (GPL) |

## Exercicis resolts

### Exercici 11.1. Pla de manteniment en Linux

Escriu un script `manteniment.sh` que actualitze els paquets, elimine els que no es necessiten, netege la memòria cau d'`apt` i el *journal* de més de 4 setmanes, mostre l'espai lliure de `/` abans i després, i indique si cal reiniciar. Programa'n l'execució els diumenges a les 3:00.

{{% details "Veure solució" %}}
```bash
#!/usr/bin/env bash
# manteniment.sh - Manteniment setmanal d'un equip Debian/Ubuntu
set -euo pipefail                          # Aturar l'script davant de qualsevol error (Unitat 3)

if [[ $EUID -ne 0 ]]; then                 # EUID: UID efectiu; 0 = root
    echo "Executa aquest script com a root" >&2
    exit 1
fi

lliure() { df -h --output=avail / | tail -n 1; }   # Espai disponible en l'arrel

abans=$(lliure)
export DEBIAN_FRONTEND=noninteractive      # Evita que apt faça preguntes

apt-get update -q
apt-get upgrade -y -q
apt-get autoremove --purge -y -q
apt-get clean
journalctl --vacuum-time=4weeks -q

despres=$(lliure)
logger -t manteniment "Manteniment completat. Lliure en /: abans $abans, després $despres"
echo "Espai lliure en /: abans $abans, després $despres"

if [[ -f /var/run/reboot-required ]]; then
    logger -t manteniment "Cal reiniciar l'equip"
    echo "AVÍS: cal reiniciar"
fi
```

```bash
sudo install -m 750 manteniment.sh /usr/local/sbin/
sudo crontab -e
# 0 3 * * 0 /usr/local/sbin/manteniment.sh
```

En els scripts s'utilitza `apt-get` en lloc d'`apt`, perquè l'eixida d'`apt` està pensada per a persones i pot canviar entre versions (el mateix `apt` ho advertix amb *WARNING: apt does not have a stable CLI interface*).
{{% /details %}}

### Exercici 11.2. Mesurar l'arrancada

En la teua màquina virtual Linux, mesura el temps d'arrancada i identifica les tres unitats que més tarden. Instal·la un servei que no necessites (per exemple, `apache2`), torna a mesurar, deshabilita'l i mesura de nou.

{{% details "Veure solució" %}}
```bash
systemd-analyze
systemd-analyze blame | head -n 3

sudo apt install apache2          # S'habilita i arranca automàticament en instal·lar-lo
sudo reboot
systemd-analyze blame | grep apache2

sudo systemctl disable --now apache2
sudo reboot
systemd-analyze
```

Anota els temps en una taula. La diferència pot ser xicoteta en una màquina virtual amb un disc ràpid, però el procediment és el mateix que se seguix en un servidor real per a decidir quins serveis deshabilitar. Fixa't també que, en Debian/Ubuntu, instal·lar un servei sol **habilitar-lo** automàticament; en altres distribucions, com Fedora, no.
{{% /details %}}

### Exercici 11.3. Avaluar una utilitat

Avalua `ncdu` enfront de `du` per a trobar els directoris que més ocupen en el teu directori personal, aplicant els criteris de l'apartat 11.5. Mesura el temps que tarda cadascun.

{{% details "Veure solució" %}}
```bash
time du -h --max-depth=2 ~ 2>/dev/null | sort -h | tail -n 10
sudo apt install ncdu
time ncdu -o /tmp/ncdu.json ~      # -o: exporta l'anàlisi a un fitxer sense obrir la interfície
ncdu -f /tmp/ncdu.json             # -f: obri l'anàlisi guardada
```

| Criteri | `du` | `ncdu` |
| --- | --- | --- |
| Necessitat | Sempre instal·lat. | Cal instal·lar-lo, però és més còmode per a explorar. |
| Origen | Paquet `coreutils` del sistema. | Repositori oficial de la distribució. |
| Llicència | GPL. | MIT. |
| Privilegis | Cap d'extra. | Cap d'extra; permet esborrar fitxers des de la interfície (precaució). |
| Ús | Ideal per a scripts i informes. | Ideal per a explorar interactivament. |
| Temps | Semblant: tots dos recorren l'arbre complet. | Semblant. |

Conclusió raonada: `du` és l'eina adequada per a automatitzar i `ncdu` per a investigar manualment. No substituïx `du`, el complementa.
{{% /details %}}

### Exercici 11.4. Manteniment en Windows

Amb PowerShell com a administrador: llista les aplicacions que es poden actualitzar amb `winget`, comprova l'estat de salut dels discos, analitza si la unitat `C:` necessita optimització i mostra els programes que s'executen a l'inici.

{{% details "Veure solució" %}}
```powershell
winget upgrade
Get-PhysicalDisk | Select-Object FriendlyName, MediaType, HealthStatus
Optimize-Volume -DriveLetter C -Analyze -Verbose
Get-CimInstance Win32_StartupCommand | Select-Object Name, Command, Location
```

En l'eixida d'`Optimize-Volume -Analyze`, Windows indica el percentatge de fragmentació i si recomana optimitzar. Si `MediaType` és `SSD`, l'optimització consistirà en TRIM, no a desfragmentar.
{{% /details %}}
