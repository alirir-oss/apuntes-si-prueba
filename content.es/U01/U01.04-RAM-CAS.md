# 4. RAM

La memoria RAM (Random Access Memory) es el almacenamiento en donde se cargan todas las instrucciones y tareas que componen los programas y de los que hará uso el procesador. Es un almacenamiento de acceso aleatorio porque es posible leer o escribir un dato en cualquier posición de memoria que haya disponible. Encontramos dos tipos de RAM:

- **DRAM (Dynamic RAM)**: Permite almacenar gran cantidad de datos en un espacio reducido y necesita ser refrescada constantemente. Cuando apagamos el PC, todo lo que en ella se borrará.
- **SRAM (Static RAM)**: No necesita refresco, ya que el bit de información permanece guardado aún sin alimentación. Es más cara de fabricar y requiere más espacio, por lo que son de menor tamaño, por ejemplo, la memoria caché de la CPU.

## 4.1 Diferencias entre SRAM y DRAM

 **Diferencias entre SRAM y DRAM** | **SRAM** | **DRAM** |
 |----------------------------------|----------|----------|
 | **Definición**                   | Memoria Estática de Acceso Aleatorio | Memoria Dinámica de Acceso Aleatorio |
 | **Construcción**                 | Transistores y pestillos para almacenar información | Condensadores para almacenar información a través de la corriente eléctrica |
 | **Precio**                       | Mayor     | Menor     |
 | **Velocidad**                    | Más rápida | Más lenta |
 | **Memoria**                      | Se utiliza para la memoria caché | Se utiliza para la memoria principal |
 | **Capacidad**                    | Menor     | 5 o 10 veces más que SRAM |
 | **Consumo**                      | Menor     | Mayor     |
 | **Tamaño**                       | Mayor     | Menor     |

## 4.3 Evolución a las DDR

DDR o Double Data Rate es la tecnología actual de las memorias RAM. Con ellas se comenzó a utilizar el encapsulado DIMM disponiendo de dos operaciones de datos simultáneas en un mismo ciclo de reloj.

Las primeras versiones DDR llegaron a dar unas velocidades de transferencia desde 200 MHz a 400 MHz. Usaban encapsulado DIMM de 182 contactos a 2,5 V. Es importante diferenciar bien entre frecuencia de bus y frecuencia de transferencia (E/S), ya que al trabajar con dos datos a la vez la frecuencia de transferencia es el doble que la frecuencia del bus. Por ejemplo: una DDR-400 tiene un bus de 200 MHz y una transferencia de 400 MHz.

{{< image src="images/18.png" alt="Description" title="Caption" loading="lazy" >}}

Con las DDR2 se doblaron los bits transferidos en cada operación de 2 a 4, por lo que la frecuencia de transferencia también se duplicó. En encapsulado DIMM pasó a tener 240 contactos a 1,8 V. Las DDR-1200 fueron las más rápidas, con una velocidad de transferencia de 1200 MHz.

La 3ª y 4ª generación, simplemente han sido mejoras respecto a la anterior, con menos voltaje y mayor frecuencia al disminuir el tamaño de los transistores. Al subir la frecuencia, también se sube la latencia. Las DDR3 mantenían un DIMM de 240 pines a 1,5 V, aunque no compatible con las DDR2, mientras que las DDR4 subieron a 288 pines a 1,35 V, llegando actualmente hasta los 4800 o 5000 MHz de transferencia.

### 4.3.1 DDR5

- Se trata del último estándar de memorias para ordenadores de sobremesa, portátiles, servidores y otros tipos de equipos informáticos. **DDR5** aumenta la densidad, el ancho de banda y las frecuencias de trabajo. Esto supone una reducción de los tiempos de acceso a la memoria.
- Integra la tecnología **ECC**: sirve para la detección y corrección de errores en los datos antes de ser suministrados a la CPU. Está integrada en un chip de memoria adicional.

{{< image src="images/20.png" alt="Description" title="Caption" loading="lazy" >}}


#### Características:
- Hasta 64 GB de memoria en un único módulo DDR5 para sistemas de sobremesa (se puede llegar a los 128 GB sin búfer).
- El estándar establece una frecuencia base de 4800 MHz.
- Dispone de dos canales de memoria independientes de 32 bits.
- Trabajan a una tensión base de 1.1 voltios.
- Integran soporte para ECC nativamente.

{{< image src="images/21.png" alt="Description" title="Caption" loading="lazy" >}}

Una de las cosas que realizan los controladores de memoria es adelantarse a las peticiones realizadas por el procesador. Hace referencia al número de datos que se pueden leer a la vez en cuanto a unidades se refiere. Así, 1n ejecutaría una lectura a la unidad de datos, 2n duplicaría esa cifra, etc.


 | **Característica**               | **DDR4**               | **DDR5**               |
 |----------------------------------|------------------------|------------------------|
 | **Publicación estándar**         | 2014                   | 2019                   |
 | **Capacidad máxima UDIMM (sin búfer)** | 32 GB           | 128 GB                 |
 | **Banda ancha**                  | 12.800 - 25.600 MB/s   | 38.400 - 57.600 MB/s   |
 | **Ratio de transferencia**        | 1.600 - 3.200 MT/s     | 4.800 - 7200 MT/s      |
 | **Frecuencia básica**            | 800 - 1.600 MHz        | 2.400 - 3.600 MHz      |
 | **Frecuencia efectiva**          | 1.600 - 3.200 MHz      | 4.800 - 7.200 MHz      |
 | **Voltaje**                      | 1.2 V                  | 1.1 V                  |
 | **Prefetch**                     | 8n                     | 8n / 16n               |
 | **ECC en matriz**                | No                     | Sí                     |



## 4.4 Formato

Como cualquier estándar de memoria RAM comercial, está disponible en dos formatos. DDR5 tendrá un formato DIMM y un formato SO-DIMM.

La diferencia está en la longitud del propio módulo de memoria RAM DDR5. El formato DIMM es el usado en ordenadores de sobremesa y el formato SO-DIMM es el usado para portátiles.

## 4.6 ¿Qué placas base soporta DDR5?

Lo más importante es saber el tipo de socket, también llamado zócalo. Es este elemento de la arquitectura de las placas base el que marca si se deben adquirir memorias RAM del tipo DDR4 o DDR5, entre otras cosas. Destacamos los 3 sockets que soporta DDR5:

- **LGA 1700**: Compatible con DDR4 y DDR5.
- **LGA 1851**: Compatible solo con DDR5.
- **AM5**: Compatible solo con DDR5.

A la hora de comprar una tarjeta RAM, debemos fijarnos en estos detalles:

- **Frecuencia (MHz)**: Cuanta más frecuencia, más potencia tendrá.
- **Latencia (CL)**: A mayor latencia, mayor tiempo para transmitir información almacenada.
- **Capacidad (GB)**: Cantidad de memoria que puede almacenar.
- **Voltaje (V)**: Gasto de energía que consumen.

## 4.8 Perfil XMP y EXPO

- **Perfil XMP 3.0 (INTEL) o AMD EXPO (EXtended Profiles for Overclocking)**:
  Se ha desarrollado un nuevo perfil XMP para ofrecer un mejor soporte al overclocking a la RAM. Esta nueva característica permite almacenar hasta 5 perfiles XMP, de los cuales 3 vendrían dados por el fabricante y 2 serían personalizados.

- **Dynamic Memory Boost**:
  Nos permite hacer overclocking a la memoria DDR5 sin necesidad de ir a la BIOS, podemos hacerlo desde Windows. Además, agrega la función de aumento de la frecuencia automática según la carga y la demanda.
