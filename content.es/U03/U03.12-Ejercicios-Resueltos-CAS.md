# 12. Ejercicios resueltos integradores

Estos ejercicios combinan todo lo visto en la unidad. Antes de mirar la solución, **intenta resolverlos tú**: la forma de aprender a programar es enfrentarse a los problemas, equivocarse y corregir.

## Cómo abordar un problema

> [!TIP]
> 1. **Entiende el enunciado** y escribe un ejemplo de cómo se ejecutará el script y qué debe mostrar.
> 2. **Simplifica**: resuelve primero una versión reducida del problema (por ejemplo, con un número fijo de datos) y amplíala después.
> 3. **Prueba pronto y a menudo**: ejecuta el script cada vez que añadas unas pocas líneas.
> 4. **Haz visible lo que ocurre**: usa `echo` de depuración o `bash -x` para ver los valores reales de las variables.
> 5. **Prueba los casos difíciles**: sin argumentos, con letras en lugar de números, con ficheros que no existen, con nombres con espacios…
> 6. **Revisa con ShellCheck** antes de dar el script por terminado.

## Ejercicio 12.1. Calculadora robusta

Escribe `calc.sh`, que reciba **tres** parámetros: un número, un operador y otro número, y muestre el resultado. Operadores admitidos: `+`, `-`, `x` (producto), `/` (división con dos decimales) y `%` (resto). El script debe detectar todos los errores posibles con mensajes claros.

```text
$ ./calc.sh 9 x 3
9 x 3 = 27
$ ./calc.sh 7 / 2
7 / 2 = 3.50
$ ./calc.sh 7 / 0
Error: no se puede dividir entre cero
$ ./calc.sh 7 + a
Error: 'a' no es un número entero
```

**Análisis.** ¿Por qué `x` y no `*` para multiplicar? Porque `*` es un comodín: la shell lo sustituiría por la lista de ficheros del directorio **antes** de llamar al script (compruébalo con `echo *`). Los errores que hay que contemplar son: número de parámetros incorrecto, operandos no numéricos, operador desconocido y división o resto entre cero.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# calc.sh - Calculadora de enteros con validación
# Uso: ./calc.sh <num1> <operador> <num2>   (operadores: + - x / %)

error() {
    echo "Error: $*" >&2
    exit 1
}

es_entero() {
    [[ $1 =~ ^-?[0-9]+$ ]]
}

# --- Validaciones ---
(( $# == 3 )) || error "se necesitan 3 parámetros. Uso: $0 <num1> <+|-|x|/|%> <num2>"

a=$1
op=$2
b=$3

es_entero "$a" || error "'$a' no es un número entero"
es_entero "$b" || error "'$b' no es un número entero"

if [[ $op == "/" || $op == "%" ]] && (( b == 0 )); then
    error "no se puede dividir entre cero"
fi

# --- Cálculo ---
case "$op" in
    +) resultado=$(( a + b )) ;;
    -) resultado=$(( a - b )) ;;
    x) resultado=$(( a * b )) ;;
    /) resultado=$(awk -v a="$a" -v b="$b" 'BEGIN { printf "%.2f", a / b }') ;;
    %) resultado=$(( a % b )) ;;
    *) error "operador '$op' no válido (usa + - x / %)" ;;
esac

echo "$a $op $b = $resultado"
```
{{% /details %}}

## Ejercicio 12.2. ¿Están en orden?

Escribe `ordenados.sh`, que reciba una lista de números e indique si están en **orden creciente** (cada uno mayor o igual que el anterior). Si no lo están, debe indicar la primera posición en la que se rompe el orden.

```text
$ ./ordenados.sh 3 10 25 78 99
Están en orden
$ ./ordenados.sh 3 10 25 15 99
No están en orden: 15 (posición 4) es menor que 25
```

**Análisis.** Primero piensa en la versión simplificada con tres números: `(( $1 <= $2 && $2 <= $3 ))`. Para generalizarla necesitamos un bucle que compare **cada número con el anterior**, así que guardaremos el anterior en una variable.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# ordenados.sh - Comprueba si los parámetros están en orden creciente

(( $# >= 2 )) || { echo "Uso: $0 n1 n2 [n3 …]" >&2; exit 1; }

for n in "$@"; do
    [[ $n =~ ^-?[0-9]+$ ]] || { echo "Error: '$n' no es un entero" >&2; exit 1; }
done

anterior=$1
posicion=1
shift                          # Ya hemos guardado el primero; recorremos el resto

for n in "$@"; do
    posicion=$(( posicion + 1 ))
    if (( n < anterior )); then
        echo "No están en orden: $n (posición $posicion) es menor que $anterior"
        exit 1
    fi
    anterior=$n
done

echo "Están en orden"
```

El código de salida (0 si están en orden, 1 si no) permite usar el script como condición en otros scripts: `if ./ordenados.sh 1 2 3; then …`.

## Ejercicio 12.3. Lista capicúa

Escribe `capicua.sh`, que indique si la lista de parámetros es **capicúa**, es decir, si se lee igual en los dos sentidos.

```text
$ ./capicua.sh 1 2 3 2 1
Es capicúa
$ ./capicua.sh ana pepe ana
Es capicúa
$ ./capicua.sh 1 2 3 1
No es capicúa: el elemento 2 (2) no coincide con el 3 (3)
```

**Análisis.** Hay que comparar el primero con el último, el segundo con el penúltimo… y así hasta la **mitad** de la lista (no tiene sentido seguir, porque repetiríamos las comparaciones). Si guardamos los parámetros en un *array*, podemos acceder a cualquier posición: el elemento `i` se compara con el `n - 1 - i`.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# capicua.sh - Indica si la lista de parámetros es capicúa

(( $# > 0 )) || { echo "Uso: $0 elem1 [elem2 …]" >&2; exit 1; }

lista=("$@")
n=${#lista[@]}

for (( i = 0; i < n / 2; i++ )); do
    j=$(( n - 1 - i ))                       # Posición simétrica
    if [[ ${lista[i]} != "${lista[j]}" ]]; then
        echo "No es capicúa: el elemento $(( i + 1 )) (${lista[i]}) no coincide con el $(( j + 1 )) (${lista[j]})"
        exit 1
    fi
done

echo "Es capicúa"
```

Con una lista impar (por ejemplo, 5 elementos) `n / 2` vale 2 (división entera): se comparan las posiciones 0-4 y 1-3, y el elemento central no necesita comparación.
{{% /details %}}

## Ejercicio 12.4. La media y el valor más cercano

Escribe `media.sh`, que lea números por teclado, uno por línea, hasta que el usuario pulse Intro sin escribir nada. Entonces debe mostrar la media (con dos decimales) y el número introducido que **más se acerca** a ella. Los valores no numéricos se rechazarán con un aviso.

```text
$ ./media.sh
Introduce números (Intro vacío para terminar):
> 4
> 10
> 7
> 1
>
Media: 5.50
Valor más cercano a la media: 4
```

**Análisis.** Hay que guardar todos los números (en un *array*), porque no se puede saber cuál es el más cercano hasta conocer la media. La distancia de un número a la media es el **valor absoluto** de la diferencia. Como Bash no trabaja con decimales, compararemos las distancias multiplicadas por 100 o usaremos `awk`; aquí lo hacemos todo en enteros multiplicando por 100.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# media.sh - Media de los números introducidos y valor más cercano

numeros=()
echo "Introduce números (Intro vacío para terminar):"

while true; do
    read -rp "> " valor
    [[ -z $valor ]] && break                         # Línea vacía: terminamos
    if [[ $valor =~ ^-?[0-9]+$ ]]; then
        numeros+=("$valor")
    else
        echo "  '$valor' no es un entero; se ignora" >&2
    fi
done

cantidad=${#numeros[@]}
(( cantidad > 0 )) || { echo "No se ha introducido ningún número"; exit 1; }

suma=0
for n in "${numeros[@]}"; do
    suma=$(( suma + n ))
done

# Trabajamos en centésimas para no perder los decimales: 5.50 → 550
media100=$(( suma * 100 / cantidad ))

cercano=${numeros[0]}
mejor_dist=-1
for n in "${numeros[@]}"; do
    dist=$(( n * 100 - media100 ))
    (( dist < 0 )) && dist=$(( -dist ))              # Valor absoluto
    if (( mejor_dist < 0 || dist < mejor_dist )); then
        mejor_dist=$dist
        cercano=$n
    fi
done

printf "Media: %s\n" "$(awk -v s="$suma" -v c="$cantidad" 'BEGIN { printf "%.2f", s / c }')"
echo "Valor más cercano a la media: $cercano"
```

Si dos números están a la misma distancia (en el ejemplo, 4 y 7 distan 1,5 de 5,5), el script se queda con el primero que encuentra, porque solo actualiza `cercano` cuando la distancia es **estrictamente** menor.

## Ejercicio 12.5. Editor de ficheros por menú

Escribe `editor.sh`, un script interactivo que trabaje sobre un fichero de texto con este menú, que se repite hasta elegir `q`:

```text
Fichero actual: notas.txt
1) Elegir fichero
2) Ver contenido (con números de línea)
3) Vaciar el fichero
4) Añadir una línea al final
5) Borrar una línea
6) Insertar una línea en una posición
q) Salir
```

Cada opción se implementará en una **función**. Las opciones 2 a 6 no deben ejecutarse si aún no se ha elegido un fichero, y la 3 debe pedir confirmación.

**Análisis.** La estructura es la de cualquier menú: un bucle `while`, `read` para la opción y `case` para llamar a la función correspondiente. Para borrar o insertar líneas usaremos `sed -i`:

- `sed -i '5d' fich` borra la línea 5.
- `sed -i '5i\texto' fich` inserta `texto` antes de la línea 5.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# editor.sh - Editor de ficheros de texto mediante menú

fichero=""

pausa() {
    read -rp "Pulsa Intro para continuar…" _
}

hay_fichero() {
    if [[ -z $fichero ]]; then
        echo "Primero elige un fichero (opción 1)."
        return 1
    fi
}

num_lineas() {
    wc -l < "$fichero"
}

linea_valida() {                      # Comprueba que $1 es un nº de línea entre 1 y $2
    [[ $1 =~ ^[0-9]+$ ]] && (( $1 >= 1 && $1 <= $2 ))
}

elegir_fichero() {
    read -rp "Nombre del fichero: " nombre
    if [[ -z $nombre ]]; then
        echo "No has escrito ningún nombre."
    elif [[ -e $nombre && ! -f $nombre ]]; then
        echo "'$nombre' existe pero no es un fichero normal."
    else
        [[ -e $nombre ]] || { touch "$nombre" && echo "Se ha creado '$nombre'."; }
        fichero=$nombre
    fi
}

ver_contenido() {
    hay_fichero || return
    echo "----- $fichero ($(num_lineas) líneas) -----"
    cat -n "$fichero"
    echo "-----"
}

vaciar() {
    hay_fichero || return
    read -rp "¿Seguro que quieres vaciar '$fichero'? (s/n) " resp
    if [[ $resp == [sS] ]]; then
        : > "$fichero"                # ':' no hace nada; la redirección vacía el fichero
        echo "Fichero vaciado."
    else
        echo "Cancelado."
    fi
}

anadir_linea() {
    hay_fichero || return
    read -rp "Texto de la nueva línea: " texto
    echo "$texto" >> "$fichero"
}

borrar_linea() {
    hay_fichero || return
    local total
    total=$(num_lineas)
    (( total > 0 )) || { echo "El fichero está vacío."; return; }
    read -rp "Número de línea a borrar (1-$total): " n
    if linea_valida "$n" "$total"; then
        sed -i "${n}d" "$fichero"
        echo "Línea $n borrada."
    else
        echo "Número de línea no válido."
    fi
}

insertar_linea() {
    hay_fichero || return
    local total
    total=$(num_lineas)
    if (( total == 0 )); then          # Fichero vacío: insertar = añadir
        anadir_linea
        return
    fi
    read -rp "Insertar antes de la línea (1-$total): " n
    if linea_valida "$n" "$total"; then
        read -rp "Texto: " texto
        sed -i "${n}i\\${texto}" "$fichero"
    else
        echo "Número de línea no válido."
    fi
}

mostrar_menu() {
    clear
    echo "Fichero actual: ${fichero:-(ninguno)}"
    echo "1) Elegir fichero"
    echo "2) Ver contenido (con números de línea)"
    echo "3) Vaciar el fichero"
    echo "4) Añadir una línea al final"
    echo "5) Borrar una línea"
    echo "6) Insertar una línea en una posición"
    echo "q) Salir"
}

# --- Programa principal ---
while true; do
    mostrar_menu
    read -rn 1 -p "Opción: " opcion
    echo
    case "$opcion" in
        1) elegir_fichero ;;
        2) ver_contenido ;;
        3) vaciar ;;
        4) anadir_linea ;;
        5) borrar_linea ;;
        6) insertar_linea ;;
        q | Q) echo "¡Adiós!"; break ;;
        *) echo "Opción no válida." ;;
    esac
    pausa
done
```

La función `hay_fichero` devuelve 1 si no se ha elegido fichero; `hay_fichero || return` hace que cada opción termine en ese caso sin repetir el mensaje en todas las funciones.

> [!NOTE]
> Si el texto insertado contiene barras invertidas `\`, `sed` las interpretará. Para un editor "real" habría que escaparlas; aquí se ha preferido mantener el código sencillo.
{{% /details %}}

## Ejercicio 12.6. Alta masiva de usuarios desde un CSV

El departamento te entrega un fichero `nuevos.csv` con los alumnos de un nuevo grupo. Escribe `alta_usuarios.sh`, que cree una cuenta por cada línea con estas reglas:

- El nombre de usuario es la inicial del nombre más el primer apellido, en minúsculas y sin tildes: *Ana López* → `alopez`.
- Si el usuario ya existe, se muestra un aviso y se pasa al siguiente.
- Cada usuario se añade al grupo indicado en el CSV (que se crea si no existe), con shell Bash y una contraseña inicial que deberá cambiar en el primer inicio de sesión.
- Por seguridad, el script funciona por defecto en **modo simulación** y solo crea las cuentas si se ejecuta con la opción `--aplicar` y como root.

```text
nombre,apellido1,apellido2,grupo
Ana,López,Pérez,dam1a
Íñigo,Martínez,Sanz,dam1a
José María,Gómez,Ruiz,dam1b
```

**Análisis.** Es un ejemplo típico de automatización de tareas de administración; la gestión de usuarios se estudia a fondo en la Unidad 4. Las partes son: leer el CSV saltando la cabecera, construir el nombre de usuario manipulando cadenas, comprobar si existe (`id usuario`), y crear grupo y usuario. El modo simulación es una práctica profesional: permite revisar qué va a pasar antes de modificar el sistema.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
#==============================================================
# alta_usuarios.sh - Crea cuentas de usuario a partir de un CSV
# Uso: alta_usuarios.sh <fichero.csv> [--aplicar]
# Formato CSV: nombre,apellido1,apellido2,grupo (con cabecera)
#==============================================================

readonly CLAVE_INICIAL="Cambiar.2026"
csv=${1:?"Uso: $0 <fichero.csv> [--aplicar]"}
aplicar=false
[[ ${2:-} == "--aplicar" ]] && aplicar=true

[[ -r $csv ]] || { echo "Error: no se puede leer '$csv'" >&2; exit 1; }
if $aplicar && (( EUID != 0 )); then
    echo "Error: para aplicar los cambios ejecuta el script con sudo" >&2
    exit 1
fi
$aplicar || echo "*** MODO SIMULACIÓN: no se modificará nada (usa --aplicar) ***"

# Genera el nombre de usuario: inicial + primer apellido, minúsculas, sin tildes
generar_login() {
    local nombre=$1 apellido=$2
    local login="${nombre:0:1}${apellido}"
    login=${login,,}                                 # Minúsculas
    login=${login// /}                               # Sin espacios
    echo "$login" | sed 'y/áéíóúüñç/aeiouunc/'       # Sin tildes ni eñes
}

# Ejecuta una orden o, en simulación, solo la muestra
ejecutar() {
    if $aplicar; then
        "$@"
    else
        echo "  [simulación] $*"
    fi
}

creados=0
omitidos=0

while IFS=, read -r nombre ape1 ape2 grupo; do
    [[ -z $nombre ]] && continue                     # Ignora líneas vacías
    login=$(generar_login "$nombre" "$ape1")

    if id "$login" &> /dev/null; then
        echo "AVISO: el usuario '$login' ya existe; se omite"
        omitidos=$(( omitidos + 1 ))
        continue
    fi

    echo "Creando '$login' ($nombre $ape1 $ape2) en el grupo '$grupo'"
    if ! getent group "$grupo" > /dev/null; then
        ejecutar groupadd "$grupo"
    fi
    ejecutar useradd -m -s /bin/bash -g "$grupo" -c "$nombre $ape1 $ape2" "$login"
    if $aplicar; then
        echo "$login:$CLAVE_INICIAL" | chpasswd      # Asigna la contraseña inicial
    else
        echo "  [simulación] asignar contraseña inicial a $login"
    fi
    ejecutar chage -d 0 "$login"                     # Obliga a cambiarla al entrar
    creados=$(( creados + 1 ))
done < <(tail -n +2 "$csv")

echo "Resumen: $creados usuario(s) a crear/creados, $omitidos omitido(s)."
```

```text
$ ./alta_usuarios.sh nuevos.csv
*** MODO SIMULACIÓN: no se modificará nada (usa --aplicar) ***
Creando 'alopez' (Ana López Pérez) en el grupo 'dam1a'
  [simulación] groupadd dam1a
  [simulación] useradd -m -s /bin/bash -g dam1a -c Ana López Pérez alopez
  [simulación] asignar contraseña inicial a alopez
  [simulación] chage -d 0 alopez
Creando 'imartinez' (Íñigo Martínez Sanz) en el grupo 'dam1a'
…
$ sudo ./alta_usuarios.sh nuevos.csv --aplicar
```

Observa que la `Í` mayúscula de *Íñigo* se convierte primero en `í` (con `,,`) y después en `i` (con la orden `y` de `sed`, que sustituye carácter a carácter). No se usa `tr` porque trabaja byte a byte y estropea los caracteres con tilde, que en UTF-8 ocupan dos bytes. Para probar el script sin riesgo, hazlo en una máquina virtual o en un contenedor: `docker run -it --rm -v "$PWD":/w -w /w ubuntu:latest bash`.

> [!WARNING]
> Una contraseña inicial común solo es aceptable si se obliga a cambiarla en el primer acceso (`chage -d 0`) y se comunica por un canal seguro. En un entorno real se generaría una contraseña aleatoria por usuario, por ejemplo con `openssl rand -base64 12`.

## Ejercicio 12.7. Comprobador de equipos de la red

Escribe `comprobar_hosts.sh`, que lea un fichero con un equipo (nombre o IP) por línea, ignorando las líneas vacías y los comentarios (`#`), y compruebe si cada uno responde a `ping`. Debe mostrar el resultado en colores (verde: responde, rojo: no responde), guardar un informe con fecha en `informe_hosts_AAAA-MM-DD.txt` y terminar con un código igual al número de equipos que no responden (máximo 255).

```text
# hosts.txt
8.8.8.8
1.1.1.1
# Equipos del aula
192.168.1.250
localhost
```

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# comprobar_hosts.sh - Comprueba qué equipos de una lista responden a ping
# Uso: ./comprobar_hosts.sh <fichero_hosts>

readonly VERDE=$'\e[32m' ROJO=$'\e[31m' NORMAL=$'\e[0m'   # Códigos de color ANSI

lista=${1:?"Uso: $0 <fichero_hosts>"}
[[ -r $lista ]] || { echo "No se puede leer '$lista'" >&2; exit 255; }

informe="informe_hosts_$(date +%F).txt"
caidos=0
total=0

echo "Informe de conectividad - $(date '+%F %T')" > "$informe"

while IFS= read -r host; do
    host=${host%%#*}             # Elimina el comentario (desde # hasta el final)
    host=${host//[[:space:]]/}   # Elimina espacios y tabuladores
    [[ -z $host ]] && continue   # Línea vacía o solo comentario

    total=$(( total + 1 ))
    if ping -c 1 -W 2 "$host" &> /dev/null; then
        echo "${VERDE}[ OK ]${NORMAL} $host"
        echo "OK      $host" >> "$informe"
    else
        echo "${ROJO}[FALLO]${NORMAL} $host"
        echo "FALLO   $host" >> "$informe"
        caidos=$(( caidos + 1 ))
    fi
done < "$lista"

echo "Total: $total, sin respuesta: $caidos" | tee -a "$informe"
echo "Informe guardado en $informe"
exit $(( caidos > 255 ? 255 : caidos ))
```

`$'\e[32m'` es una cadena con un **código de escape ANSI** que el terminal interpreta como "escribe en verde". La última línea usa el operador ternario de la aritmética de Bash (`condición ? valor_si : valor_no`), porque los códigos de salida no pueden superar 255.
{{% /details %}}

## Ejercicios propuestos

Estos ejercicios no tienen solución publicada. Resuélvelos aplicando la metodología del principio de la página.

1. **Contador de palabras.** Script que reciba un fichero de texto y muestre las 10 palabras más repetidas, sin distinguir mayúsculas y sin signos de puntuación. *Pista:* `grep -oE '[[:alpha:]]+'` extrae una palabra por línea.
2. **Limpieza de temporales.** Script que borre de un directorio los ficheros con una extensión dada y más antiguos que N días (ambos como parámetros), con modo simulación por defecto, y que registre lo borrado con `logger`.
3. **Monitor de un proceso.** Script que compruebe cada 30 segundos si un proceso (nombre como parámetro) está en ejecución y, si no lo está, lo registre y lo vuelva a lanzar. Termina al pulsar `Ctrl+C` mostrando cuántas veces lo ha relanzado. *Pista:* `trap 'orden' INT`.
4. **Gestor de notas.** Script con menú que mantenga un fichero CSV `alumno,nota` y permita añadir alumnos, modificar una nota, borrar un alumno, listar ordenado por nota y calcular la media.
5. **Informe del sistema en HTML.** Script que genere `informe.html` con el nombre del equipo, la distribución, el tiempo encendido, la memoria, el espacio en disco y los 5 procesos que más CPU consumen, usando un *here document*. Prográmalo con `cron` para que se regenere cada hora.
6. **Copia incremental.** Modifica el `backup.sh` del apartado 11 para que haga una copia completa los domingos y, el resto de días, solo de los ficheros modificados en las últimas 24 horas (`find -newer` o `tar --newer-mtime`).
