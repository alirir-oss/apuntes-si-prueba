# 10. Arrays y manipulación de cadenas

## 10.1 *Arrays* indexados

Un ***array*** (vector o lista) es una variable que guarda **varios valores**, cada uno identificado por un **índice** numérico que empieza en **0**.

```bash
# Creación
lenguajes=("Java" "Kotlin" "Python" "Bash")
notas=(7 5 9 6)
vacio=()

# Acceso a un elemento: ¡las llaves son obligatorias!
echo "${lenguajes[0]}"      # Java
echo "${lenguajes[2]}"      # Python
echo "${lenguajes[-1]}"     # Bash (índices negativos: desde el final)

# Modificar y añadir
lenguajes[1]="C#"
lenguajes+=("SQL")          # Añade al final
unset 'lenguajes[0]'        # Elimina un elemento (el índice 0 queda vacío)
```

| Expresión | Resultado |
| --- | --- |
| `"${a[@]}"` | Todos los elementos, cada uno por separado (como `"$@"`). |
| `${#a[@]}` | Número de elementos. |
| `"${!a[@]}"` | Lista de índices. |
| `${#a[i]}` | Longitud del elemento `i`. |
| `"${a[@]:1:2}"` | Dos elementos a partir del índice 1 (un "trozo" del *array*). |

### Recorrer un *array*

```bash
notas=(7 5 9 6)

# Por valores
for nota in "${notas[@]}"; do
    echo "Nota: $nota"
done

# Por índices (cuando necesitamos la posición)
for i in "${!notas[@]}"; do
    echo "Alumno $i: ${notas[i]}"     # Dentro de [ ] no hace falta el $
done

# Con un contador estilo C
for (( i = 0; i < ${#notas[@]}; i++ )); do
    echo "Posición $i → ${notas[i]}"
done
```

### Rellenar un *array*

```bash
# Desde la salida de una orden o un fichero, un elemento por línea
mapfile -t lineas < /etc/hostname
mapfile -t usuarios < <(cut -d: -f1 /etc/passwd)
echo "Hay ${#usuarios[@]} usuarios; el primero es ${usuarios[0]}"

# Desde una cadena, separando por un carácter
ruta="/usr/local/bin"
IFS=/ read -ra partes <<< "$ruta"     # partes=("" "usr" "local" "bin")

# Desde el teclado
read -rap "Escribe varios números separados por espacios: " numeros
echo "Has escrito ${#numeros[@]} números"

# Con ficheros
fotos=(*.jpg)
```

### Pasar un *array* a una función

Las funciones no reciben *arrays* como tales, sino una lista de parámetros. Se expande el *array* en la llamada con `"${a[@]}"` y, dentro de la función, se recupera con `"$@"`:

```bash
media() {
    local suma=0 n
    for n in "$@"; do
        suma=$(( suma + n ))
    done
    echo $(( suma / $# ))
}

notas=(7 5 9 6)
echo "Media entera: $(media "${notas[@]}")"   # Media entera: 6
```

## 10.2 *Arrays* asociativos (ampliación)

En un *array* **asociativo** (diccionario o mapa) los índices son **cadenas** en lugar de números. Hay que declararlos con `declare -A`:

```bash
declare -A capital
capital[España]="Madrid"
capital[Francia]="París"
capital+=([Italia]="Roma")

echo "${capital[Francia]}"                # París
for pais in "${!capital[@]}"; do          # El orden de las claves no está garantizado
    echo "$pais → ${capital[$pais]}"
done

# Contar apariciones: shells usadas en el sistema
declare -A cuenta
while IFS=: read -r _ _ _ _ _ _ shell; do
    cuenta[$shell]=$(( ${cuenta[$shell]:-0} + 1 ))
done < /etc/passwd
for s in "${!cuenta[@]}"; do echo "$s: ${cuenta[$s]}"; done
```

## 10.3 Manipulación de cadenas

Bash dispone de **expansiones de parámetros** que permiten transformar el contenido de una variable sin recurrir a programas externos.

### Longitud y subcadenas

```bash
texto="Sistemas Informáticos"
echo "${#texto}"          # 21  -> longitud
echo "${texto:0:8}"       # Sistemas  -> 8 caracteres desde la posición 0
echo "${texto:9}"         # Informáticos  -> desde la posición 9 hasta el final
echo "${texto: -5}"       # ticos  -> los 5 últimos (¡el espacio antes del - es necesario!)
```

### Eliminar prefijos y sufijos

| Expansión | Elimina… |
| --- | --- |
| `${var#patrón}` | La coincidencia **más corta** del patrón **al principio**. |
| `${var##patrón}` | La coincidencia **más larga** al principio. |
| `${var%patrón}` | La coincidencia **más corta** **al final**. |
| `${var%%patrón}` | La coincidencia **más larga** al final. |

Una regla para recordarlo: en el teclado, `#` está a la izquierda de `%`, igual que el principio está a la izquierda del final.

```bash
ruta="/home/alumno/proyectos/informe.final.pdf"

echo "${ruta##*/}"      # informe.final.pdf      -> nombre del fichero (como basename)
echo "${ruta%/*}"       # /home/alumno/proyectos -> directorio (como dirname)
echo "${ruta##*.}"      # pdf                    -> extensión
fichero=${ruta##*/}
echo "${fichero%.*}"    # informe.final          -> nombre sin la última extensión
echo "${fichero%%.*}"   # informe                -> nombre sin ninguna extensión
```

### Reemplazar

```bash
frase="hola mundo, hola Bash"
echo "${frase/hola/adiós}"     # adiós mundo, hola Bash   -> la primera coincidencia
echo "${frase//hola/adiós}"    # adiós mundo, adiós Bash  -> todas
echo "${frase// /_}"           # hola_mundo,_hola_Bash    -> espacios por guiones bajos
```

### Mayúsculas y minúsculas

```bash
nombre="aNa lÓpez"
echo "${nombre^^}"     # ANA LÓPEZ  -> todo en mayúsculas
echo "${nombre,,}"     # ana lópez  -> todo en minúsculas
echo "${nombre^}"      # ANa lÓpez  -> solo la primera letra en mayúscula
```

### Valores por defecto (recordatorio)

| Expansión | Resultado |
| --- | --- |
| `${var:-valor}` | `valor` si `var` no existe o está vacía (no modifica `var`). |
| `${var:=valor}` | Igual, pero además **asigna** `valor` a `var`. |
| `${var:?mensaje}` | Si `var` no existe o está vacía, muestra `mensaje` y termina el script. |
| `${var:+valor}` | `valor` si `var` **tiene** contenido; vacío en caso contrario. |

## Ejercicios resueltos

### Ejercicio 10.1. Ordenar un vector (método de la burbuja)

Script que guarde en un *array* los números recibidos como parámetros y los ordene de menor a mayor **sin usar `sort`**, implementando el método de la burbuja. Muestra el vector antes y después.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# burbuja.sh - Ordena los parámetros con el método de la burbuja
# Uso: ./burbuja.sh 10 2 32 14 5

(( $# > 0 )) || { echo "Uso: $0 n1 n2 …" >&2; exit 1; }

datos=("$@")
n=${#datos[@]}
echo "Original: ${datos[*]}"

# En cada pasada, el mayor de los no ordenados "sube" hasta su posición final
for (( pasada = 0; pasada < n - 1; pasada++ )); do
    for (( j = 0; j < n - 1 - pasada; j++ )); do
        if (( datos[j] > datos[j + 1] )); then
            # Intercambio usando una variable auxiliar
            aux=${datos[j]}
            datos[j]=${datos[j + 1]}
            datos[j + 1]=$aux
        fi
    done
done

echo "Ordenado: ${datos[*]}"
```

```text
$ ./burbuja.sh 10 2 32 14 5
Original: 10 2 32 14 5
Ordenado: 2 5 10 14 32
```

Este algoritmo lo estudiaréis también en Programación. En un script real usaríamos `printf '%s\n' "${datos[@]}" | sort -n`.

### Ejercicio 10.2. ¿Es un palíndromo?

Script que pida una frase e indique si es un palíndromo (se lee igual al derecho y al revés), sin tener en cuenta los espacios ni las mayúsculas. Por ejemplo: "Anita lava la tina".

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# palindromo.sh - Comprueba si una frase es un palíndromo

read -rp "Escribe una frase: " frase

# Normalizamos: minúsculas y sin espacios
limpia=${frase,,}
limpia=${limpia// /}

# Construimos la cadena invertida carácter a carácter
invertida=""
for (( i = ${#limpia} - 1; i >= 0; i-- )); do
    invertida+=${limpia:i:1}
done

if [[ $limpia == "$invertida" ]]; then
    echo "\"$frase\" es un palíndromo"
else
    echo "\"$frase\" NO es un palíndromo"
fi
```

Para simplificar, el script no elimina las tildes: "Dábale arroz a la zorra el abad" no se detectaría. Se podría mejorar con `sed 'y/áéíóú/aeiou/'`. Existe también la orden `rev`, que invierte una cadena: `invertida=$(rev <<< "$limpia")`.
{{% /details %}}

### Ejercicio 10.3. Ordenar las descargas por tipo

Script que recorra un directorio (por defecto `~/Descargas`) y mueva cada fichero a una subcarpeta con el nombre de su extensión en minúsculas (`pdf/`, `jpg/`, `zip/`…). Los ficheros sin extensión irán a `otros/`. Al final mostrará cuántos ficheros se han movido a cada carpeta. Debe admitir la opción `-n` como primer parámetro para **simular** (mostrar qué haría sin mover nada).

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# ordenar_descargas.sh - Organiza ficheros en carpetas por extensión
# Uso: ./ordenar_descargas.sh [-n] [directorio]
#   -n  Simulación: muestra lo que haría sin mover nada

simular=false
if [[ $1 == "-n" ]]; then
    simular=true
    shift
fi

dir=${1:-$HOME/Descargas}
[[ -d $dir ]] || { echo "Error: '$dir' no es un directorio" >&2; exit 1; }

declare -A movidos            # extensión -> número de ficheros

for ruta in "$dir"/*; do
    [[ -f $ruta ]] || continue          # Solo ficheros (ni directorios ni nada si está vacío)

    nombre=${ruta##*/}
    if [[ $nombre == *.* ]]; then
        ext=${nombre##*.}
        ext=${ext,,}
    else
        ext="otros"                     # Sin extensión
    fi

    if $simular; then
        echo "[simulación] $nombre → $ext/"
    else
        mkdir -p "$dir/$ext"
        mv -n -- "$ruta" "$dir/$ext/"
    fi
    movidos[$ext]=$(( ${movidos[$ext]:-0} + 1 ))
done

echo "--- Resumen ---"
for ext in "${!movidos[@]}"; do
    printf "%-8s %3d fichero(s)\n" "$ext/" "${movidos[$ext]}"
done
```

El comodín `*` no incluye los ficheros ocultos (los que empiezan por punto), así que el script no los mueve. `simular` guarda la palabra `true` o `false`, que también son órdenes (devuelven 0 y 1), por eso `if $simular; then` funciona como una condición.
