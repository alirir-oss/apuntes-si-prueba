# 8. Bucles: repetir acciones

Un **bucle** repite un bloque de órdenes varias veces. Bash ofrece tres: `for` (para cada elemento de una lista), `while` (mientras se cumpla una condición) y `until` (hasta que se cumpla una condición).

## 8.1 El bucle `for` sobre una lista

```bash
for variable in lista de elementos; do
    órdenes que usan "$variable"
done
```

En cada vuelta (**iteración**), la variable toma el valor del siguiente elemento de la lista.

```bash
for fruta in manzana pera "uva blanca"; do
    echo "Me gusta la $fruta"
done
```

La lista puede generarse de muchas formas:

```bash
for i in {1..5}; do echo "Vuelta $i"; done           # Rango con llaves
for i in {0..20..5}; do echo "$i"; done              # 0 5 10 15 20 (con salto)
for i in $(seq 1 2 9); do echo "$i"; done            # 1 3 5 7 9  (seq inicio salto fin)
for fichero in *.txt; do echo "Procesando $fichero"; done   # Ficheros que encajan con el patrón
for usuario in $(cut -d: -f1 /etc/passwd); do echo "$usuario"; done   # Salida de una orden
for param in "$@"; do echo "Parámetro: $param"; done        # Parámetros del script
```

> [!WARNING]
> Si ningún fichero encaja con `*.txt`, Bash deja el patrón **tal cual** y el bucle se ejecuta una vez con la variable valiendo literalmente `*.txt`. Para evitarlo, comprueba que el fichero existe dentro del bucle (`[[ -e $fichero ]] || continue`) o activa `shopt -s nullglob` al principio del script.

> [!NOTE]
> `for x in $(orden)` separa la salida por **espacios y saltos de línea**, así que no es adecuado si los elementos pueden contener espacios (por ejemplo, nombres de fichero). Para recorrer líneas se usa `while read` (apartado 8.4) y para recorrer ficheros, los comodines (`for f in *`).

## 8.2 El bucle `for` de estilo C

Cuando necesitamos un contador numérico, Bash admite la sintaxis de C y Java:

```bash
for (( i = 0; i < 10; i++ )); do
    echo "i vale $i"
done

for (( i = 10; i > 0; i -= 2 )); do echo -n "$i "; done; echo   # 10 8 6 4 2
```

Tiene tres partes: **inicialización** (`i = 0`), **condición** para continuar (`i < 10`) y **actualización** en cada vuelta (`i++`). A diferencia de `{1..n}`, los límites pueden ser variables:

```bash
read -rp "¿Hasta qué número? " n
for (( i = 1; i <= n; i++ )); do echo "$i"; done
```

## 8.3 Los bucles `while` y `until`

`while` repite **mientras** la condición sea verdadera; `until`, **hasta que** lo sea (es decir, mientras sea falsa).

```bash
contador=1
while (( contador <= 5 )); do
    echo "Contador: $contador"
    contador=$(( contador + 1 ))
done

contador=1
until (( contador > 5 )); do        # Mismo resultado con until
    echo "Contador: $contador"
    contador=$(( contador + 1 ))
done
```

`while` es el bucle adecuado cuando **no sabemos cuántas vueltas** se van a dar, por ejemplo, al pedir datos hasta que sean correctos:

```bash
read -rp "Introduce un número positivo: " num
while [[ ! $num =~ ^[0-9]+$ ]]; do
    echo "Valor no válido."
    read -rp "Introduce un número positivo: " num
done
echo "Has introducido $num"
```

O al esperar a que algo ocurra:

```bash
until ping -c 1 -W 1 servidor.local > /dev/null 2>&1; do
    echo "Esperando a que el servidor responda…"
    sleep 5
done
echo "¡Servidor disponible!"
```

Un bucle **infinito** se escribe con `while true` y se abandona con `break` (o `Ctrl+C`):

```bash
while true; do
    read -rp "Escribe 'salir' para terminar: " orden
    [[ $orden == "salir" ]] && break
    echo "Has escrito: $orden"
done
```

## 8.4 Leer un fichero línea a línea

Una de las tareas más frecuentes de los scripts de administración es procesar un fichero de texto línea a línea. La forma correcta es:

```bash
while IFS= read -r linea; do
    echo "Línea: $linea"
done < fichero.txt
```

- `< fichero.txt`, al final del bucle, hace que `read` lea del fichero en lugar del teclado.
- `read` devuelve "falso" cuando llega al final del fichero, y el bucle termina.
- `IFS=` evita que se eliminen los espacios del principio y del final de la línea, y `-r` que se interpreten las barras invertidas.

`IFS` (*Internal Field Separator*) es la variable que indica a `read` qué carácter separa los campos. Si le damos un valor, `read` puede **trocear cada línea** en varias variables. Es ideal para ficheros CSV o para `/etc/passwd`:

```bash
#!/bin/bash
# usuarios.sh - Muestra usuario, UID y shell de cada cuenta
while IFS=: read -r usuario _ uid gid descripcion home shell; do
    echo "$usuario (UID $uid) usa $shell"
done < /etc/passwd
```

El guion bajo `_` es un nombre de variable que, por convenio, indica "este campo no me interesa".

> [!CAUTION]
> Evita escribir `cat fichero | while read …`. La tubería ejecuta el bucle en un **subproceso**, así que las variables que modifiques dentro (contadores, sumas…) **se pierden** al terminar el bucle. Usa siempre la redirección `done < fichero`.

## 8.5 `break` y `continue`

- `break` sale del bucle inmediatamente.
- `continue` abandona la vuelta actual y pasa a la siguiente.

```bash
for n in {1..20}; do
    (( n % 2 == 0 )) && continue   # Salta los pares
    (( n > 11 )) && break          # Termina al pasar de 11
    echo -n "$n "
done
echo                                # 1 3 5 7 9 11
```

## 8.6 Menús interactivos

Combinando `while` y `case` se construyen menús que se repiten hasta que el usuario elige salir. Es un patrón muy habitual en los ejercicios de esta unidad:

```bash
#!/bin/bash
# menu.sh - Menú de información del sistema

while true; do
    echo
    echo "===== MENÚ ====="
    echo "1) Fecha y hora"
    echo "2) Usuarios conectados"
    echo "3) Espacio en disco"
    echo "4) Salir"
    read -rp "Elige una opción: " opcion

    case "$opcion" in
        1) date ;;
        2) who ;;
        3) df -h / ;;
        4) echo "¡Hasta pronto!"; break ;;
        *) echo "Opción no válida" ;;
    esac
done
```

Bash incluye también la orden `select`, que genera automáticamente un menú numerado a partir de una lista:

```bash
PS3="Elige un lenguaje: "            # PS3 es el mensaje que muestra select
select lenguaje in Java Kotlin Python Salir; do
    case "$lenguaje" in
        Salir) break ;;
        "")    echo "Opción no válida" ;;   # Número fuera de rango
        *)     echo "Has elegido $lenguaje" ;;
    esac
done
```

### Ejercicio 8.1. Tabla de multiplicar

Script que reciba un número como parámetro (si no se recibe, lo pide por teclado) y muestre su tabla de multiplicar del 1 al 10 con un formato alineado.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# tabla.sh - Tabla de multiplicar
# Uso: ./tabla.sh [número]

num=$1
while [[ ! $num =~ ^-?[0-9]+$ ]]; do
    read -rp "Introduce un número entero: " num
done

for (( i = 1; i <= 10; i++ )); do
    printf "%3d x %2d = %4d\n" "$num" "$i" $(( num * i ))
done
```

Si `$1` está vacío o no es un número, la condición del `while` es verdadera y se pide el valor hasta que sea correcto.
{{% /details %}}

### Ejercicio 8.2. Suma y media de los parámetros

Script que reciba una cantidad variable de números enteros y muestre cuántos son, su suma, su media (con dos decimales), el mayor y el menor. Los parámetros que no sean números se ignorarán con un aviso.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# estadisticas.sh - Estadísticas de los números recibidos
# Uso: ./estadisticas.sh n1 n2 n3 …

(( $# > 0 )) || { echo "Uso: $0 n1 [n2 …]" >&2; exit 1; }

cantidad=0
suma=0

for n in "$@"; do
    if [[ ! $n =~ ^-?[0-9]+$ ]]; then
        echo "Aviso: se ignora '$n'" >&2
        continue
    fi
    # En la primera vuelta válida, el número es a la vez el mayor y el menor
    if (( cantidad == 0 )); then
        mayor=$n
        menor=$n
    fi
    (( n > mayor )) && mayor=$n
    (( n < menor )) && menor=$n
    suma=$(( suma + n ))
    cantidad=$(( cantidad + 1 ))
done

(( cantidad > 0 )) || { echo "No se ha recibido ningún número válido" >&2; exit 2; }

media=$(awk -v s="$suma" -v c="$cantidad" 'BEGIN { printf "%.2f", s / c }')

echo "Cantidad: $cantidad"
echo "Suma:     $suma"
echo "Media:    $media"
echo "Mayor:    $mayor"
echo "Menor:    $menor"
```

```text
$ ./estadisticas.sh 4 8 hola 15 -3
Aviso: se ignora 'hola'
Cantidad: 4
Suma:     24
Media:    6.00
Mayor:    15
Menor:    -3
```

`awk -v` pasa variables de Bash a `awk`, que sí sabe trabajar con decimales.
{{% /details %}}

### Ejercicio 8.3. Renombrado masivo

Script que añada a todos los ficheros `.jpg` del directorio indicado (por defecto, el actual) un prefijo con la fecha de hoy: `foto.jpg` → `2026-11-08_foto.jpg`. Al final, debe indicar cuántos ficheros ha renombrado.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# prefijo_fecha.sh - Añade la fecha como prefijo a los .jpg
# Uso: ./prefijo_fecha.sh [directorio]

dir=${1:-.}
[[ -d $dir ]] || { echo "Error: '$dir' no es un directorio" >&2; exit 1; }

hoy=$(date +%F)
renombrados=0

for ruta in "$dir"/*.jpg; do
    [[ -e $ruta ]] || continue          # No hay ningún .jpg
    nombre=$(basename "$ruta")          # foto.jpg (sin el directorio)
    [[ $nombre == "${hoy}_"* ]] && continue   # Ya tiene el prefijo: no lo repetimos
    mv -n -- "$ruta" "$dir/${hoy}_$nombre"
    renombrados=$(( renombrados + 1 ))
done

echo "Ficheros renombrados: $renombrados"
```

Para probarlo sin riesgo: `mkdir prueba && touch prueba/{a,b,c}.jpg && ./prefijo_fecha.sh prueba && ls prueba`.
{{% /details %}}

### Ejercicio 8.4. Informe de usuarios desde un CSV

Dado el fichero `alumnos.csv` (créalo con el contenido de abajo), muestra un listado con el formato `APELLIDOS, Nombre (grupo)` y, al final, el número de alumnos de cada grupo. La primera línea es la cabecera y no se debe procesar.

```text
nombre,apellidos,grupo
Ana,López Pérez,DAM1A
Luis,García Ruiz,DAM1B
Marta,Sanz Gil,DAM1A
Pablo,Ortega Martín,DAM1A
```

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# informe_alumnos.sh - Procesa alumnos.csv
fichero=${1:-alumnos.csv}
[[ -r $fichero ]] || { echo "No se puede leer '$fichero'" >&2; exit 1; }

total_a=0
total_b=0

# tail -n +2 muestra el fichero a partir de la línea 2 (sin cabecera).
# < <(orden) es una "sustitución de procesos": el bucle lee la salida de la orden
# sin usar una tubería, así que los contadores no se pierden.
while IFS=, read -r nombre apellidos grupo; do
    echo "${apellidos^^}, $nombre ($grupo)"     # ^^ convierte a mayúsculas
    case "$grupo" in
        DAM1A) total_a=$(( total_a + 1 )) ;;
        DAM1B) total_b=$(( total_b + 1 )) ;;
    esac
done < <(tail -n +2 "$fichero")

echo "---"
echo "DAM1A: $total_a alumnos"
echo "DAM1B: $total_b alumnos"
```

```text
LÓPEZ PÉREZ, Ana (DAM1A)
GARCÍA RUIZ, Luis (DAM1B)
SANZ GIL, Marta (DAM1A)
ORTEGA MARTÍN, Pablo (DAM1A)
---
DAM1A: 3 alumnos
DAM1B: 1 alumnos
```

Si hubiera muchos grupos distintos, sería mejor contarlos con un *array* asociativo (apartado 10) o con `cut -d, -f3 alumnos.csv | tail -n +2 | sort | uniq -c`.

### Ejercicio 8.5. Adivina el número

Juego en el que el script elige un número aleatorio entre 1 y 100 y el usuario tiene 7 intentos para adivinarlo. Tras cada intento, el script indica si el número secreto es mayor o menor.

{{% details "Ver solución" %}}
```bash
#!/bin/bash
# adivina.sh - Juego de adivinar un número
readonly MAX_INTENTOS=7
secreto=$(( RANDOM % 100 + 1 ))     # RANDOM: 0-32767 → % 100: 0-99 → +1: 1-100

for (( intento = 1; intento <= MAX_INTENTOS; intento++ )); do
    read -rp "Intento $intento/$MAX_INTENTOS. Tu número: " n

    if [[ ! $n =~ ^[0-9]+$ ]]; then
        echo "Eso no es un número (el intento cuenta igualmente)."
    elif (( n < secreto )); then
        echo "El número secreto es MAYOR."
    elif (( n > secreto )); then
        echo "El número secreto es MENOR."
    else
        echo "¡Correcto! Lo has adivinado en $intento intentos."
        exit 0
    fi
done

echo "Has agotado los intentos. El número era $secreto."
exit 1
```
