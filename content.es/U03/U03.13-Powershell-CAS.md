# 13. *Scripting* en PowerShell

Los sistemas Windows, muy presentes en empresas y en los equipos de desarrollo, también se administran y automatizan con scripts. En este apartado se presenta la sintaxis básica de **PowerShell** y sus equivalencias con lo aprendido en Bash, para que puedas trabajar con soltura en los dos sistemas.

## 1. Scripting en Windows (PowerShell)

### 1.1 ¿Qué es PowerShell?

**PowerShell** es el shell de línea de comandos y lenguaje de scripting de Microsoft para Windows (también disponible en Linux y macOS). Es el sucesor del antiguo **CMD** (símbolo del sistema) y del lenguaje por lotes (`.bat`), y está construido sobre **.NET**.

Sus características principales son:

- Es **orientado a objetos**: los comandos no devuelven texto plano, sino **objetos .NET**, que se pueden filtrar, ordenar y encadenar sin parsear cadenas.
- Dispone de un **lenguaje de scripting completo**: variables, condicionales, bucles, funciones, gestión de errores.
- Usa **cmdlets** (se pronuncia "command-lets"): comandos con un formato de nombre normalizado.

> [!NOTE]
> Conviven dos versiones: **Windows PowerShell 5.1** (`powershell.exe`), incluida en Windows y que ya solo recibe correcciones, y **PowerShell 7** (`pwsh.exe`), multiplataforma, de código abierto y en desarrollo activo. Se recomienda instalar PowerShell 7 (`winget install --id Microsoft.PowerShell`). Todo lo que se explica en este anexo funciona en ambas, salvo que se indique lo contrario.

### 1.2 Cmdlets: formato de nombre

Los cmdlets siguen siempre el patrón **Verbo-Sustantivo**, en inglés y en singular:

```powershell
Get-Service     # obtener servicios
Get-Process     # obtener procesos
Set-Location    # cambiar de directorio
Copy-Item       # copiar un elemento
```

Los verbos más habituales: `Get` (consultar), `Set` (modificar), `New` (crear), `Remove` (eliminar), `Copy`, `Move`, `Start`, `Stop`, `Restart`, `Out` (enviar a salida), `Import`/`Export`.

Los parámetros se indican con guion: `-Name`, `-Path`, `-Force`, `-Recurse`, `-ErrorAction`. Muchos son abreviables: `-Recurse` se acepta escribiendo `-r` si no hay ambigüedad.

### 1.3 El sistema de ayuda

```powershell
Get-Help Get-Process          # ayuda de un cmdlet
Get-Help Get-Process -Examples  # solo ejemplos
Update-Help                   # actualiza la ayuda local
Get-Command *service*         # cmdlets que contienen "service"
Get-Member                    # propiedades y métodos de los objetos recibidos
```

### 1.4 Alias

PowerShell incluye alias de compatibilidad con CMD y Linux para los cmdlets más comunes:


| Alias         | Cmdlet          | Equivalente en CMD/Linux |
| ------------- | --------------- | ------------------------ |
| `ls`, `dir`   | `Get-ChildItem` | `ls`, `dir`              |
| `cd`          | `Set-Location`  | `cd`                     |
| `cp`, `copy`  | `Copy-Item`     | `cp`                     |
| `mv`, `move`  | `Move-Item`     | `mv`                     |
| `rm`, `del`   | `Remove-Item`   | `rm`                     |

Se crean alias propios con `New-Alias` y se listan con `Get-Alias`.

### 1.5 El pipeline (`|`)

El operador `|` pasa la salida de un cmdlet como entrada del siguiente, pero **transfiriendo objetos completos**, no texto:

```powershell
Get-Process | Where-Object CPU -gt 10 | Sort-Object CPU -Descending
```

Cmdlets de uso muy frecuente en el pipeline:


| Cmdlet                         | Función                                 |
| ------------------------------ | --------------------------------------- |
| `Where-Object`                 | filtra objetos según una condición      |
| `Sort-Object`                  | ordena                                  |
| `Select-Object`                | selecciona propiedades                  |
| `Measure-Object`               | cuenta, suma, promedia                  |
| `Format-Table` / `Format-List` | da formato de tabla o lista a la salida |
| `Group-Object`                 | agrupa                                  |
| `ForEach-Object`               | ejecuta un bloque por cada objeto       |


### 1.6 Estructura de un script

Un script de PowerShell es un fichero de texto con extensión **`.ps1`**. Ejemplo mínimo:

```powershell
# saludo.ps1
Write-Host "Inicio del script"
$Nombre = Read-Host "¿Cómo te llamas?"
Write-Host "Hola, $Nombre"
```

Elementos del lenguaje:

**Variables** — se declaran con `$`, sin tipos obligatorios:

```powershell
$Nombre = "Mell"
$Numero = 7
$Lista  = @("uno", "dos", "tres")     # array
$Tabla  = @{ clave = "valor" }        # tabla hash
```

**Condicionales:**

```powershell
if ($Numero -gt 5) {
    Write-Host "Mayor que cinco"
} elseif ($Numero -eq 5) {
    Write-Host "Es cinco"
} else {
    Write-Host "Menor que cinco"
}
```

Operadores de comparación (no se usan `>`, `<`, `=`): `-eq` (igual), `-ne` (distinto), `-gt`/`-lt` (mayor/menor), `-ge`/`-le` (mayor o igual/menor o igual), `-like`/`-match` (patrones), `-and`, `-or`, `-not`.

**Bucles:**

```powershell
foreach ($item in $Lista) {
    Write-Host $item
}

for ($i = 0; $i -lt 5; $i++) {
    Write-Host "Vuelta $i"
}

while ($Numero -lt 10) {
    $Numero++
}
```

**Funciones:**

```powershell
function Saludo {
    param([string]$Nombre)
    Write-Host "Hola, $Nombre"
}
Saludo -Nombre "Mell"
```

**Comentarios:** con `#` para una línea y `<# ... #>` para bloques.

### 1.7 Ejecución de scripts y política de ejecución

Por seguridad, Windows **bloquea por defecto la ejecución de scripts**. La directiva que lo controla se consulta y se cambia con:

```powershell
Get-ExecutionPolicy                    # consultar (por defecto: Restricted)
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Valores principales: `Restricted` (ningún script), `RemoteSigned` (scripts locales sí, descargados solo si están firmados — el más recomendado), `AllSigned` (todos firmados) y `Unrestricted` (todos, con aviso).

Para ejecutar un script desde una consola:

```powershell
.\saludo.ps1        # en el directorio actual
pwsh -File C:\scripts\saludo.ps1      # PowerShell 7 (en 5.1: powershell -File …)
```

Como en Linux, es necesario indicar la ruta (o que el directorio esté en `$env:Path`).

### 1.8 Parámetros y entrada del usuario

Un script de PowerShell recibe parámetros declarándolos en un bloque `param()` al **principio** del fichero. A diferencia de Bash, los parámetros tienen **nombre** y pueden tener **tipo**, valor por defecto y validaciones:

```powershell
# saludar.ps1 - Ejemplo de parámetros con tipo y validación
param(
    [Parameter(Mandatory)]              # Obligatorio: si falta, PowerShell lo pide
    [string]$Nombre,

    [ValidateRange(1, 10)]              # Solo admite valores entre 1 y 10
    [int]$Veces = 1,                    # Valor por defecto

    [switch]$Mayusculas                 # Interruptor: vale $true si se escribe -Mayusculas
)

if ($Mayusculas) { $Nombre = $Nombre.ToUpper() }

for ($i = 1; $i -le $Veces; $i++) {
    Write-Output "Hola, $Nombre ($i/$Veces)"
}
```

```powershell
.\saludar.ps1 -Nombre Ana -Veces 2 -Mayusculas
# Hola, ANA (1/2)
# Hola, ANA (2/2)
.\saludar.ps1 Ana          # Los parámetros también se pueden pasar por posición
.\saludar.ps1 -Veces 20    # Error: 20 no está en el rango 1-10
```

| Bash | PowerShell | Significado |
| --- | --- | --- |
| `$1`, `$2`… | `param([string]$Nombre, …)` | Parámetros del script. |
| `$#` | `$args.Count` / `$PSBoundParameters.Count` | Número de parámetros. |
| `"$@"` | `$args` | Parámetros sin declarar (como *array*). |
| `${1:-valor}` | `[string]$Nombre = "valor"` | Valor por defecto. |
| `read -rp "Texto: " var` | `$var = Read-Host "Texto"` | Leer del teclado. |
| `read -rsp …` | `Read-Host "Clave" -AsSecureString` | Leer sin mostrar lo escrito. |
| `exit 1` | `exit 1` | Terminar con un código de salida (consultable con `$LASTEXITCODE`). |

`Read-Host` siempre devuelve **texto**. Para operar con números hay que convertirlo y comprobar que la conversión es posible:

```powershell
$entrada = Read-Host "Introduce un número entero"
if ($entrada -match '^-?\d+$') {          # -match usa expresiones regulares
    $numero = [int]$entrada                # Conversión explícita a entero
    Write-Output "El doble es $($numero * 2)"
} else {
    Write-Error "'$entrada' no es un número entero"
    exit 1
}
```

## 3. Comandos de Gestión de Ficheros

### 3.1 Listar, copiar, mover y borrar


| Comando (cmdlet)              | Función                           | Ejemplo                                        |
| ----------------------------- | --------------------------------- | ---------------------------------------------- |
| `Get-ChildItem` (`ls`, `dir`) | listar contenido de un directorio | `Get-ChildItem C:\Users -Recurse`              |
| `Copy-Item` (`cp`)            | copiar ficheros/directorios       | `Copy-Item C:\datos D:\backup -Recurse`        |
| `Move-Item` (`mv`)            | mover o renombrar                 | `Move-Item viejo.txt nuevo.txt`                |
| `Rename-Item`                 | renombrar                         | `Rename-Item informe.docx final.docx`          |
| `Remove-Item` (`rm`, `del`)   | eliminar                          | `Remove-Item .\temp -Recurse -Force`           |
| `New-Item`                    | crear fichero o directorio        | `New-Item -ItemType Directory -Path .\pruebas` |
| `New-Item -ItemType File`     | crear fichero vacío               | `New-Item -ItemType File -Path .\notas.txt`    |
| `Get-Content` (`cat`)         | leer un fichero                   | `Get-Content .\log.txt -Tail 20`               |
| `Set-Content` / `Add-Content` | escribir / añadir a un fichero    | `Add-Content log.txt "Nueva línea"`            |

| `Get-ItemProperty`            | propiedades de un fichero         | `Get-ItemProperty .\notas.txt`                 |


### 3.2 Comodines y filtrado

Los comodines funcionan igual que en Linux: `*` (cualquier texto) y `?` (un carácter):

```powershell
Get-ChildItem *.txt
Get-ChildItem C:\Users\?ata
Get-ChildItem -Recurse -Filter "*.log" | Where-Object Length -gt 1MB
```

### 3.3 Ejemplo de script

```powershell
# limpieza.ps1 — borra ficheros .tmp de más de 7 días y deja registro
$Carpeta = "C:\Users\usuario\AppData\Local\Temp"

Get-ChildItem $Carpeta -Filter *.tmp -Recurse | Where-Object {
    $_.LastWriteTime -lt (Get-Date).AddDays(-7)
} | ForEach-Object {
    Remove-Item $_.FullName -Force
    Add-Content limpieza.log "Borrado: $($_.Name)"
}
```

La variable automática `$_` representa el objeto actual del pipeline.

}

## 5. Comandos de Empaquetado y Compresión

### 5.1 Compresión con `Compress-Archive`

PowerShell incluye cmdlets nativos para trabajar con ficheros **ZIP**:


| Cmdlet             | Función              | Ejemplo                                                         |
| ------------------ | -------------------- | --------------------------------------------------------------- |
| `Compress-Archive` | comprimir en .zip    | `Compress-Archive -Path C:\datos -DestinationPath copia.zip`    |
| `Expand-Archive`   | descomprimir un .zip | `Expand-Archive -Path copia.zip -DestinationPath C:\restaurado` |


```powershell
# Comprimir varios elementos en un zip
Compress-Archive -Path .\informes\*, .\facturas\* -DestinationPath backup.zip -Force

# Descomprimir sobrescribiendo
Expand-Archive -Path backup.zip -DestinationPath .\restaurado -Force
```

El parámetro `-Force` sobrescribe el destino si ya existe.

### 5.2 Otras herramientas de empaquetado


| Herramienta                                         | Uso                                                                      |
| --------------------------------------------------- | ------------------------------------------------------------------------ |
| `tar`                                               | disponible en Windows 10+ y PowerShell: `tar -czf copia.tar.gz carpeta/` |
| `MakeCab`                                           | empaquetar en formato .cab (heredado de CMD)                             |
| `Expand`                                            | extraer ficheros .cab: `expand fichero.cab -F:* .\salida`                |
| Gestores de paquetes de software: `winget`, `choco` | instalar programas desde la consola: `winget install git`                |


> [!NOTE]
> En Windows/PowerShell el formato nativo de compresión por cmdlet es ZIP; para `.tar.gz` se usa `tar`, que ya viene incluido en el sistema.

### 5.3 Script de copia de seguridad comprimida

```powershell
# backup.ps1 — comprime el directorio de datos con fecha en el nombre
$Origen  = "C:\Users\usuario\Documentos"
$Destino = "D:\Backups"
$Fecha   = Get-Date -Format "yyyyMMdd"

if (-not (Test-Path $Destino)) {
    New-Item -ItemType Directory -Path $Destino | Out-Null
}

Compress-Archive -Path $Origen -DestinationPath "$Destino\copia_$Fecha.zip" -Force
Write-Host "Backup creado: copia_$Fecha.zip"
```

## Ejercicios resueltos

### Ejercicio 13.1. Calculadora con parámetros

Escribe `calc.ps1`, que reciba dos números (`-A` y `-B`) y una operación (`-Operacion`) que solo pueda ser `suma`, `resta`, `producto` o `division`, y muestre el resultado. La división entre cero debe mostrar un error.

{{% details "Ver solución" %}}
```powershell
# calc.ps1 - Calculadora con parámetros validados
# Uso: .\calc.ps1 -A 7 -B 2 -Operacion division
param(
    [Parameter(Mandatory)] [double]$A,
    [Parameter(Mandatory)] [double]$B,
    [Parameter(Mandatory)]
    [ValidateSet("suma", "resta", "producto", "division")]   # Valores permitidos
    [string]$Operacion
)

switch ($Operacion) {                     # switch equivale al case de Bash
    "suma"     { $resultado = $A + $B }
    "resta"    { $resultado = $A - $B }
    "producto" { $resultado = $A * $B }
    "division" {
        if ($B -eq 0) {
            Write-Error "No se puede dividir entre cero"
            exit 1
        }
        $resultado = [math]::Round($A / $B, 2)
    }
}

Write-Output "$A $Operacion $B = $resultado"
```

`[ValidateSet]` hace que PowerShell rechace cualquier otra operación y, además, permite autocompletarla con `Tab`. Al declarar los números como `[double]`, PowerShell trabaja directamente con decimales, a diferencia de Bash.
{{% /details %}}

### Ejercicio 13.2. Alta masiva de usuarios locales desde un CSV

Escribe `alta_usuarios.ps1`, equivalente al ejercicio 12.6 de Bash: a partir de un CSV con las columnas `nombre,apellido1,apellido2,grupo`, crea un usuario local por cada línea (inicial del nombre + primer apellido, en minúsculas y sin tildes), lo añade a su grupo (creándolo si no existe) y le obliga a cambiar la contraseña en el primer inicio de sesión. Por defecto debe funcionar en **modo simulación**; solo aplicará los cambios con el interruptor `-Aplicar`.

{{% details "Ver solución" %}}
```powershell
# alta_usuarios.ps1 - Crea usuarios locales a partir de un CSV
# Uso: .\alta_usuarios.ps1 -Csv .\nuevos.csv [-Aplicar]   (consola de administrador)
param(
    [Parameter(Mandatory)] [string]$Csv,
    [switch]$Aplicar
)

if (-not (Test-Path $Csv)) { Write-Error "No existe '$Csv'"; exit 1 }
if (-not $Aplicar) { Write-Output "*** MODO SIMULACIÓN: usa -Aplicar para crear los usuarios ***" }

# Quita tildes y diéresis: "Íñigo" -> "Inigo"
function Quitar-Tildes([string]$texto) {
    $descompuesto = $texto.Normalize([Text.NormalizationForm]::FormD)
    return ($descompuesto -replace '\p{Mn}', '')   # \p{Mn}: marcas diacríticas
}

$claveInicial = ConvertTo-SecureString "Cambiar.2026" -AsPlainText -Force

foreach ($fila in Import-Csv -Path $Csv -Encoding utf8) {
    $login = Quitar-Tildes(($fila.nombre.Substring(0, 1) + $fila.apellido1) -replace ' ', '')
    $login = $login.ToLower()

    if (Get-LocalUser -Name $login -ErrorAction SilentlyContinue) {
        Write-Warning "El usuario '$login' ya existe; se omite"
        continue
    }

    Write-Output "Creando '$login' ($($fila.nombre) $($fila.apellido1)) en el grupo '$($fila.grupo)'"
    if ($Aplicar) {
        if (-not (Get-LocalGroup -Name $fila.grupo -ErrorAction SilentlyContinue)) {
            New-LocalGroup -Name $fila.grupo | Out-Null
        }
        New-LocalUser -Name $login -Password $claveInicial `
            -FullName "$($fila.nombre) $($fila.apellido1) $($fila.apellido2)" | Out-Null
        Add-LocalGroupMember -Group $fila.grupo -Member $login
        net user $login /logonpasswordchg:yes | Out-Null   # Cambio obligatorio al entrar
    }
}
```

Compara esta solución con la de Bash: `Import-Csv` convierte cada línea en un **objeto** con propiedades (`$fila.nombre`, `$fila.grupo`), de modo que no hace falta trocear el texto con `IFS` ni `cut`. `Write-Warning` y `Write-Error` envían los mensajes a sus propios flujos, como `>&2` en Bash.

### Ejercicio 13.3. Vigilante de espacio en disco

Escribe `espacio.ps1`, que compruebe el porcentaje de uso de todas las unidades locales y, si alguna supera un umbral (parámetro `-Umbral`, 80 por defecto), escriba un aviso en pantalla y en el fichero `C:\Logs\espacio.log`. Prográmalo cada hora con el Programador de tareas (apartado 11.4).

{{% details "Ver solución" %}}
```powershell
# espacio.ps1 - Avisa si alguna unidad supera el umbral de uso
param([ValidateRange(1, 100)] [int]$Umbral = 80)

$log = "C:\Logs\espacio.log"
New-Item -ItemType Directory -Path (Split-Path $log) -Force | Out-Null   # Crea C:\Logs si falta

# DriveType = 3: discos locales (excluye USB, red y lectores ópticos)
$unidades = Get-CimInstance Win32_LogicalDisk -Filter "DriveType = 3"

foreach ($u in $unidades) {
    $uso = [math]::Round((1 - $u.FreeSpace / $u.Size) * 100)
    $linea = "{0:yyyy-MM-dd HH:mm} {1} al {2} %" -f (Get-Date), $u.DeviceID, $uso   # -f: formato
    if ($uso -ge $Umbral) {
        Write-Warning $linea
        Add-Content -Path $log -Value "AVISO $linea"
    } else {
        Write-Output "OK $linea"
    }
}
```

```powershell
$accion  = New-ScheduledTaskAction -Execute "pwsh.exe" `
             -Argument '-NoProfile -ExecutionPolicy Bypass -File "C:\Scripts\espacio.ps1" -Umbral 85'
$disparo = New-ScheduledTaskTrigger -Once -At (Get-Date) `
             -RepetitionInterval (New-TimeSpan -Hours 1)        # Repetir cada hora
Register-ScheduledTask -TaskName "Vigilante de espacio" -Action $accion -Trigger $disparo
```

El operador `-f` sustituye `{0}`, `{1}`… por los valores indicados, de forma parecida a `printf` en Bash.
