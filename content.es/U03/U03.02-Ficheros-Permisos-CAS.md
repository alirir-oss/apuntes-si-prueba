# 2. Ficheros, directorios y permisos

En Linux se suele decir que **"todo es un fichero"**: los documentos, los directorios, los dispositivos e incluso la información de los procesos se representan como ficheros. Por eso, saber manejarlos desde la terminal es la base de todo lo demás.

## 2.1 Listar y navegar

| Comando | Función |
| --- | --- |
| `pwd` | Muestra el directorio actual (*print working directory*). |
| `cd ruta` | Cambia de directorio. |
| `ls [ruta]` | Lista el contenido de un directorio. |
| `tree [ruta]` | Muestra el árbol de directorios (puede que haya que instalarlo: `sudo apt install tree`). |

Opciones más útiles de `ls`:

| Opción | Efecto |
| --- | --- |
| `-l` | Formato largo: permisos, propietario, tamaño, fecha… |
| `-a` | Incluye los ficheros ocultos (los que empiezan por `.`). |
| `-h` | Tamaños legibles (K, M, G). Se usa junto con `-l`. |
| `-t` | Ordena por fecha de modificación (más reciente primero). |
| `-r` | Invierte el orden. |
| `-S` | Ordena por tamaño. |
| `-R` | Recursivo: entra en los subdirectorios. |
| `-d` | Muestra el propio directorio, no su contenido. |

```bash
ls -lah ~          # Todo el directorio personal, ocultos incluidos, tamaños legibles
ls -lt /var/log    # Registros ordenados por fecha
ls -ld /tmp        # Información del directorio /tmp en sí
```

### Interpretar la salida de `ls -l`

```text
-rw-r--r-- 1 alumno alumno 1036 nov  8 18:41 notas.txt
drwxr-xr-x 2 alumno alumno 4096 nov  8 18:40 proyectos
lrwxrwxrwx 1 alumno alumno   10 nov  8 18:42 enlace -> notas.txt
```

| Campo | Ejemplo | Significado |
| --- | --- | --- |
| Tipo | `-` / `d` / `l` | `-` fichero normal, `d` directorio, `l` enlace simbólico, `c`/`b` dispositivo de caracteres/bloques. |
| Permisos | `rw-r--r--` | Permisos del propietario, del grupo y del resto (ver apartado 2.7). |
| Enlaces | `1` | Número de enlaces duros al fichero. |
| Propietario | `alumno` | Usuario propietario. |
| Grupo | `alumno` | Grupo propietario. |
| Tamaño | `1036` | Tamaño en bytes. |
| Fecha | `nov  8 18:41` | Fecha de la última modificación. |
| Nombre | `notas.txt` | Nombre del fichero. |

## 2.2 Crear, copiar, mover y borrar

| Comando | Función | Opciones importantes |
| --- | --- | --- |
| `mkdir dir` | Crea directorios. | `-p` crea los intermedios y no falla si ya existe. |
| `touch fich` | Crea un fichero vacío o actualiza su fecha si ya existe. | |
| `cp origen destino` | Copia ficheros. | `-r` recursivo (directorios), `-i` pregunta antes de sobrescribir, `-a` conserva permisos, fechas y enlaces, `-v` muestra lo que hace. |
| `mv origen destino` | Mueve **o renombra**. | `-i` pregunta antes de sobrescribir, `-n` no sobrescribe nunca. |
| `rm fich` | Borra ficheros. | `-r` recursivo, `-i` pregunta, `-f` fuerza sin preguntar. |
| `rmdir dir` | Borra un directorio **vacío**. | |

```bash
mkdir -p ~/practicas/u03         # Crea practicas y u03 si no existen
cd ~/practicas/u03
touch a.txt b.txt                # Dos ficheros vacíos
cp a.txt copia.txt               # Copia con otro nombre
cp a.txt b.txt /tmp/             # Varios ficheros a un directorio (el destino va al final)
cp -r ~/practicas ~/practicas.bak   # Copia un directorio completo
mv copia.txt renombrado.txt      # Renombrar
mv renombrado.txt /tmp/          # Mover
rm -i b.txt                      # Borrar pidiendo confirmación
rmdir vacio/                     # Solo funciona si el directorio está vacío
rm -r ~/practicas.bak            # Borra un directorio y todo su contenido
```

> [!CAUTION]
> En Linux **no hay papelera** desde la terminal: lo que se borra con `rm` desaparece. Revisa dos veces cualquier orden `rm -r` o `rm -rf`, especialmente si contiene comodines o variables. Una orden como `rm -rf /` (o `rm -rf $DIR/` con `$DIR` vacío) puede destruir el sistema.

## 2.3 Ver el contenido de los ficheros

| Comando | Función |
| --- | --- |
| `cat fich` | Muestra el fichero completo. Con varios ficheros, los concatena. |
| `less fich` | Muestra el fichero paginado. `Espacio` avanza, `b` retrocede, `/texto` busca, `q` sale. |
| `head -n N fich` | Muestra las N primeras líneas (10 por defecto). |
| `tail -n N fich` | Muestra las N últimas líneas (10 por defecto). |
| `tail -f fich` | Sigue el fichero en tiempo real (muy útil con registros). `Ctrl+C` para salir. |
| `nl fich` / `cat -n fich` | Muestra el fichero con las líneas numeradas. |
| `wc fich` | Cuenta líneas (`-l`), palabras (`-w`) y bytes (`-c`). |

```bash
cat /etc/hostname
less /etc/services
head -n 3 /etc/passwd
sudo tail -f /var/log/syslog     # En sistemas con journald puro: journalctl -f
wc -l /etc/passwd                # ¿Cuántas líneas (usuarios) hay?
```

## 2.4 Información sobre ficheros

```bash
file /bin/ls          # ELF 64-bit LSB pie executable…  -> tipo real del fichero
file foto.jpg         # JPEG image data…  (Linux no depende de la extensión)
stat notas.txt        # Tamaño, permisos, inodo y fechas de acceso/modificación/cambio
du -sh ~/Descargas    # Espacio que ocupa un directorio (-s resumen, -h legible)
```

## 2.5 Enlaces

Cada fichero se almacena en el disco en una estructura llamada **inodo**, que guarda sus datos y metadatos (permisos, propietario, bloques que ocupa…). El nombre del fichero es solo una entrada de directorio que apunta a un inodo. Hay dos tipos de enlaces:

| | Enlace duro (`ln`) | Enlace simbólico (`ln -s`) |
| --- | --- | --- |
| Qué es | Otro nombre para el **mismo inodo**. | Un fichero pequeño que contiene la **ruta** de otro (como un acceso directo). |
| Si se borra el original | El contenido sigue accesible desde el enlace. | El enlace queda "roto". |
| Directorios | No permitido. | Permitido. |
| Entre particiones | No. | Sí. |

```bash
ln notas.txt notas_duro.txt          # Enlace duro
ln -s /var/log/syslog ~/syslog       # Enlace simbólico: ln -s DESTINO NOMBRE_ENLACE
ls -li                               # -i muestra el número de inodo
```

## 2.6 Buscar ficheros con `find`

`find` recorre un árbol de directorios y muestra los ficheros que cumplen unas condiciones:

```text
find [dónde] [condiciones] [acción]
```

| Condición | Significado |
| --- | --- |
| `-name 'patrón'` | Nombre (admite comodines; ponlo **entre comillas** para que no lo expanda la shell). |
| `-iname 'patrón'` | Igual que `-name`, sin distinguir mayúsculas. |
| `-type f` / `-type d` / `-type l` | Ficheros normales / directorios / enlaces simbólicos. |
| `-size +10M` / `-size -1k` | Más de 10 MiB / menos de 1 KiB. |
| `-mtime -7` / `-mtime +30` | Modificados hace menos de 7 días / más de 30 días. |
| `-user nombre` | Pertenecen al usuario indicado. |
| `-perm -u=x` | Tienen activado el permiso de ejecución para el propietario. |
| `-empty` | Ficheros o directorios vacíos. |
| `-maxdepth N` | Baja como máximo N niveles. |

| Acción | Significado |
| --- | --- |
| `-print` | Muestra la ruta (acción por defecto). |
| `-exec orden {} \;` | Ejecuta una orden por cada fichero; `{}` se sustituye por su ruta. |
| `-exec orden {} +` | Igual, pero pasando muchos ficheros de una vez (más eficiente). |
| `-delete` | Borra los ficheros encontrados (¡pruébalo antes sin `-delete`!). |

```bash
find ~ -name '*.java'                       # Ficheros .java en mi directorio personal
find /etc -maxdepth 1 -type f -name '*.conf'
find ~ -type f -size +100M                  # Ficheros grandes
find /tmp -type f -mtime +7 -user "$USER"   # Mis ficheros temporales de hace más de una semana
find . -type f -name '*.sh' -exec chmod u+x {} +   # Da permiso de ejecución a todos los .sh
find . -type d -empty                       # Directorios vacíos
find /etc -name '*.conf' 2>/dev/null        # Oculta los errores de "Permiso denegado"
```

> [!TIP]
> Para buscar **dentro** del contenido de los ficheros se usa `grep -r 'texto' directorio`, que veremos en el siguiente apartado.

## 2.7 Permisos

Linux es un sistema **multiusuario**: cada fichero tiene un **propietario** y un **grupo**, y unos permisos que indican qué puede hacer cada tipo de usuario.

### Los tres permisos y las tres clases de usuario

| Permiso | Sobre un fichero | Sobre un directorio |
| --- | --- | --- |
| `r` (lectura) | Ver su contenido. | Listar su contenido (`ls`). |
| `w` (escritura) | Modificar su contenido. | Crear, borrar y renombrar ficheros dentro. |
| `x` (ejecución) | Ejecutarlo como programa o script. | Entrar en él (`cd`) y acceder a sus ficheros. |

Los permisos se agrupan de tres en tres:

```text
 -   rwx   r-x   r--
 │    │     │     └── o (others): el resto de usuarios
 │    │     └──────── g (group): miembros del grupo propietario
 │    └────────────── u (user): el propietario
 └─────────────────── tipo de fichero
```

### `chmod`: cambiar permisos

`chmod` admite dos notaciones.

**Notación simbólica**: `[ugoa][+-=][rwx]`

```bash
chmod u+x script.sh          # Añade ejecución al propietario
chmod g-w informe.txt        # Quita escritura al grupo
chmod o= privado.txt         # Deja al resto sin ningún permiso
chmod a+r publico.txt        # Lectura para todos (a = all)
chmod u+rwx,g+rx,o-rwx dir/  # Varias modificaciones separadas por comas
chmod -R g+w compartido/     # Recursivo: el directorio y todo su contenido
```

**Notación octal**: cada clase de usuario se representa con un número que es la suma de `r=4`, `w=2` y `x=1`.

| Octal | Permisos | | Octal | Permisos |
| --- | --- | --- | --- | --- |
| `7` | `rwx` (4+2+1) | | `3` | `-wx` (2+1) |
| `6` | `rw-` (4+2) | | `2` | `-w-` |
| `5` | `r-x` (4+1) | | `1` | `--x` |
| `4` | `r--` | | `0` | `---` |

```bash
chmod 755 script.sh     # rwxr-xr-x : típico de scripts y directorios
chmod 644 index.html    # rw-r--r-- : típico de ficheros de datos
chmod 600 ~/.ssh/id_ed25519   # rw------- : claves privadas (SSH lo exige)
chmod 700 ~/privado     # rwx------ : directorio solo accesible por mí
```

> [!NOTE]
> En la Unidad 4 se estudian con detalle el cambio de propietario (`chown`, `chgrp`), la máscara `umask`, los permisos especiales (SUID, SGID, *sticky bit*) y las listas de control de acceso (ACL).

## Ejercicios resueltos

### Ejercicio 2.1. Organizar una práctica

Crea en tu directorio personal la carpeta `entrega`, con los ficheros vacíos `main.sh`, `README.md` y `notas.txt`. Después copia toda la carpeta a `entrega_backup`, renombra `notas.txt` a `apuntes.txt` (en la carpeta original) y borra la copia de seguridad.

{{% details "Ver solución" %}}
```bash
mkdir ~/entrega
touch ~/entrega/{main.sh,README.md,notas.txt}
cp -r ~/entrega ~/entrega_backup
mv ~/entrega/notas.txt ~/entrega/apuntes.txt
rm -r ~/entrega_backup
ls -l ~/entrega      # Comprobación
```
{{% /details %}}

### Ejercicio 2.2. Interpretar permisos

Indica qué puede hacer cada clase de usuario y escribe el equivalente octal:

1. `-rwxr-x---`
2. `-rw-rw-r--`
3. `drwx--x--x`

{{% details "Ver solución" %}}
1. `750`. Propietario: leer, escribir y ejecutar. Grupo: leer y ejecutar. Resto: nada.
2. `664`. Propietario y grupo: leer y escribir. Resto: solo leer.
3. `711`. Es un directorio. El propietario puede listarlo, crear ficheros y entrar; el grupo y el resto solo pueden **entrar** (`cd`) y acceder a un fichero si conocen su nombre exacto, pero no pueden listar el contenido.
{{% /details %}}

### Ejercicio 2.3. Proteger un fichero

Crea el fichero `secreto.txt` de forma que **solo tú** puedas leerlo y modificarlo. Hazlo con las dos notaciones de `chmod` y comprueba el resultado.

{{% details "Ver solución" %}}
```bash
touch secreto.txt
chmod 600 secreto.txt           # Notación octal
chmod u=rw,go= secreto.txt      # Notación simbólica equivalente
ls -l secreto.txt               # -rw------- 1 alumno alumno 0 … secreto.txt
```
{{% /details %}}

### Ejercicio 2.4. Búsquedas con `find`

Escribe la orden que:

1. Muestra los ficheros `.log` de `/var/log` (sin entrar en subdirectorios).
2. Muestra los ficheros de tu directorio personal modificados en las últimas 24 horas.
3. Cuenta cuántos ficheros `.conf` hay en `/etc` y sus subdirectorios.
4. Borra los ficheros `.tmp` de `~/practicas` (comprobando antes cuáles son).

{{% details "Ver solución" %}}
```bash
find /var/log -maxdepth 1 -type f -name '*.log'
find ~ -type f -mtime -1
find /etc -type f -name '*.conf' 2>/dev/null | wc -l   # wc -l cuenta las líneas (ver apartado 3)
find ~/practicas -type f -name '*.tmp'          # 1.º: comprobar
find ~/practicas -type f -name '*.tmp' -delete  # 2.º: borrar
```
{{% /details %}}
